# 動作環境の決め方と測った値（2026-11-23）

ユーザー「対応機種や PC の対応スペックも、世の中の開発者はどうやって算出しているのか調べて実装した方がいい」。

## 世の中の決め方（調べた結果）
- 一番低く支えると決めた端末で実際に遊び、場面ごとのメモリと処理の重さを記録し、余裕を足して最低の条件にする。試した一番低い環境を書く（Unity・Unreal の開発者の議論、PC Gamer の記事）。
- iPhone の Safari は1つのページが使えるメモリに上限があり、超えると「問題が起きたので再読み込みしました」と落ちる。WebKit の開発者は「1.5GB を目安に、メモリの少ない機種ではそれより低く見積もる」。600MB 程度という古い見積もりもある（WebKit Bugzilla 227636・261685、bugnet の記事）。
- 画像をまとめて展開すると落ちやすい・blob の URL の解放漏れで落ちる（同上）。

## 決めた動作環境（販売ページ・説明書に書く）
- スマホ（横画面専用）
  - iPhone：iOS 16 以降、iPhone XS / XR 以降（メモリ 3GB 以上）。iPhone 11 以降をおすすめ。Safari。ホーム画面に追加して全画面で遊ぶのがおすすめ
  - Android：Android 10 以降、メモリ 4GB 以上、Chrome 105 以降
  - iPad：iPadOS 16 以降
- パソコンのブラウザ：Chrome / Edge 105 以降、Safari 16 以降、Firefox 121 以降。メモリ 4GB 以上（8GB 以上がおすすめ）。画面 1280×720 以上がおすすめ
- パソコン版（Windows のアプリ）：Windows 10 / 11（64ビット）、メモリ 4GB 以上（8GB 以上がおすすめ）
- 通信：初回は Wi-Fi をおすすめ（約8MB、遊ぶと場面ごとに読む）。通信なしで遊ぶにはオフラインパック（約84MB）

## 根拠と余裕
- iOS 16：使っている書き方の下限は 15.4。16 にしたのは、15 の端末（iPhone 6s/7）がメモリ 2GB で、上の山（パソコンで約1GB）に余裕が無いため。
- iPhone XS/XR 以降：メモリ 3GB。WebKit の目安（メモリの少ない機種は 1.5GB より低く）に対し、描画の係 300MB ＋画像・GPU の取り置きで収まる見込み。iPhone 11 以降（4GB）をおすすめに。
- 実機で確かめた端末：まだ無し（iPhone 13 で落ちる報告を受けて直した。実機での確認は台帳に残す）。

## 測り直し方
`node qa/memwatch.mjs`（出入りの山）・`node qa/perfprobe.mjs 1,4,6`（滑らかさ）・`QA_URL=https://takakazuaikawa-hue.github.io/tousatsu-mimi/index.html node qa/netprobe.mjs`（読み込み）。新しい遊び・大きな絵を足したら流す。

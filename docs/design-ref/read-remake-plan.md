## 3. 作り直しの芯（3つ共通）

1. **読み合いの決断＝卓の操作。** 読み合いの最後に押す「付いていく／降りる」が、そのまま卓のコール／フォールドになる。横の「自信の賭け」はやめる（判断が1つになり、賭かるのは本物のチップ）。
2. **答えは画面に書かない。プレイヤーが作る。** 10個の印の目盛り（勝ち目）は、プレイヤーが見つけた物（癖・当たり札）を入れて初めて埋まる。払う額の線は同じ目盛りに金の杭で立つ。比べるのはプレイヤー。
3. **物差しは1つ。** 画面で見せた材料で数えた答え＝採点の答え。見えない札の運は採点に入れず、答え合わせで「運の分」と分けて見せる。
4. **足場かけの3段（D8）**：段1 お手本（リコがやって見せ、光った所を押すだけ・外しても減らない）→ 段2 手引き（道具は出るが、肝心の1手は自分。困ったらリコに聞ける）→ 段3 ひとり（ご褒美2倍）。2回続けて正しい判断で次の段へ。段は遊びごとにセーブ。
5. **答え合わせの劇場。** 決着の後、相手の札がめくれる → 自分で作った目盛りが再生される → 判断の判子（◎正しい／△惜しい／×損）と勝ち負け（運）を分けて押す → 理由を札や顔の上で光らせ、1行だけ書く。
6. **画面の要素は4つまで。** 相手（顔かミニキャラ）・場（卓の布の上の本物の札）・道具（目盛り）・押す所。稼ぎ・コンボは画面の隅の1つの札にまとめる。

## 11/16 決定：呼び名は「リーディング」

心理バトル・論理バトルの言い方は廃止し、「リーディング」に統一する（ユーザー「読み合っているというより読んでいるだけ」「広報でも特徴として押し出す」）。遊びごとの名前は「リーディング：値付け」のように付ける。設定の2つのスイッチは「リーディングを出す／出さない」1つにまとめる。言葉の直しは新しいリーディングを本編に入れる時に全画面まとめて行う。

## 1. 筋：なぜ彼女が言い出すのか、卓のどこで起きるのか

**卓の場面**：場札5枚が全部出た後。ミミが大きく賭けた（プレイヤーが自分で押した本当の賭け）。次はポルカの番。

**ポルカの気持ち**：手はペアくらい。払うにはこわい。降りるのはくやしい。しらふなら黙って降りる所。でも今夜は酔っていて（ポルカは泣き上戸）、口もガードもゆるい。だから口に出る。

> 「う〜、こわいよぉ……。ねえ、1枚ずつ 見せっこしよ？」
> （返事を待たずに、自分の札を1枚ぺろっとめくる）
> 「あたし、これ〜！ 弱そうだったら、払うから〜」

- 本物のポーカーでも、大きく賭けられて迷った人が「1枚見せてくれたら決める」と言うのは、よくある場面。しらふの人は自分の札までは見せない。**自分から先に見せてしまうのが、酔っている所**。
- 見せるのは、役ができている方の1枚（「9 と 9 でペア〜♪」と自慢したい）。
- ミミが見せなければ、彼女は安心できないまま降りる（「あたしだけ見せたのに〜！ ずるい〜！」）。
- 「わざわざ言う状況があるか？」への答え：**迷っている人が、決め手をほしがっている**。ミミを揺さぶるためではなく、自分が安心したいから言う。だから「弱そうなら払う・強そうなら降りる」という反応も、そのまま筋が通る。

## 3. 決まり1つ

画面にいつも1行で出す：

> **見せた1枚＋場札の役が、彼女の役より下に見えれば、払う。上なら、降りる。**

「見せない」ボタンの下に小さく：「こわがったまま、降りる」。

- 彼女は酔っているので、**見えた分だけで決めつける**（伏せた方の札は考えない）。これがポルカの酔い方。
- くらべる相手は、彼女の**本当の役**。彼女が見せた1枚＋場札の役が、そのまま本当の役になる場面だけで出す（§6）。だから、役の札に書いてある名前は事実。
- 「下」は、役の強さがはっきり下のこと。同じなら降りる（試作の6場面に同点は無い）。
- 乱数は無い。どの札を見せたら彼女がどうするかは、決める前に全部決まっている。

**この決まりから出てくること（覚えなくてよい。遊ぶと分かる）**

1. ミミが勝っている時：彼女より弱く見える札を見せれば、払ってもらえる（一番の得）。強く見える札を見せるか、見せなければ、降りられる（ポットだけ）。
2. ミミが負けている時：何を見せても、彼女の役より下に見える → 安心して払われる → 負ける。**見せないのが正解**（彼女はこわがったまま降りる。はったりが通る）。
3. こわい札は、数字の大きさでは決まらない。**場札とつながる札**がこわい（同じ数字・並びの最後の1枚・同じマークの5枚目）。

絵の印（文でなく絵で見せる）：
- 彼女が見せた札と、それとペアになる場札を、**金の糸**で結ぶ。その下に役の札「9 のペア」。
- 明かしで、ミミの見せた札も同じ金の糸で場札と結ばれ（つながらなければ糸は出ない）、「こう見えた：4 のペア」の札が出る。彼女の役の札と上下に並び、強い方が上にせり上がる。
- 決める前、ミミの札には糸を出さない（ここが考える所）。場面1・2（手引き）だけ、札を持ち上げると糸と「こう見える」が出る。

## 5. 固定の6場面

共通：場面ごとに独立。全部、最後の札の後・ミミが 300 賭けた所から。場面1・2は手引きの段（左下に「リコに聞く」。札を持ち上げると金の糸と「こう見える」が出る）。場面3〜6はひとりの段（リコは出ない。持ち上げても何も出ない。「お手本」は開ける）。
ミミの札は、下に書いた順に左・右へ置く。金の糸・役の名前・彼女の出方・理由の文の { } は、手で書かず計算から出す（表と食い違わないように。目利き・異議ありと同じ作り）。

### 場面1（手引き）　高い札の方が、こわくない　→ 左の札（A♦）

- 場札：J♥ 8♠ 6♦ 3♣ 2♥
- ミミ：A♦ J♣（J のペア）／ポルカ：8♦ 4♠（8 のペア。見せるのは 8♦）
- A♦ を見せる → 「役なし」に見える → **払う** ◎ ＋900。ポルカ「なーんだ、何もないじゃん！ はったりだ〜♪」「払う払う〜！」→ J♣ がめくれる →「えっ……J も！？ J のペア！？ ず、ずる〜い！ うわぁ〜ん！」
- J♣ を見せる → 「J のペア」に見える → 降りる △
- 見せない → 降りる △
- 理由の1行：「A は場札とつながらない。『役なし』に見えるので、安心して払った」
- リコの1行：「A は大きいけど、場に A は無いよね。J は？ 場に J があるよ」
- ねらい：お手本は「小さい方を見せる」だった。ここで**大きい A の方が安全**と分かる。「小さい方を見せればいい」と覚えた人が止まる。

### 場面2（手引き）　負けている時は、見せない　→ 見せない

- 場札：Q♠ 10♦ 7♣ 4♥ 2♠

- 9♥ を見せる → 「役なし」→ 払う ✕ −300（同じ）

## 7. 一番の不安と、やめる線（正直に）

1. **考える段が2つある。**「ミミは勝っている？」→「どっちの札が弱く見える？」。目利き・異議ありは1段だった。勝ち負けは役の札2枚を見くらべるだけにしてあるが、作者が「難しい」と感じたら、決める画面の1行を「ミミの勝ち。払わせたい」「ミミの負け。降ろしたい」と言い切る形に替える（考える所は「どっちの札」だけになる）。
2. **負けている場面の答えは、いつも「見せない」。** 覚えると反射になる。支えは「本当に負けているか」を見くらべる所（場面4）。浅いと感じたら、負けている場面を6問中1問に減らす。
3. **勝っている時、「見せない」は「まちがった札」と同じ結果（逃げられる）。** 罰が無いので「とりあえず見せる」が損にならない。危ないのは負けている時だけ。これは本物のポーカーどおりだが、度胸の要る場面は6問中2問しかない。
4. **ポルカがいつも「見えた分だけ」で決めるのは、都合がよすぎないか。** 酔っているから、で通すが、作者が不自然と感じたら、ここが一番の直し所（例：同じマークが場に3枚ある時は、見せた1枚が同じマークならフラッシュをこわがる、など。その分、決まりが増える）。
5. **役の名前を2つくらべる力が要る**（ペア＜ツーペア＜スリーカード＜ストレート＜フラッシュ）。ほろ酔いの夜はクリア後なので、足りている見込み。
6. **やめる線**：作者が6場面を遊んで「場面3・5・6で、なぜその札がこわいのか納得できない」なら、明かしの絵（札が寄って光る）を直す。「どれを押しても同じに感じる」「クイズを解かされているだけ」なら、作り込まずに外す。

- 「酔っ払いの粋を極めた無茶苦茶な夜」

  - おしっこガマンで泣いちゃう、赤ちゃん甘え、「触って触って」
  - 洋服ぐちゃぐちゃでパンツかぶる
  - 奇声、意味不明の言葉の連発
- 11/09 の追加案
  - 素肌にトランプを貼る
  - グラスや瓶を股に挟む
  - パンツを振りまわす
  - スカート捲りごっこをする

## 3. 案（決めてもらう所）
### 3-1. 勝負の途中の場面の数
- 案A：1戦に2回（序盤と終盤）。泥酔は読み合いが無い分、会話劇を増やす。
- 案B：1戦に1回（ほろ酔いと同じ）＋決着の直前に短い一言。
- 本体のおすすめ：**案A**。読み合いの代わりに、場面そのものを遊びの山にする。

### 3-2. 卓での泥酔らしさ（読み合いの代わりの手触り）
- 相手の台詞が意味不明になる。手がかりにはならない。
- 相手がときどき、とんでもない賭けをする（全部賭ける・降りるのを忘れる）。泥酔ならではの事故として出す。
- ミミの助言・心の声は全部「ふにゃ…」か奇声。泥酔は数字も出さない。
- ※勝ち負けがただの運にならないよう、相手の打ち方の崩れ方は人ごとに決める（例：ポルカは泣いて降りる、グラーノは何でも買う）。

### 3-3. 一枚絵
- 1人6枚（ほろ酔いと同じ）。うち2枚を勝負の途中に回す（3-1 の案Aの場合）。
- 追加案（1・11/09）を、人ごとに割り振る。

| 相手 | 割り振りの案 |
|---|---|
| リコ | 赤ちゃん甘え・「触って触って」 |
| ポルカ | おしっこガマンで泣く・パンツを振りまわす |
| セリナ | 意味不明の理屈を連発・素肌にトランプを貼る |
| グラーノ | 下ネタ連発・グラスや瓶を股に挟む |
| ヴェルベット | 洋服ぐちゃぐちゃでパンツかぶる・スカート捲りごっこ |

### 3-4. クリア報酬
- 案：写真集の第2弾（泥酔のミミとリコ、または5人全員）。

## 4. 作る順（決まってから）
1. 5人＋ミミの「前ボタン全開・ずり落ち」立ち絵を描く → ユーザーが選ぶ
2. 会話（扉・幕間・途中の場面・締め）の文案 → ユーザーが見る
3. 一枚絵（1人6枚） → ユーザーが選ぶ
4. 酔った打ち方・台詞・ふにゃの泥酔版
5. ホームの切り替え・夜の絵・台帳・報酬
6. 素面・ほろ酔いの絵が混ざらないかを全画面で確かめる（ほろ酔いの夜で Codex に指摘された所と同じ）

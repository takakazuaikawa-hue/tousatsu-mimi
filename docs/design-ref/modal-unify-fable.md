## 1. 共通の小窓の型（CSS の値で）

考え方：ホームの「台帳の額」と「今夜の卓へ」の札をそのまま小窓にする。
**地は黒に近い深紅、線は金の二重線、見出しは深紅の銘板に金文字、主ボタンは札、副ボタンは線だけ。角は尖らせる（丸めても 2px まで）。白い面・ピンク・紫・緑を一切使わない。**

外に太い暗金、内に細い明金。本物の額縁の「外は彫りで暗く、内側の細い縁が光る」を線で再現する。角は 0。

  0 0 0 5px #0a0304,                               /* 外縁の黒 */

## 2. ChatGPT で描く価値のある部品（最小限）

**新しく描くのは 1 枚だけ。** あとは既にある home の部品を使い回す。

### 新規 A：小窓の角飾り（1枚で四隅）
- 用途：§1-3 の外側の暗金の線の四隅に乗せる。PC 56px／スマホ 40px 表示。
- 描き方：正方形 1024×1024、純緑 #00FF00 の無地背景。**左上の角**として描く。上辺と左辺の端まで真っ直ぐな金の縁（幅 48px）が伸び、角でアカンサスの葉と C スクロールが膨らむ（膨らみは角から 320px 以内）。金はホームの額（`assets/ui/home/frame.webp`）を添付して「同じ金属・同じ光」と指定。光は左上から、面の陰影だけで立体にし、**落ち影は描かない**（緑に影が乗ると切り抜けない）。宝石なし、文字なし、両腕の端は切り口が平らになるように。
- 切り抜き：緑を抜いた後、縁を 1px 削る（緑のフリンジ対策）。2倍（112px 相当）で webp、`assets/ui/modal/corner.webp`。他3隅は CSS の反転で足りる。
- 確認：黒地に置いて白い点・緑の縁が出ていないこと（前回の額で出た症状）。

### 流用（描かない）
| 部品 | 使う所 |
|---|---|
| `oct.webp` | 閉じるボタン（§1-9）。メダリオンの赤石を減らす直しが入れば、自動で閉じるも揃う |
| `nameplate.webp` / `plate.webp` | 見出しの銘板（§1-4）・節の「3/5」の小銘板。まず border-image の 9 分割で試す |
| `seal.webp` | 撃破済み・達成済みの印（手帳の緑のチェック、名鑑の「✓撃破済み」の代わり） |
| `lock.webp` | 手帳・装備の未解放（絵文字🔒の代わり） |
| `mark.webp` | 節の頭の印、辞典の見出し |
| `ico_coin.webp` | 価格の前のコイン |

### 条件付きで 1 枚：長い銘板
`nameplate.webp` を 9 分割で伸ばした時に中央の模様が割れる場合だけ、横長 1024×256、中央 400px が無地の金縁の深紅の板を描く（両端に飾り、中は平ら）。それ以外は描かない。
罫線の中央飾り（◆）や区切り線は CSS で足りる。描かない。

## 3. 型をかぶせるだけでは足りない小窓（並べ方から直す）

### 3-1. 役の早見表（hand-guide）— PC で右半分が空く、スマホで縦に長い
- 10 役を **2列×5行** にする。PC は M 720px の中に列幅 340px、行の高さ 48px。スマホは全画面紙面で 2 列 × 5 行 × 44px = 220px ＋見出し 44 ＋余白で 390 に収まり、スクロールが要らなくなる。
- 行：役名 `700 13px 明朝 #efcd82`／説明 `11px #b19a74`／右に札 5 枚（22×30px）。札は今の白いままでよい（白い面はここだけの例外、札だから）。
- 「タップして閉じる」の文字を消し、× ＋幕タップ＋Esc。PC 写真で閉じなかった件はここで一緒に確認する。

### 3-2. キャラ名鑑（char-profile）— スマホで立ち絵が豆粒、全部が縦スクロール
- **左右 2 段組**にする。左 34% に立ち絵を紙面の高さいっぱいで（`object-fit:contain`、下端を足元に揃える）、右 66% に文章。右だけスクロール。PC も同じ 2 段（立ち絵 300px 高）。
- 名前は右上に銘板（§1-4）、肩書きは名前の下に `12px #b19a74`。🔥 の丸い印は外す（キャラを丸で囲まないの決まりに触れる）。
- 「ブラフ入門」「開始チップ…」「✓撃破済み」のピルは、小銘板（高さ 20px）と `seal.webp` に置き換える。
- 能力のバー：溝 `#2b1309` 4px、満ちた側 `#d9b269`、数値は明朝の金。

### 3-3. ゲーム設定（settings-overlay）＋ 音量・設定（.home-dialog）— 2 つあるのが混乱、縦に長い
- **一つの「設定」に統合**し、タブ3つ：音（BGM・効果音のつまみ・消音でも鳴らす）／バトル（心理・論理）／その他（装備変更へ・手帳へ・辞典へ・リセット）。M 720px。
- スマホではタブのまま 2 列（左にラベル、右に切替）で 44px の行が 3〜4 本。今の「閉じる」が紙面の端に貼り付く縦長はなくなる。
- 「トロフィー手帳を開く」「辞典を開く」は設定の中にある必要がない。ホームにもう出口があるなら消してよい（その他タブの行数が減る）。
- リセットは §1-6 の危険ボタンで左下、押したら確認（mimi-confirm）。

### 3-4. 物語の台帳（ledger）— スマホで 5 行目が切れる、ボタンの文字が長い

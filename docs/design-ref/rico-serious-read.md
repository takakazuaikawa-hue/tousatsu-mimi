# 本気のリコ専用の読み合い「卒業試験」（中身・2026-10-25 案）

台帳 34・41。読み合いは「4人の総まとめ」ではなく、本気のリコだけの遊びにする（10/21 決定）。骨組みより先にこの中身を決める。

## 人物の考察（芯）

- リコ先輩は教育係。教えた順：降りる勇気 → 言葉と顔の食い違い → ベット額の意味 → 払う価値（ポットと支払額）→ 場の危なさ → 積み重なった証拠。
- 本気のリコは「練習は終わり。ここからは試験よ」「教える立場やめたから」「ミミ、もう守らないからね」と言う。
- そして先輩は、ミミの全部を見てきた人。「今日までの全部、ちゃんと見てたから」（ヴェルベット戦後の幕間）「ミミならできるって、アタシが一番知ってる」（セリフ集）。
- だから本気の先輩は、**ミミの癖を読んで、その逆を突いて賭けてくる**。大きな賭けにすぐ降りる子にはブラフで、付いてきすぎる子には本物で。これは上級者の「相手の癖を突く」打ち方（相手が自分をどう見ているかを読む、ポーカーの考え方のレベル3）そのもの。
- 卒業とは、先輩に読まれない打ち手になること。教わった道具（教え）で、教えた本人を読み返す。

## 手本（調べたもの）

- The Boss（メタルギアソリッド3）：師匠が最後の相手。教わった技（CQC）で返すことが勝ち筋。
- サイコ・マンティス（メタルギアソリッド）：プレイヤーの遊び方を読んで先読みする。読まれない手（差し口を替える）で破る。
- じゃんけんの機械（ニューヨーク・タイムズ）：人の手の癖を覚えて先を読む。人はでたらめに打てないので、癖が読まれる。
- ポーカーの「レベルの考え」：相手が自分の手と癖をどう見ているかを読む段で、上手下手が分かれる。

## 遊びの4点

| | 中身 |
|---|---|
| 目的 | 本気の先輩の大きな賭けが、本物（ミミより強い）かブラフかを読む。**先輩の予想を外して当てると「卒業」に近づく** |
| やり方 | ① ミミ自身の記録を見る（先輩はこれを見て賭けている）② 先輩に教わった3つの教えから1つ使って、手がかりを1つ得る ③ 本物かブラフか、自信を決めて預ける |
| 危なさ | 先輩はミミの癖の逆を突いてくる。癖どおりに読むと外れやすい。当たっても、先輩の予想どおりの読みなら卒業には近づかない |
| 決める所と見る物 | ① どの教えを使うか → 3つの教えの「確かさ」と、今の場面に効きそうか ② 本物かブラフか → 天秤（ミミの記録の重り＋教えの手がかりの重り）と、先輩の予想 ③ 自信 → 天秤の見込み |

## 作り（本当の手から）

- 本当の手の勝負：本物＝読んだ時点でミミが勝つ見込み 50% 未満（ほかの読み合いと同じ）。答え合わせは手の決着の後。
- **ミミの記録**：大きな賭け（ポットの6割以上）を受けた最近20回の「降りた／付いていった」。セーブに積む（相手を問わず）。記録が無いうちは、教わったとおり慎重な子として「降りた 12／付いていった 8」から始める。
- **天秤の最初の重り＝ミミの癖**：降りた割合が高いほど、先輩のブラフが混ざる（癖を突く）。例：降りた 14/20 → ブラフ寄り 65%。付いていった 14/20 → 本物寄り 65%。本当の手の答えは見込みで決まるので、重りは「起きやすさ」の目安（見つめ合いの記録と同じ扱い）。
- **先輩の予想**（はじめに公開）：ミミの癖から「ミミはここで『本物』と読んで降りる」のように言い切る。手の中身は使わない（答えの手がかりではない）。
- **3つの教え**（1つだけ使える）：本当の手から手がかりを1つ作る。確かさは◆で見せる。
  - ベット額の意味（◆◆）：この大きさは極端な手か。賭けの大きさと場から
  - 場の危なさ（◆◆◆／場に強い形がある時だけ）：先輩がその形を持っていそうか
  - 言葉と顔（◆）：本気の先輩はほとんど顔に出ない。当たりにくいが、出れば大きい
- **卒業**：先輩の予想を外して当てた回数を数える。本気のリコ戦の中で3回で「卒業」（称号＋専用の一枚絵）。
- 助言の欄は、リコ先輩ではなくミミの心の声（相手が先輩なので）。卓の背景は専用に（台帳34）。

## 楽しさの見込み（採点の6点）

迷い＝教えの選び方と「癖に従うか破るか」／明かし＝決着後に、先輩の予想と本当の手が並ぶ／性格＝教えた本人が癖を突いてくる／上達＝自分の癖が見え、変えると勝てる／新しさ＝相手ではなく自分が読まれる／手触り＝記録の点・封をした予想・天秤。

## 決めてもらうこと

1. 先輩の予想は、はじめから見せるか（案）／封をして答え合わせで開くか
2. 卒業の条件：本気のリコ戦の中で「予想を外して当てた」3回（案）か、ほかの数か

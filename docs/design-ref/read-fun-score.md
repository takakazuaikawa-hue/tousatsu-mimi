## 全体の問題（本体の考察）

1. **卓の勝負と切り離されている。** 読み合いの札は架空で（「読み合いは、卓とは別の小さな勝負です。札も別のものが出ます」）、勝っても卓の相手の強さが一言分かるだけ。いま卓で賭かっている手と関係がないので、勝っても負けても気持ちが動かない。これが「何のためにやるのか分からない」の根っこでもある。
2. **心理5種のうち3種（探偵・見つめ合い・ガチャ）が「ブラフか強い手か」の同じ問い。** 手触りが違っても、考えることが同じ。
3. **論理4種のうち3種（危険札・アウツ・容疑者）が「棒の比べっこ」で同じ終わり方。** 作業は答えに効かない。
4. **台本が少ない**（異議あり8・容疑者3・危険札5）。何度か遊ぶと同じ話になる。
5. **相手の性格が遊び方を変えるのは一部だけ**（ヴェルベットの演技、ポルカとセリナの崩れやすさ）。

## 大きな方向の案（調査の結果を見て固める）

**読み合いを、いま卓で賭かっている本当の手の勝負にする。**
- 心理：相手の本当の手（state.opponentHand）が、ミミの手に勝っているか（＝本物か、ブラフか）を読む。手がかりは本当の手から作る。読み勝てば、卓での判断にそのまま使える。
- 論理：アウツは本当の残りの札、割に合う線は本当の賭け額とポット、危険な形は本当の場札から出す。
- 効き目：毎回の場面が本当の手で変わるので、台本の少なさが消える。勝つ意味がはっきりする（この手を勝つため）。卓のポーカーそのものがうまくなる。
- 確かめること：読み合いが始まるのは、相手が賭けた時（心理）とフロップ以降（論理）。その時点で本当の手・場札・ポット・賭け額がそろっている（game.js の startReadBattle の呼び出し元で確認）。

## 2. 候補（10案）

書き方：芯＝何を考える遊びか。見込みの点は §3 の表。

### A　おねだり　【おすすめ】
最後の1枚の前に、彼女が欲しい札を声に出す。札がめくれた後、彼女は大きく賭ける。おねだりの札が来ていれば本物、来ていなければはったり。
芯＝**引きが外れた人のはったりを見抜く**（本物のポーカーで一番よくある読み）。

### B　来ないで〜！（A の裏）
最後の1枚の前に、彼女がこわい札を声に出す（「♥だけは来ないで〜！」）。その札が来たら、ミミは持っているふりで賭ける。彼女は降りる。来なければ、賭けても払われる。
芯＝**こわい札が出た時に、役があるふりをする**。A と同じ仕掛けなので、A の先の段として持つ（§4-A の最後）。

### C　ひとつだけ見せたげる
彼女が大きく賭けた後、手札の1枚を表にし、もう1枚は「マークか数字、片方だけ見せたげる♡」。どっちを見れば勝ち負けが決まるかを考える。
芯＝**自分は何に負けるのか**（相手の手の範囲を、負ける手だけに絞る）。

### D　今夜のクセ
勝負が決まった「さっきの3手」の写真に、賭けた時の仕草の印と、開いた手（本物／はったり）が残っている。今の彼女の仕草を見て、払うか降りるか。
芯＝**開いた手と仕草を結びつけて、癖を自分で見つける**（本物の卓での癖の覚え方）。

### E　次の札、賭けよ？（前の H2）
次の1枚の前に、彼女が横の賭けを持ちかける（「次が♥なら200あげる。違ったら100ちょうだい」）。受けるか断るか。

### F　じらし見せ（寝落ちのぞきの手触りを、同意の形に）

採点のわけ（辛い所だけ）：
- **A の「重ならない 6.5」**：目利き（札への反応から読む）と、押し出すふり（最後は払う／降りる）の両方に少し近い。違いは、手がかりが札の**前**に出ること、考えるのが「引きが外れたか」であること、明かしが本物の最後の1枚であること。
- **A の「面白さ 7」**：判断が「来たか・来ないか」だけなので、底が浅い心配がある。8 は付けない。
- **D の「正解 8」**：試作は台本で事実にできるが、本編では「本当に起きた3手の記録」と「仕草を必ず同じ意味で出す AI」が要る。
- **C の「易しさ 6.5」**：「自分は何に負けるか」を頭の中で並べる所が、値付けの読み替えに近い重さになる危険がある。
- **E を落としたわけ**：5人の人柄は一番よく出る（持ちかける賭けが人柄そのもの）。でも「4回に1回の当たりに、何倍なら得か」は割り算で、物差し（計算は画面にさせない・決まり1つ）に入らない。同じ額の賭けに直すと「色を数えるだけ」になり、ポーカーから離れる。**「払う額と勝ち目」は、リーディングではなく卓の助言やチュートリアルで教える方が合う**、と考える。
- **B を上位に入れなかったわけ**：点は高いが、起きている相手のこわがりに付け込んで降ろす形なので、倫理を 7 にした（ポーカーのはったりの範囲。見せ合いっこの「見せないで降ろす」と同じ重さ）。A が当たった後、作者が良いと言えば足す。

## 4. 上位3案

### 4-A　リーディング：おねだり　【1位・おすすめ】

**一言**：「最後の1枚の前に、彼女が欲しい札を声に出す。札がめくれて、彼女がどーんと賭ける。——おねだりは、かなった？」

**筋**：場札4枚の後。彼女の手は、あと1枚で役ができる「待ち」。ほろ酔いで陽気なので、乾杯のついでに願いが声に出る。最後の札がめくれる。かなっていれば、うれしくて大きく賭ける。かなっていなければ、引っこみがつかなくて、大きく賭けてごまかす（はったり）。どちらも、しらふの上手な人もやる打ち方。違うのは、願いが声に出ている所だけ。

**決まり1つ**（画面にいつも1行）：

**正解の決め方**：彼女の本当の手札から計算する。
- おねだりの印＝彼女の待ちを完成させる札（フラッシュ待ちならマーク、ストレート待ちなら数字）。
- 最後の札が印に合う → 役ができた（本物）。合わない → 役なし（はったり）。
- 出すのは、彼女の手が「待ちだけ」（ペアも無い）で、ミミがペアより上を持っている時だけ。だから「はったりには必ず勝つ」が事実になる。
- 最後の札がたまたま彼女の手札とペアになった時は、彼女ははったりをかけない（「あ、これでもいいや♪」）。リーディングは出さず、ふつうの勝負に戻す。

**答え合わせの見せ方**：
- 彼女の2枚がめくれ、待ちの札が場札と1列に寄る。**外れ**なら「♥が4枚で止まった」の絵（5枚目の席が空いて暗い）。**当たり**なら5枚そろって光り、役の名前が押される。
- おねだりの印が、最後の札の上で「○ かなった」「× かなわなかった」に変わる。
- 印は4つ：◎ 見やぶった（外れに払って勝ち）／◎ かわした（当たりに降りた）／✕ だまされた（外れに降りた。「払えば勝っていた」）／✕ つかまった（当たりに払った）。
- 理由は1行。例「おねだりは♥。来たのは♣。フラッシュはできていない」。
- **運は残らない**。決める時には、札は全部出ている。正しく読めば必ず得をする（読みと運がねじれない）。

**何が面白いか**：
1. **本物の最後の1枚が、山場になる**。おねだりを聞いた後のめくりは「来るな、来るな……」と見る。リーディングが卓を止めず、卓の一番いい瞬間に重なる。
2. **目利きの良さを引き継ぐ**。彼女のふるまい（おねだり）が手がかり。印は札の上に残る。答えは彼女の本当の札。「こわく見える札」と「本当にこわい札」を見分ける。
3. **本物の読み**。「引きが外れた人は、はったりが増える」は、卓で一番使う読み。待ちの種類（マーク・並びの両はし・間の1枚・枚数）も一緒に身に付く。
4. **人柄が同じ決まりの上で出る**（上の表）。
5. 当てた時、彼女は手札を見せて笑う。「止まった4枚」の絵は、何度見ても気持ちいい見込み。

**心配な点**（正直に）：
1. **浅い**。判断は「おねだりの札が来たか」。場面の型は6〜7つで、慣れると3秒で決まる。支えは、①本物のめくりの緊張　②印のぼかし方が相手で変わる　③場面5（自分が強くなっても降りる）のような気持ちに逆らう回。**紙の上の見込み：分かりやすさ 9／考える 5.5／飽きにくさ 6**。目利き（8／7／6.5）より考える所は少ない。
2. **出せる手が限られる**。彼女が場札4枚の時に「待ちだけ」で、ミミがペアより上、の時だけ。出せる割合は数えていない（試作の前に数える）。1対戦に1回の見込み。
3. **AI のつなぎ**：この手だけ、最後の札の後の賭けを「来たら賭ける・外れても賭ける」に固定する（1か所）。外れて必ずはったりをかけるので、分かっている人には必ず取られる。彼女にとっては損な癖だが、「ほろ酔いの夜の味」として通す。強すぎれば1対戦1回を守る。
4. **目利きと近い**と作者が感じるかもしれない。その時は 2位の「今夜のクセ」に替える。
5. **やめる線**：6場面を遊んで「札を見くらべるだけ。めくりもどきどきしない」なら外す。「場面6・セリナの枚数が分からない」なら、その2人は印をぼかさない。

**倫理の確認**：
- 彼女は起きていて、自分の意思で賭けている。はったりをかけているのは彼女の側。ミミは見抜くだけ。
- 手がかりは、彼女が自分で声に出したこと（リコとヴェルベットは、わざと聞かせている）。盗み見は無い。
- ミミが読みを外せば、彼女がちゃんと勝つ。一方的な取り立てにならない。
- 見破られた後の反応は、笑う・すねる・ほめる。泣かせるのはポルカだけ（泣き上戸で、いつもの範囲）。

**先の段（作者が良いと言えば）：来ないで〜！**
おねだりの裏。彼女が役を持っている時は、こわい札を声に出す（印に ✕ が付く。「♥だけは来ないで〜！」）。その札が来たら、ミミは役が無くても賭ける → 彼女はこわがって降り、札を見せる（「ツーペアだったのに〜！ ……え、ミミちゃん♥持ってなかったの！？」）。来なければ、賭けても払われる。決めるのは「賭ける／賭けない」。

### 4-D　リーディング：今夜のクセ　【2位】

**一言**：「ほろ酔いの夜は、癖が大きく出る。さっき札が開いた3手の写真に、仕草が写っている。——今の仕草は、本物の時のやつ？ はったりの時のやつ？」

**正解の決め方**：
- 仕草と意味の結びつきは、その夜の始まりに相手ごとに決める（毎晩変わる。覚えて持ち越せない）。AI は、大きく賭ける時に必ずそのとおりの仕草を出す。

  1. 仕草1つ：回す→はったり、回す→はったり、回さない→本物。今：回す → **払う**。

  5. 写真に無い仕草（初めて見る）→ **まだ分からない**。
  6. 写真3枚のうち1枚は別の仕草で、今の仕草の写真は1枚だけ → それでも「同じ仕草は同じ意味」なので、その1枚に従う。

**答え合わせの見せ方**：

**5人の違い**（決まりは同じ。仕草が人柄）

1. **癖を教わるのではなく、自分で見つける**。今までのリーディングは、決まり（印の意味）を先に教えていた。これは「同じ仕草は同じ意味」だけ教えて、中身は写真から見つける。見つけた時の「やっぱり！」が芯。
2. **本物の読みそのもの**。上手な人は、札が開いた時に「あの賭けの時、何をしていたか」を思い出して結びつける。それを写真で見える形にした。
3. **毎晩ちがう**。癖はその夜だけの物なので、覚えて終わりにならない。
4. 仕草の絵は、人柄とお色気の見せ場になる。

**心配な点**：
1. **ドラマが弱い**。写真を見くらべる時間は静か。明かしの「3つそろって活字」で補うが、おねだりの「本物のめくり」ほどの山場は無い。紙の上の見込み：分かりやすさ 7.5／考える 7／飽きにくさ 7。
2. **本編のつなぎが重い**。①札が開いた手の記録　②AI が大きく賭ける時に仕草を必ず出す　③仕草の見せ方（印だけなら今ある絵で作れる。絵で見せるなら、仕草の差分が1人2枚要る）。写真が3枚たまらない短い対戦では出ない。
3. **写真3枚は小さくなる**。844×390 で1枚 150×100 ほど。印と王冠が一目で読めるかは、作って測る。
4. 最後は「払う／降りる」で、押し出すふりと出口が同じ。入口（写真から見つける）は違う。

**倫理の確認**：

- 彼女は起きていて、自分で賭けている。癖を読むのは、ポーカーの正しい遊び方。
- 酔いは「癖が大きく出る」だけに使う。判断を奪う筋は無い。3案の中で一番きれい。

## 5. おすすめと、進め方

**いちばんのおすすめ：A「おねだり」。**
- 物差しに一番きれいに入る（見る物3つ・決まり1つ・2択・12〜15秒・印は札の絵）。
- 山場が、卓の本物の最後の1枚に重なる。卓を止めない。

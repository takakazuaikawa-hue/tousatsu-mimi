1．未決事項の決定

- 長針によるCTA指示は外す。時計の針として背景内に収め、横スマホで配置を変えても導線が破綻しない構成にする。
- クリーム色の劇場券は廃止。Bの緞帳付きグラーノ額と真鍮半券に集約し、右側の白い面積と情報の重複を減らす。
- 金は細い縁・接合部・主ボタンに集中。時計の逆光は琥珀色へ抑え、黒檀と深紅の広い暗面でリコの顔と主操作を際立たせる。
- 英文の格言・筆記体・疑似英文は削除。日本語の操作名と進行用のローマ数字で、読める情報を残す。
- 左列はPC幅220px、彫刻は四隅に限定。人物入り2枚を維持し、残り3枚は浅い浮彫で軽くする。
- 台帳は④の5人をI〜V順に厳守。I〜IIIは勝利の封蝋、IVは今夜の栞、Vは暗い肖像と錠前。顔を封蝋で隠さない。
- 横スマホは専用再配置。844×390で左176×44pxを5段、右幅220px・CTA高さ52px。文字11px以上、操作44px角以上。台詞と紹介を省き、5枚の札と報酬を残す。

3．他方の統合案に予想する弱点

長針の誘導を残す案は、時計とボタンの位置関係に拘束される。横スマホで右額を縮めると針先が文字に侵入し、構図の魅力が操作の邪魔になりやすい。

# 読み合い11種類の中身（骨組みより先に決める）

2026-10-21。clarity-rules.md の「遊びの4点」と「選ぶ所」の決まりを、11種類それぞれに当てた。
この中身が全部入る形として、共通の骨組み（最後の章）を決める。仕組みを変える所は【変更】と書く。

## 0. 全種類に共通の決めごと

| 項目 | 中身 |
|---|---|
| 相手の癖（心理） | 相手ごとのブラフの多さを、全部の心理バトルで同じにする【変更】。ポルカ 65%・ヴェルベット 45%・グラーノ 50%・セリナ 25%。画面では「○○の大きな賭け 20回」の点（赤＝ブラフ、金＝本物）で見せる |
| 判断の道具（心理） | **天秤**1つ。左の皿＝ブラフ（ミミの勝ち）、右の皿＝強い手（ミミの負け）。最初に「記録」の重りが乗り、手がかりが出るたびに重りが乗る。重りの大きさ＝その手がかりの確かさ。傾きと「ブラフ ○%」で見せる |

## 1. 手がかり探偵（ポルカ・セリナ）

| | 中身 |
|---|---|
| 目的 | 相手の伏せ札が「ブラフ」か「強い手」かを当てる。当てるとコイン |
| やり方 | 手がかりの札をめくり、それぞれを天秤のどちらかの皿に載せる（関係なければ載せない）。「ミミの勘」は必ず当たる手がかりを1つ出す |
| 危なさ | 手がかりを逆の皿に載せると、天秤が間違った方へ傾く。ミミの勘を使うと、ご褒美が20減る【変更】 |
| 決める所と見る物 | ①手がかりをどちらに載せるか → 手がかりの文（汗・目が泳ぐ＝ブラフ、落ち着いている＝強い手）／②ミミの勘を使うか → 天秤の傾き（もう大きく傾いていれば要らない）／③ブラフか強い手か → 天秤／④賭け → 天秤の％ |
| 【変更】 | 「賭け額」の手がかり（いつも同じ文で意味がない）をやめ、「記録」の重りにする。天秤の重りは確かさで重さが変わる（今は数え引き）。各手がかりに確かさ◆ |

## 2. 見つめ合い（ポルカ・セリナ・ヴェルベット）

| | 中身 |
|---|---|
| 目的 | 同上（伏せ札がブラフか強い手かを当てる） |
| やり方 | 見つめるたびに相手が動揺して、手がかりが1つ出る（最大3つ）。出るたびにご褒美も増える（20→30→40→50） |
| 危なさ | 見つめるたびにミミも緊張する。ミミが先に目をそらすと見つめ合いは終わり、ご褒美は半分 |
| 決める所と見る物 | ①もう一度見つめるか、やめるか → ボタンの金と赤の印（10回のうち、こらえる回数）と、押した時に増える・減る額／②ブラフか強い手か → 天秤／③賭け → 天秤の％ |
| 【変更】 | 長押しをやめ、1回ずつ選ぶ。こらえる回数は相手ごとに決める（ポルカ 9・8・7、ヴェルベット 9・7・4、セリナ 8・5・3）。試算で、金が5つ以上なら見つめる方が得（分かれ目はこらえる率 0.35〜0.5）。ポルカは最後まで、ヴェルベットとセリナは2つで止めるのが得 |

## 3. ダウト！（ポルカ）

| | 中身 |
|---|---|
| 目的 | ポルカのおしゃべり5つを「本音」か「ウソ」か見分け、4つ以上当てる。最後の1つは今の賭けの話（ウソならブラフ） |
| やり方 | 1つずつ出るおしゃべりに、時間内に「本音」か「ウソ」を押す |
| 危なさ | 時間切れは外れ。決まりに合わない「例外」が1つまじることがある |
| 決める所と見る物 | ①本音かウソか → 言い方（！が多い・語尾がのびる＝ウソ、短い・……＝本音）。決まりの札をずっと出しておく／②賭け → 迷った数 |
| 【変更】 | 勝ちの条件（4つ以上）を最初の絵札に出す。例外は「多くても1つ」と書く |

## 4. 心の声ガチャ（ポルカ・セリナ・グラーノ・ヴェルベット）

|---|---|

| やり方 | ぱにゅを10使うと、相手の心の声が1つ聞ける（最大3回）。声には当たりやすさがある（N ◆／R ◆◆／SR・SSR は札が見えて確実） |

## 5. 異議あり！（ヴェルベット）— 2026-10-23 本当の手の版に作り替え済み

| | 中身 |
|---|---|
| 目的 | ヴェルベットの伏せ札が本物（ミミより強い）かブラフ（ミミの方が強い）かを読む。答え合わせはこの手の決着の後 |
| やり方 | ヴェルベットが自分の手について3つ言う。ウソは1つ。ウソの発言と、それと食い違う証拠を1組選んで突きつける |
| 危なさ | 外すたびに信用が1つ減り、ご褒美が減る（40→35→30）。3回外すと、記録だけで読む（15） |
| 決める所と見る物 | ①どの発言とどの証拠か → 発言の札・マーク・通りと、証拠（卓の記録・ミミの手札・目撃か仕草）を見比べる／②本物かブラフか → ウソの向き（強がりのウソ＝ブラフ／弱いふりのウソ＝本物）と天秤（記録＋ウソの重り◆◆◆）／③賭け → 天秤の％ |

作り方（battles/games/objection.js の build）：台本をやめ、卓の本当の手から毎回作る。
- ウソ：ブラフなら持っていない物を「持ってる」と強がる（ミミの手札にある札・場札にある札・2枚とも同じマーク・フロップからずっと大きく賭けた・この札で手ができた）。本物なら持っている物を「持ってない」と弱いふり（決め手の数字・フラッシュのマーク・手を上げた場札は関係ない・フロップは関係ない・配られた札は最悪・一番大きい札）。
- 証拠は3つ：卓の記録（通りごとの場札と、ヴェルベットのその通りの一番強い動き。game.js の state.handActs）、ミミの手札、目撃か仕草（決め手でない時は意味のない仕草）。
- 本当の発言2つ：本当の手のとおりの文（持っていない数字・その通りの賭け方・手が変わらなかった場札・マークの枚数）。ウソと同じ話題（数字・マーク・札・通り）は避ける。
- 点検：架空の手を何千回も配り、ウソが1つ・ウソの中身が本当の手と食い違う・本当の発言が本当、を機械で確かめる（不具合0）。

## 6＋7. 役くらべ（役づくり＋ハイ＆ローをまとめる。2026-10-27 ユーザー決定「まとめる」）

本当の手の論理バトル。ポルカ・グラーノの論理の枠で、役づくりとハイ＆ローの代わりに出す。

| | 中身 |
|---|---|
| 目的 | 相手の賭けに付いていくのが割に合うかを決める。決着の後に、付いていく／降りるの判断が正しかったか答え合わせ。当たればコイン |
| やり方 | ①卓のミミの札（手札2枚＋いまの場札）から一番強い5枚を選ぶ（場札が5枚ない時は、いまある札で一番強い組）。②相手の賭け方に合う手の候補5つを1つずつめくり、「ミミの勝ち／引き分け／ミミの負け」を選ぶ。比べ終えると、勝つ見込みの棒ができる（5つのうち勝てる数＝10個の印のうち2個ずつ） |
| 危なさ | 比べ違えたら、その場で×と正しい答えを見せ、棒は正しい方で作る（見えない失敗はしない）。代わりに、続けて正しく比べるほど上がるご褒美（20→40→80→160→320）がそこで止まる |
| 決める所と見る物 | ①どの5枚か → 役の強さ順の表と今の5枚の役名／②どちらが勝つか → 2人の役名と、同じ役なら比べる札（キッカー）／③付いていくか降りるか → 2本の棒（勝つ見込みと、割に合う線）／④自信 → 棒の差 |
| 楽しさ | 比べる5つを「一見強そうで負ける」「同じ役のキッカー勝負」が半分以上になるように選ぶ（ハイ＆ローの出題の型を引き継ぐ）。正しく続けるほど倍になる緊張（ハイ＆ローのダブルアップ） |
| 候補の作り方 | 相手の性格の賭け方（強い時に大きく賭ける／ブラフでも大きく賭ける）に合う手を、残りの札から引く。本当の手は入るとは限らない（入れると答えが漏れる） |

## 12. ここから決まる骨組み

全種類が画面に出す物は、次の4つに分かれる。

| 置き場所 | 中身 | 全種類で一番多い時 |
|---|---|---|
| 上 | 手順と今やることの1行 | 1行 |
| 真ん中・左（遊び） | 顔の窓・おしゃべり・発言と証拠・7枚の札・グラフ・残りの札・容疑者 | 種類ごとに違う。一番大きいのはアウツの残りの札と容疑者のタイル |
| 真ん中・右（材料） | 状況（場札・手札）＋判断の道具（天秤か2本の棒）＋記録・手がかりの一覧 | 心理：状況・天秤・手がかり3〜4行。論理：状況・2本の棒・見本 |
| 下（押す所） | 2〜3個のボタンか、賭けのチップ3つ | ボタン3個（ハイ＆ローの三択） |

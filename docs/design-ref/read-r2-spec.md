## 1. 面白さ

**1行：「わたしより弱くて、それでも払ってくれる品はどれ？――欲張れば逃げられ、安くすれば買いたたかれる。グラーノの財布のひもを、口ぐせと札から読む」**

| | 中身 |
|---|---|
| **迷う** | 大きい山を押したい。でも彼女の品が「小さい品」なら、高い値は全部ただの空振り。さっき「安いものですな」と言ったのは本当にまだ上があるのか。最後にめくれた札で、彼女の品は値上がりしたのか、値崩れしたのか。**そもそも、値を付けていい場面か**（払ってくれるのは、ミミより強い品だけかもしれない） |
| **明かし** | 値を出すと、グラーノがルーペでチップを値踏みする2秒。山の後ろを**金の線（彼女の上限）**がせり上がる。自分の山まで届くか。届けば「むう……ぎりぎりですな」とチップが入る。届かなければ「惜しい。あと少し安ければ」。線がずっと上まで行ったら「安いものですな。喜んで」――取りこぼした、と一目で分かる |
| **上達** | ①口ぐせの意味が分かる（「安い」＝まだ上がある／「ぎりぎり」＝そこが上限）→ ②最後の札が彼女の品をどう変えたかが見える（値崩れ・外れた待ち・完成した待ち）→ ③自分の手札が相手の手を減らしているのに気づく（ミミが A を2枚持っていれば、彼女の A は少ない）→ ④値を付けない勇気。稼ぎの合計が、目に見えて増える（§7 の合計：読む人 +2400／いつも小 +1200／いつも中 +400／いつも大 −300） |

勉強になること：強い手で稼ぐ賭け方（バリューベット）。「弱い手は降り、強い手だけが払う値」を付けない。外れた待ちは何にも払わない。こわい札が出たら相手の払える額は下がる。

## 2. 遊びのしくみ

### 2-1. 隠れている物と、上限の決まり方

**隠れているのは、グラーノの手札2枚だけ。** 上限は手札から決まり、乱数は無い。決める前に1つに決まっている。

**グラーノの値札表**（公開の決まり。クセ帳に載る。試作では最初から全部見られる）

| 彼女の品（手の格） | 中身 | 払う上限 | 出方 |
|---|---|---|---|
| **上物** | ツーペアより上（ツーペア・スリーカード・ストレート・フラッシュ…） | **大**（ポットと同じ額）まで | 大・中には払う。**小には「買い増し」**（倍にして中の額にしてくる）。こちらが見送ると、**自分からポットの半分を賭けてくる** |
| **良い品** | 場の一番上の札とのペア。または、それより上のポケットペア | **中**（ポットの3分の2）まで | 中・小には払う。大には降りる |
| **小さい品** | それより下のペア | **小**（ポットの3分の1）まで | 小には払う。中・大には降りる |
| **空箱** | ペアなし | 払わない | どの値でも降りる |

途中の札（フロップ・ターン）での追加の決まり：
- **待ち**（あと1枚でフラッシュかストレート。当たり札が8枚以上）は、**中まで払う**（「未来の可能性を買う」）。最後の札で外れたら、ただの空箱になる。
- 上物を持っていても、途中では黙って払うだけ（罠を張る性格）。**自分から賭けてきたら、必ず上物**（今ある決まり「グラーノが賭けてきた時は本物」と同じ）。

**払う時の口ぐせ**（グラーノは値踏みが口に出る。これが一番の手がかり）
- 「安いものですな」＝上限は、今の値より上。
- 「……ぎりぎりですな」＝上限は、ちょうど今の値。

値の大きさ：小＝ポット÷3、中＝ポット×2÷3、大＝ポット。試作のポットは 600・900・1200 だけ使う（割り切れる）。
本編の卓の賭けは細かい額になるので、つなぐ時は「ポットの4割まで＝小、8割まで＝中、それより上＝大」と読む。

グラーノは**自分の品の格だけ**を見て値を決める（ミミの手は考えない）。これが商人グラーノの弱点で、付け込む所。

### 2-2. プレイヤーが知れる根拠と、知らないまま引き受ける危険

Codex の「上限を読む材料が無ければ当てずっぽう」への答え。**画面に出ている物だけで、彼女の品の格は1つか2つに絞れる。** 残った2つのどちらかは分からない。そこは危険として引き受ける、と画面でも分ける。

| 知れる根拠（決める前に画面に出る） | 何が分かるか |
|---|---|
| ① **賭けの跡**（フロップ・ターンで、ミミのどの値に払ったか／彼女が自分から賭けたか） | その時の上限が、その値より下ではなかった |
| ② **払う時の一言**（安い／ぎりぎり） | その時の上限が、値より上か、ちょうどか |
| ③ **最後の札（リバー）と場札** | 彼女の品が値上がりしたか・値崩れしたか・待ちが外れたか・完成したか |
| ④ **ミミの手札** | ミミが持っている札は彼女は持てない。ミミがどの格に勝ち、どの格に負けるか |
| ⑤ 値札表（クセ帳） | 格 → 上限 → 出方 |

| 知らないまま引き受ける危険 | 画面での扱い |
|---|---|
| 同じ跡を残す品が2種類ある時、どちらか（例：「中にぎりぎり」は、良い品か、待ち） | 明かしで「同じ跡を残す手は2種類あった」と並べて見せる。外れても責めない |
| 最後の札で、小さい品が上物に化けた（例：手札の 2 のペアが、リバーの 2 でスリーカード） | 買い増しで分かる。受けるか降りるかは自分で決められる |
| 上物の中で、ミミより上か下か | 見せ合いの札 |

**採点の決まり**：◎×の判子は押さない。「ぴったり賞」も出さない。出るのは ①本物のチップの増減 ②グラーノが自分で言う上限（金の線と台詞）③彼女の札（見せ合いになった時）と品の名前、の事実だけ。「取りこぼし 200」は、線と山の差として見えるだけにする。

### 2-3. グラーノの反応（値段でどう変わるか）

値と上限の差で、出方・顔・台詞・間（ま）が変わる。**反応そのものが、次の回の手がかりの言葉を教える**（明かしで聞いた「安い」「ぎりぎり」が、次の場面の跡に出る）。

| 付けた値と上限 | 出方 | 顔（今ある絵の候補） | 台詞（案。文言は作者が選ぶ） | 間 |
|---|---|---|---|---|
| 上物に、小 | **買い増し**（倍にして中の額に） | grano_offer | 「おや、お安い！　では倍、買い増しましょう」 | 即 |
| 上限より下 | 払う（即） | grano_recommend／shop_smile | 「安いものですな。喜んで」→ 後で「あと200は出せましたぞ、お嬢さん」 | 0.5秒 |
| ちょうど上限 | 払う（しぶしぶ） | grano_cutin_haggle → default | 「むう……ぎりぎりですな。……買いましょう」 | 2秒ためる |
| 上限の1つ上 | 降りる | grano_concerned／shop_trouble | 「惜しい。あと少し安ければ、買いましたのに」 | 1.5秒 |
| 上限の2つ以上上・空箱 | 降りる（即） | grano_cutin_smug | 「はっはっは、ご冗談を」／空箱「これは値の付かぬ品でしてな」 | 即 |
| 見送り × 上物 | **自分から賭ける**（ポットの半分） | grano_offer | 「では私から。本物の品ですぞ」 | 1秒 |
| 見送り × それ以外 | 見送る → 見せ合い | grano_default | 「では、見せ合いといきましょう」 | 即 |
| 見せ合いで負けた | — | grano_cutin_panic／grano_bow | 「これは一本取られましたな……」 | — |

買い増し・彼女の賭けの後は、ミミが「受ける／降りる」を自分で押す（卓の払う・降りると同じ物）。**グラーノの買い増しと賭けは上物だけ**なので、ミミの手が上物に勝てるかどうかで決められる。

### 2-4. チップへの返り方

- 付けた値は、そのまま卓の賭けになる。払われれば見せ合い。勝てばポット＋払わせた額がミミへ。負ければ付けた額を失う。
- 降りられたら、ポットはミミの物（増えない）。
- 特別なコイン・コンボ・倍率は付けない。**もうけは卓のチップだけ。**
- 試作の画面の「値付けで増えた分」＝「ただ見せ合った時」と比べた差（§6 の表の数字）。

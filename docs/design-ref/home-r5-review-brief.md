実装したこと（home-r5-fable.md / home-r5-astra.md の合わせ）
- 勝ち数（--stage 0〜5）で劇場が育つ：0勝は客席の燭台まわりに暗がり、勝つたびに内から外へ灯りが入る。文字盤の数字 I〜V の区画は、まだ勝っていない分だけ琥珀色の影に沈み、勝つごとに一区画ずつ明るくなる。0勝で 1.04 倍、5勝で 1.00 倍とわずかに視野が開く。
- 勝った直後の一度だけの「開幕の儀」：入場が終わってから、長針の先が光り数字が灯る → 台帳に封蝋が押される → 灯りが入る → 額が鎖で引き上がり次の相手が降りて揺れて止まる → 札が跳ねる → リコの一言。押せば即座に終わる。
- 常に動く物：燭台の暖色の揺らぎ（10か所、スマホ6）、逆光の中を昇る金粉（2層）、19秒ごとに札の列へ上から順に同じ風、額は遅れて応える。額・名札・台帳・八角金具のどれか一つに3.3秒ごと金の反射。逆光の呼吸 11秒。卓札の6秒ごとの跳ねはやめて、儀式の時だけに。
- 案内札3つ（交換所・コレクション・リコの教室）と右上4つの線画アイコンを、ChatGPT で描いた金の浮き彫り（天秤・リボンで束ねた絵札・本と角帽・劇場の扉・贈り物の箱・ウサギの金貨・赤石の歯車）に差し替え。

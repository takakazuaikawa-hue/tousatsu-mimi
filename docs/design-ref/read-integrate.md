## 3. 本物の札で、遊びの決まりを当てる

### 3-1. 目利き
- 印：read-simple-fable §5-3 の計算。相手の手札2枚＋そこまでの場札の役が上がり、しかも場札だけの役より上になった場札に印。
- 出さない：手の中のペア、場札だけの役が相手の役以上、見立ての外れ2つが作れない。
- 見立て：本当の役＋「印か場札と食い違う役」2つを自動で作る（候補：役なし、場札の各数字のペア、その場で作れないフラッシュ・ストレート、ツーペア）。
- 相手ごとの決まり（1人に1つ。お手本の4点の札の「見る物」もこれに替える）：
  - グラノ：役ができた札を、ルーペでのぞく（試作のまま）。
  - セリナ：めがねを直すのは、**最後に役が上がった1回だけ**。見立ての外れは「最後の印と食い違う物」から作る。
  - ヴェルベット：本物の印は小さく、**1つだけ大げさな演技の印**（「まあ♡」と身を乗り出す）を、役の上がらない札に付ける。決まりの1行「大げさな方は、演技」。見立ての外れの1つは演技の印に合う手にする。
- 当たりのご褒美：相手の手札2枚を、この手の間、卓で表にしておく（state.rdOpen = { hand, cards:[0,1] }。卓の相手の札の描画で表にする）。

### 3-2. 異議あり（ポルカ）
言い分は、本当の手から順に決める。作れないなら出さない。
1. 本当にフラッシュ・ストレート・フルハウス → その役（「作れる」が正解）。
2. ブラフ（intent が bluff 系）で、あと1枚で届かなかったフラッシュ（同じマーク4枚）・ストレート（4つ続き）がある → その役。
3. ツーペア → フルハウスに盛る。
4. それ以外は出さない。
- 正解：その役が、場札で「作れる」か（read-s2-spec §2 の数え方。作れる＝場札以外の2枚組のどれかで、ちょうどその役ができる）。
- 明かしの台詞は試作のまま。「作れる」が正しかった時は「○ 正しく見た（ウソとは言えない）」＋「でしょ〜？ ちゃんと作れるもん♪／だから、降りたほうがいいってば〜」。
- 盛っていたのに見逃した時の「ぷぷっ、盛っちゃった♪」は、手の後の答え合わせで見せる。

### 3-3. 押し出すふり
- 顔の材料は卓の事実：賭けの intent が bluff 系 → はったりの反応、value → 本物の反応。
- 出さない（ボタンを光らせない）：本物なのに役がペアより下、場札だけで相手の役ができている、相手の役が手札2枚だけでできていて場札を1枚も使わない（ポルカ以外は光る場札が無くなるため）。
- 決まり（画面の1行）は相手で替える：
  - ポルカ：「あわてたら、はったり。にやけたら、本物——口がすべって、役を言う」（試作のまま）。
  - グラノ・セリナ・ヴェルベット：「**光った場札が、彼女の役。何も光らなければ、はったり**」。役の名前は言わない。光るのは、相手の役に使う場札。ミミはそれを見て、自分の役とくらべる。
- 3人の崩れ方（おバカにしない。崩れは小さい）：

| 相手 | 本物の時 | はったりの時 |
|---|---|---|
| グラノ | 商人の顔になる。目がその場札へ行き、指でとん、とたたく（光る）。「おや、お買い上げで？|良い品ですぞ」 | 値段の話でごまかす。どの場札も見ない。「……お支払いは、|よくお考えなされ」 |
| セリナ | 黙ったまま、めがねの奥の目がその場札へ流れる（光る）。「……どうぞ。払うなら」 | めがねを直して、ミミのチップだけを見る。「……本気？」 |
| ヴェルベット | 大げさにこわがる芝居（「やだ、払うの？|こわぁい♡」）。でも目はその場札へ（光る） | 落ち着いて笑うだけ。「どうぞ？」。何も光らない。顔の芝居は、どちらも手がかりにならない（決まりの1行どおり、見るのは場札） |

- 明かしは試作の6通りの形を、各人の台詞に置き換える（勝ち・負け・降りた後に自分から開くのはポルカだけ。ほかの3人は、降りられたら札を伏せたまま「……賢明ですな」等）。

### 3-4. おねだり
- 条件と計算は qa/onedari/engine.js と check.js（待ちの種類が1つ、ミミがペア以上、だぶり無し）。
- AI のつなぎ：おねだりが出た手は、リバーの相手の行動を「ポットの3分の2を賭ける」に固定（state.rdOnedari = handNo）。intent は来たら value、外れたら bluff。
- 流れ：ターンの賭けが済む → 「言う」の画面（相手の台詞と印）→ 卓に戻って本物のリバーがめくれる（卓のめくりのまま）→ 相手が賭ける → 「払う？降りる？」の画面 → 卓のコール／フォールド → 手の後に答え合わせ（待ちの5枚の列）。

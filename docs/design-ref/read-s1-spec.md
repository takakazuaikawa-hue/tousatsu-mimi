## 1. 筋：なぜ・いつ本編の卓で起きるか

**卓の場面**：場札5枚が全部出た後。ポルカが大きく賭けた（ポットと同じくらい）。次はミミの番。

**ポルカの側**（game.js の本当の打ち方と合っている）：
- ポルカは「弱い時ほど声が大きい、調子乗りの初心者客」。大きく賭けるのは、**何もない時（はったり）**か、**すごくいい役ができた時**。中くらいの役の時は小さく賭ける。だから「大きく賭けた瞬間」は、はったりか本物か、賭け額だけでは分からない。ここが使いどころ。
- ポルカは最近「顔に出てるよ」と言われて、ポーカーフェイスを覚えたて。賭けた後は、口を結んで、必死にすまし顔をしている（それがもう顔に出ている）。
- でも、全部顔に出る子。ミミのチップが本当にこっちへ来そうになると、がまんが切れる。
  - はったりの時：「えっ、は、払うの……！？」とあわてる。
  - 本物の時：うれしくてにやける。調子に乗って「払って払って♪ だってストレートだもん！」と言ってしまい、「……あっ」と口をおさえる。

**ミミの側**：本物のポーカーにもある探り。払うふりでチップに手をかけて、相手の反応を見る。リコ先輩に教わった小技で、「ふりは1対戦に3回まで。やりすぎは行儀が悪いよ」と言われている。

**異議ありとの住み分け**：どちらも「ポルカが大きく賭けた瞬間」。異議ありは、**ポルカから**言ってくる（ミミを降ろそうとして役を言い張る。ウソかもしれない）。押し出すふりは、**ミミから**仕掛ける（ポルカが思わず漏らす。素なので本当）。同じ手で両方は出さない。

## 3. 決まり1つ

画面にいつも1行で出す：

> **あわてたら、はったり。にやけたら、本物——口がすべって、役を言う。**

- **あわてる**＝払われたら負ける手で賭けている（試作の場面では、役なし）。
- **にやける**＝払ってほしい手で賭けている。言う役の名前は、彼女の**本当の役**（うれしくて漏らすので、ウソはつかない。ウソをつくのは異議ありの方）。
- 顔が変わるのは、チップが金の線の近くまで来た時。乱数は無い。はったりか本物か、何の役かは、賭けた時にもう決まっている。
- 決まりが教えるのは「彼女の事実」まで。**払うか降りるかは、自分の役とくらべて決める**（ここが考える所。決まりには入れない）。
  - あわてた → ミミに何か役があれば、払って勝ち。
  - にやけた → 言った役と、ミミの役をくらべる。ミミが上なら払う。下なら降りる。

絵の印（文でなく絵で見せる）：
- 顔の横に、あわてた時は汗の印と小さな札「あわてた」。
- にやけた時は、彼女の伏せ札の下に役の札「ポルカ：ストレート」。その役に使っている場札（例：9・8・7）が金に光る。
- ミミの手札の下には、いつも役の札「ミミ：スリーカード」。
- 手引きの段（場面1・2）だけ、口がすべった後に**役のはしご**（小さな縦の絵。ペア・ツーペア・スリーカード・ストレート・フラッシュ・フルハウス）が出て、ポルカとミミの印が付く。ひとりの段では、明かしの時だけ出る。

**正直な所（顔の対応表にならないか）**：顔が全部を教える形（あわてたら払う・にやけたら降りる）を紙の上で何通りも組んでみたが、どれも「顔を読んだら答えが1つ」になった。上乗せを足しても「あわてる所まで押して上乗せ」がいつも得になるだけだった。顔だけで終わらせない方法は、顔が教える事実を**札とくらべる**一段を残すことだった。その一段は「役の上下」で、見せ合いっこ（自分の札が場札とどうつながるか）より易しい。

### 4-2. 押し出しの決まり（指の操作）

- チップの山を、指で左（ポルカのほう）へ引きずる。山は指についてくる。離すと、その場に止まる。
- 道は3つに分かれている（線は引かない。顔で分かる）：
  - **遠い**（道の右から4割まで）：すまし顔のまま。
  - **途中**（4割〜7割5分）：出はじめ。すまし顔のまま、汗の印が1つ（はったり）か、音符の印が1つ（本物）。台詞は無し。
  - **近い**（7割5分〜金の線）：はっきり崩れる。あわてる／にやけて口がすべる。
- **山は金の線で止まる。越えられない**（ふりなので。押しまちがいで払ってしまうことが無い）。
- 引きもどすと、顔はすまし顔に戻る（「……すんっ」）。「あわてた」の印と、口がすべった役の札は**残る**。何度押しても同じ反応（乱数なし）。
- 「払う」「降りる」は、一度「近い」まで押すと光る（試作では、ふりを必ず1回やる。本編では、ふりを使った時だけこの画面に来る）。光ってから0.4秒は押せない。
- 指で引きずれない時のために、山を軽く押すと1段ずつ進む（遠い → 途中 → 近い）。検査の台本もこれで動かす。

## 6. 本編に入れる時の決まり

1. **自分で使う道具にする。** 卓の「払う／降りる」の横に「ふり（のこり3）」を置く。1対戦に3回まで（リコ「やりすぎは行儀が悪いよ」）。使わなくてもよい。
2. **出せる時**：一周目のポルカ戦。場札5枚が出た後、ポルカが大きく賭けて（ポットの3分の2以上）、ミミの番の時だけボタンが光る。途中の札（引き目がある）では出さない（「あと1枚で化ける手」は、あわてるでも にやけるでもないので）。
3. **顔と口は、卓の本当の事実から出す。** ポルカの賭けの「つもり」がはったり → あわてる。本物（値打ちで賭けた）→ にやける。口がすべる役は、彼女の本当の役の種類。乱数を引かない。
   - 本物なのに役がペアより下（A の高い札だけ、など）の時、場札だけで彼女の役ができている時は、ふりのボタンを光らせない（口がすべる役が事実にならないので）。
4. **決めた後は、そのまま卓の勝負。** 「払う」「降りる」は本当の操作。上乗せしたい人のために、小さく「卓にもどって決める」も置く（顔と、口がすべった役の札は、卓に持ち帰る）。判子は、卓の勝ち負けに任せる（「読みは合っていたが負け」は起きない。払った結果がそのまま出る）。
5. **同じ種類の役どうしの時**（ポルカ「フラッシュだもん！」・ミミもフラッシュ）：顔と役の名前までは分かるが、どっちが上かは分からない。ここは判子を押さず、ふつうの勝負に任せる（試作の6場面には入れていない）。
6. **使いどころ（Codex の「場ごとに変わるか」への答え）**：ふりが効くのは、**自分の手が「はったりには勝つが、役には負けるかもしれない」時**。自分の手がこの場でほぼ最強の時は、顔を見るまでもなく払う。3回しか無いので、ポルカが小さく賭けた時（中くらいの役で、はったりは少ない）に使うのはもったいない。——ただし、これが本当に迷いになるかは、6場面の試作では確かめられない（§7）。
7. **どれくらい出るか**（札だけの目安。20万回配って、役なしは36%・ツーペア以上は75%で大きく賭けるとして重みを付けた。賭けの流れは見ていない）：あわてる 20%（払えばミミの勝ち 82%。残りは、ミミも役なしで高い札の負け）／にやける・ミミの役が上 8%／にやける・ミミの役が下 55%／にやける・同じ種類の役 17%（ミミの勝ち 43%）。実際のポルカは、はったりの頻度がもっと高く、ミミも弱い手では最後まで来ないので、あわてる・ミミが上の割合は上がる。無理に半々にはしない。
8. **異議ありと重ねない**：同じ手で、ポルカが役を言い張った時（異議あり）は、ふりのボタンを光らせない。1ハンドに1つ。

10. **声・絵**：新しい絵は要らない。声は、役の名前を言わない短い所だけに付ける（「どーん！」「えっ、は、払うの……！？」「払って払って♪」「……あっ」「うそぉ〜！」「うわぁ〜ん！」）。

## 7. 一番の不安と、やめる線（正直に）

1. **押した後は、役をくらべるだけになる。** 顔と役の名前が出た後の答えは1つに決まる。役の順を知っている人には、3回目から「いじって、くらべて、押す」の手順になる。支えは、①自分の指で顔を崩す手触り ②「にやけたのに払われて大泣き」の落差 ③役の順を覚える勉強（最初の相手なので、覚えたら出番を減らす教材でよい）。**くり返しの面白さは、紙の上では 5／10 の見込み。**
2. **「使いどころが場ごとに変わるか」は、この試作では確かめていない。** 6場面は全部「ふりを使う場面」なので。本当の勝負は、本編で「3回しか無いふりを、どの賭けに使うか」が迷いになるかどうか。試作が当たったら、次はポルカ戦だけにつないで、**使わなかった賭け・使った賭けを記録して**確かめる（使った賭けが「自分の手が中くらい・相手の賭けが大きい」に寄っていれば、使いどころが生きている。毎回1〜3ハンド目で使い切っていれば、生きていない）。
3. **ポルカが役まで言うのは、都合がよすぎないか。** 調子乗りで見せたがり・異議ありでも役を言い張る子なので、筋は通ると見ている。作者が不自然と感じたら、名前は言わせず、**役の場札に目が行く（金に光る）だけ**にする。その分、光った札から役を読む一段が増えて、難しくなる。
4. **にやけた時の顔の変化が、あわてた時より弱いかもしれない。** 賭けた直後を「得意顔」でなく「すまし顔」にしたのは、このため（すまし顔 → にやける、の落差を作る）。絵を当ててみて弱ければ、にやける側は大きいカットインの絵を使う。
5. **指の操作**：引きずる操作は、紙では確かめられない。山が線で止まること・軽く押しても進むこと・押しまちがいで払わないことを、試作で先に見る。
6. **やめる線**：作者が6場面を遊んで「押して顔が変わるのが、3回目でもう楽しくない」なら、この遊びは外す（手触りが芯なので、直しようが無い）。「場面2・5で、なぜ払うのか納得できない」なら、ひとりの段でも役のはしごを出す。「役くらべのクイズだ」と感じたら、3の替え（名前を言わせない）を試す。

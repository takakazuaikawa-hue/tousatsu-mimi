**4．賞金・初優勝特典・繰り返す理由**

大会チップと所持コインは完全に分けます。9,000チップを集めた優勝者に、別途コイン賞金を渡します。

| 順位 | コイン賞金 |
|---|---:|
| 1位 | 1,200 |
| 2位 | 600 |
| 3位 | 300 |
| 4位 | 100 |
| 5位 | 50 |
| 6位 | 0 |

参加無料なので、負けても次の挑戦ができます。途中棄権は賞金なし、中断保存は棄権に含めません。

本編のヴェルベット再戦は基本700コインで、周回による減額があります。大会は長く難しい代わりに、**上表の賞金を周回しても維持**する設計を推します。大会の報酬には本編の評価ボーナスやコイン倍率を重ねず、入場案内に表示した金額をそのまま払います。

初優勝は次の組み合わせです。

- **称号「時を制した者」**。ホームの名札と大会記録に設定できる。
- **既存衣装「ミミ・黄金」**を獲得。所持済みなら代わりに1,500コインを一度だけ付与。
- 優勝日・決勝相手・最後の役を記した大会記録を残す。

「ミミ・黄金」は[交換所の既存商品](/C:/Users/takakazu/projects/mp_panyu/game.js:4984)で、画像 `assets/characters/mimi_gold.webp` も存在します。既に解放済みの本編CGを、新しい賞品のように再配布する必要はありません。

繰り返す理由は、次の三つに絞ります。

1. **安定したコイン獲得**で、交換所の残りを集められる。
2. **毎回変わる席順と決勝相手**で、同じ攻略が通用しにくい。
3. **「5人それぞれに決勝で勝つ」記録**を埋める。全達成で称号「六席の主」。

順位記録には優勝回数・直近10大会・決勝相手別の勝敗を載せます。速さだけを競う実績は、雑なオールインを誘うので優先しません。

**5．本編との違い――五人がそれぞれ勝ちに来る**

難しさは初期チップ差ではなく、**ポジション、残り人数、持ち点差を使う判断**で出します。AIはミミの伏せ札も、ほかのAIの伏せ札も参照しません。

現行の[AI](/C:/Users/takakazu/projects/mp_panyu/game.js:1125)には、よくコールする相手にブラフを減らす仕組みがあります。これを六人分の観測履歴へ広げ、対ミミ専用の判断から、全員を相手にした判断へ変えます。

| 相手 | 大会で感じさせる強さ | 台詞例 |
|---|---|---|
| リコ | 場所によって参加する手を変え、無理な勝負を避ける。好機では薄い利益も取る | 「そこまで払う？　じゃ、付き合おっか」 |
| ポルカ | 攻撃性を残しつつ、後ろに人数がいる時は止まる。後ろの席からブラインドを奪う | 「ボクが騒いでる時だけ、見てたでしょ？」 |
| セリナ | 複数人が残った場では慎重。強い役には取り逃さない額を付ける | 「まだ三人残っています。その勝負には付き合えません」 |
| グラーノ | 賞金が近づくと生存価値を計算する。短い持ち点の相手へ圧をかける | 「その一手、順位まで含めてお得ですかな」 |
| ヴェルベット | 大きな持ち点を使って中位の相手を苦しめる。見せたブラフも次の罠に使う | 「そのチップ、守ってるだけじゃ勝てないの」 |

キャラの癖は残します。ただし「この顔なら必ずブラフ」という一対一対応にはしません。強気の表情が強い手にもブラフにも出る中で、直前の行動や人数と合わせて読む遊びにします。

**11種の読み合いと心理バトルは、正式な大会の進行中には挟まない案を推します。**

現行の[読み合い報酬](/C:/Users/takakazu/projects/mp_panyu/game.js:14405)は、対象1人の実際の手から強弱のヒントを作っています。六人卓で頻繁に発動させると、一局が長くなり、対象を選んで非公開情報を得ることが大会の中心になります。また、参加者のリコがミミに助言を続けるのも不自然です。

11種は本編に残し、大会では**結果画面の「読みを振り返る」から任意の練習へつなぐ**のがよいです。大会中は表情・台詞・ベット履歴で読み合い、決着後に公開された手を使って理解を深めます。公開されなかった他人の手は、振り返りでも勝手に明かしません。

実装は、既存の2人用処理を人数だけ増やす方式では足りません。

大会専用の状態と進行処理を設け、カード描画・役評価・音・表情素材を共有します。[卓のCSS](/C:/Users/takakazu/projects/mp_panyu/style.css:17150)は絶対座標の上書きが多いため、新卓は専用クラスに分けます。スマホも1280×800の一括縮小ではなく、上記の844×390用配置を持たせます。

ルール上は、デッドボタン、ヘッズアップでのボタン＝SB、短いオールイン後の再レイズ権、ポット別の分配を明示的に扱います。ここは通常の大会ルールを基準にします。[Poker TDA公式規則](https://www.pokertda.com/view-poker-tda-rules/)

同時脱落は、この大会の規則として「ハンド開始時の持ち点が多い人を上位、同額なら同順位・該当賞金を均等分配」と定めます。

実装後に必須なのは、三人以上の異額オールイン、フォールドした人の投入額、未コール分返却、同着、同時脱落、3人から2人への移行、中断再開の検証です。**全員の残チップ＋未精算の投入額＝9,000**を常に確認します。所要時間は自動対戦でハンド数分布を測り、スマホ実測で操作時間を足して調整します。

**7．新しい絵は最小限何を描くか／完成予想図の指示**

対戦画面の機能を成立させるだけなら、新規キャラ素材は不要です。既存の顔差分を肖像窓に使い、背景・カード裏・チップ・金飾りを再利用できます。卓の楕円、革縁、陰影はコードで描けます。

**新規を一枚に絞るなら「六人が同じ卓に着席した開幕の一枚絵」**を推します。

ミミが手前、五人が奥と左右。時計塔の裏の劇場、卓、椅子、人物、反射、接地影まで一つの絵として描きます。舞台に切り抜き立ち絵を貼り付けて六人集合を作る方式は避けます。開幕でこの絵を見せてから、対応する六つの肖像窓へ移れば、対戦中のUIにも「同じ卓に座っている」という意味が生まれます。

対戦中の顔は、あくまで**額に収まったUIの肖像**として扱います。部屋の中に実在する身体として貼り込まないので、背景との照明・遠近の不一致を隠す必要がありません。

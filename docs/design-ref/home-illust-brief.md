# ホーム絵 1番「今夜の卓へ」 イラスト設計書（2026-10-15）

## 1. この絵が担う役目
- ホームは「今夜はどの卓で遊ぶか」へ向かう入口。ひと目で **時計台の中のカジノの賭場** と分かり、遊びたくなること。
- 主役はリコ先輩。新人のミミ（＝遊ぶ人）の **面倒見のいい先輩・案内役**。「アタシが叩き込む。安心してかかってきな」の、さばさばした姉御肌。かわいい店員ではなく、**腕の立つ大人のディーラー**。
- 衣装を買うとホームのリコ先輩も替わる仕組みがあるので、1番は **制服（rico_default）** の基本形。

## 2. 画面の割り付け（ホーム v11 の UI に合わせる。1280×800 の舞台）
| 場所 | 載る物 | 絵への注文 |
|---|---|---|
| 左の端 0〜430px | 話数・行き先の一覧（交換所・コレクション・ぱにゅぱにゅ・教室・衣装）、左下に手札の扇 | 暗く静かに。細かい模様や強い光を置かない |
| 中央 430〜900px | リコ先輩（頭から太ももまで） | ここに絵の見せ場を全部集める |
| 右の端 900〜1250px | 先輩のメモ・今夜の卓の札・「卓へ」の金のボタン | 暗く静かに。金のボタンが一番目立つよう、近くに金の強い光を置かない |
| 頭の上 | （何も載らない） | うさ耳の先まで切らずに入れる。大時計が後光になる |

## 3. 舞台
- グランドクロック・カジノシアター：巨大な時計台の中のカジノと劇場。英国バロックの豪華絢爛。
- この絵は **賭場（ゲームフロア）**。深紅のフェルトのポーカー台が灯りの下に奥へ並ぶ。
- 時計台の証拠：賭場の奥の高い壁に、**大時計の文字盤を裏から見た巨大な円窓**（ローマ数字は裏返し、金の歯車がゆっくり噛み合う）。この円窓がリコ先輩の頭の後ろで後光になる。
- 奥に劇場の深紅の幕が少しのぞく（カジノと劇場の両方の館だと分かる程度）。

## 4. キャラデザインの決まり（rico_default から）
- 顔：**切れ長で少し伏せた目、色気と余裕のある目つき**、口角だけ上げた自信のある笑み（歯は少しだけ）。かわいい丸い目にしない。
- 金の長い髪（毛先に軽いウェーブ）、琥珀色の瞳、褐色の肌。
- 赤と黒のうさ耳、黒いリボンと金の飾りの髪飾り、白い襟と赤い蝶ネクタイ。
- 金の縁取りの黒と赤の胴衣、胸元の金の星形の飾り、白いカフスと片手だけの黒い腕輪、ブラウンのタイツ、後ろに垂れる赤と黒の飾り布。

## 5. 構図の候補（ラフで比べる）
- **A 台に寄りかかる**：ポーカー台の縁に腰を預け、片手でカードを1枚つまんでこちらに見せる。目は伏せ気味にこちら。
- **B 振り返って誘う**：奥の空いた卓へ歩きかけて振り返り、肩越しに指2本で「こっち」と招く。
- **C カードを切る**：台の向こうで、両手でカードを扇に広げながら顔を上げてこちらを見る（ディーラーの腕前が伝わる）。

## 6. 品質の基準（自分で見て落とすもの）
- 顔が元絵より甘い・目が丸くかわいい → 落とす
- 舞い散る物・光のごてごてで盛っている → 落とす（品と人物の美しさで見せる）
- 左右の端が明るい・物が多い → 落とす
- うさ耳の先が切れる、指の本数・形の崩れ → 落とす
- 賭場に見えない（劇場の玄関に見える） → 落とす

## 7. 進め方
1. ChatGPT で A・B・C のラフ（白黒の下描き）を作り、構図を決める
2. 決めた構図で清書（元絵・大時計のホール・賭場の3枚を添付）
3. ホーム v11 の画面に載せて、切り方・端の暗さ・光を合わせる（パソコン 1280×800、横向きスマホ 844×390）

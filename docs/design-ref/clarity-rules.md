# 初めての人が分かるための決まり（ゲーム全体）

2026-10-21 作成。見つめ合いの作り直しで、作者から次々に指摘を受けて作った（「〇〇せずに見つめろの〇〇が分からないから、押しっぱなしにする」「①見つめろだけじゃ足りない」「全部私が直すんですか？」）。
読み合い11種類だけでなく、卓・交換所・ホーム・結果画面など、プレイヤーが何かを選ぶ画面すべてに当てる。新しい画面や遊びを作る時も、見せる前に必ずこの決まりで確かめる。

## 1. 遊びの4点（遊びを始める前に、1枚の絵札で見せる）

どの遊びも、次の4つを言葉で言えて、画面に出ていること。言えなければ、仕組みから作り直す（説明を足して埋めない）。

| | 書くこと | 悪い例 | 良い例（見つめ合い） |
|---|---|---|---|
| 1 目的 | 何を当てる／何を目指すのか。うまくいくと何がもらえるのか | 「見つめ合う」 | ポルカの伏せ札が「ブラフ」か「強い手」かを当てる。当てるとコイン |
| 2 やり方 | 何をすると、何が起きるのか | 「長押しで見つめ、離して止める」 | 見つめるとポルカが動揺して、顔や言葉に手がかりが出る（最大3つ） |
| 3 危なさ | 何をすると損をするのか。それはいつ起きそうか、見えるか | 「ミミが先に崩れたら負け」 | 見つめるたびにミミも緊張する。先に目をそらすと終わり、ご褒美は半分 |
| 4 決める所と見る物 | 何を決めるのか。その時に何を見るのか | （書いていない） | 続けるか→金と赤の印／ブラフか→記録と手がかり（天秤）／賭け→天秤の％ |

- 4点の絵札は、その遊びの初回は必ず出す。2回目からは出さず、画面の隅の「ルール」でいつでも開けるようにする。
- 4点は文で書く。表や記号だけにしない。

## 2. 選ぶ所（ボタンが2つ以上ある所すべて）

1. **押すと何が起きるかを、押す前にボタンに書く。** うまくいった時と、だめだった時の両方を書き、増える・減る数も書く（例：「こらえる → 手がかり＋1・ご褒美40／目をそらす → ご褒美15で終わり」）。
2. **運で決まる時は、確率を「10個の印のうち何個」で見せる。** ％の数字だけにはしない。
3. **判断の材料は、見える物1つにまとめる。** 何個もの数字を、頭の中で足したり掛けたりさせない（例：記録と手がかりを天秤1つにまとめる）。
4. **見えない物で失敗させない。** 時間や操作の上手さで決まる遊びは、危なさが目に見えて、自分で避けられること。見えない速さや乱数で失敗させない。
5. **操作で決まるように見せて、実は乱数で決まる、という作りにしない。** そうするなら「運試し」と正直に書く。
6. **どれを選んでも同じ、という選択肢を出さない。** いつも同じ答えが一番得になる選択は、作り直すかなくす（例：前の「読みに賭ける」は、当たる確率が3分の1を超えると、いつも×3が一番得だった）。
7. 書いた言葉どおりに本当に得になるかを、試算で確かめる（2万回ほど回す）。

## 3. 言葉

1. **作った言葉を、説明なしで出さない。** 段・線・帯・見込み・確かさなどは、その場で何のことかが分かるように書く。分からない言葉は使わない。
2. **数字には意味を付ける。** 「出る33・当たる60」のような、何の数か分からない数字は出さない。
3. **今やることの1行は、「何をするか」だけでなく「何のためか」も入れる。**
4. ゲームの普通の言葉で書く。中の名前（stage・prior など）を出さない。

## 4. 結果

- 「何を選んで → 何が起きて → それはなぜか」を1〜2行で書く。運が悪かっただけなのか、選び方がまずかったのかを分ける。

## 5. 見せる前の確かめ（本体が自分でやる）

1. 各画面を撮る（スマホ横 844x390 と PC 1280x800）。
2. **画面の文字だけを見て、4点と、選ぶ所ごとの「押すと何が起きるか」を書き出す。** 頭の中の知識は使わない。書けない所があれば直す。
3. はみ出しは0にする（qa/readaudit.mjs を QA_MEASURE=1 で動かし、舞台の scrollHeight が clientHeight と同じになるまで詰める）。
4. 2と3を直した後で、もう一度撮って書き出す。それでやっと見せる。
5. 見せる時は、4点の文を添える。

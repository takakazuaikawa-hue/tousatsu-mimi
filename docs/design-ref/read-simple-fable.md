# リーディングを易しく作り直す案　2026-11-16・上位モデル

作者の感想：「リーディング、正直難しくて情報量が多くてわからなかった」（値付けの試作 qa/r2proto を遊んで）。
読んだ物：read-ideas-fable.md、read-r2-spec.md、試作の写真（qa/out/r2proto/844x390_*.png）、read-remake-plan.md、clarity-rules.md、Codex の批評（critique-4）。
ブラウザは開いていない。数字は Node で数えた（末尾）。**面白さはまだ確かめていない。紙の上の見込み。**

先に結論：
- 値付けが難しいのは、文字が多いからではなく、**「跡 → その時の上限 → 品の格 → 最後の札で格が変わったか → 今の上限 → 山」という5段の読み替え**を、値札の表を引きながらやらせているから。字を削っても直らない。
- 直し方は「読み替えを1段にする」。**彼女の気持ちを、文ではなく場札の上の印で見せる。**
- おすすめは案B **「リーディング：目利き」**。場札が1枚ずつめくれ、グラーノは自分の役ができた札だけルーペでのぞく。その印を見て、彼女の手を3つから当てる。見る物3つ・決まり1つ・3択。

## 1. なぜ難しく感じたか（診断）

試作の「値を付ける」画面（844x390_s4_pick.png）で数えた。

### 1-1. 覚える事：12個

| # | 覚える事 | どこに書いてあるか |
|---|---|---|
| 1〜4 | 品の格が4つ（上物・良い品・小さい品・空箱）と、それぞれの中身（ツーペアより上／場の一番上の札とのペア、またはそれより上のポケットペア／それより下のペア／ペアなし） | 値札の表 |
| 5〜7 | 格ごとの上限（大・中・小） | 値札の表 |
| 8 | 上物は、小には上乗せし、見送ると自分から賭ける | 値札の表 |
| 9 | 待ちは途中の札では中まで払い、外れたら空箱 | 値札の表の下 |
| 10 | 口ぐせ「安いものですな」＝上限はもっと上 | 値札の表の下 |
| 11 | 口ぐせ「これが精一杯ですな」＝上限はちょうどそこ | 値札の表の下 |
| 12 | 小・中・大＝ポットの3分の1・3分の2・同額 | お手本 |

値札の表（844x390_s1_sheet.png）は、それだけで画面いっぱいの文章になっている。**これを覚えるか、毎回開かないと解けない。**

### 1-2. 同時に見る物：13個

①今やることの1行　②グラーノの台詞の帯　③場札5枚　④ミミの手札2枚　⑤ミミの役の名前　⑥跡の1行目（フロップ）　⑦跡の2行目（ターン）　⑧見送る　⑨小の山　⑩中の山　⑪大の山　⑫ポット　⑬決めるボタン。
さらに隅に、場面の番号・増えた分・お手本・値札・リコに聞く。
しかも⑥⑦は**文**で、中に暗号（口ぐせ）が入っている。場札③も「どの札を見ればいいか」が分からないまま5枚とも見ることになる。

### 1-3. 決める数：1回に最大3つ、頭の中の読み替えは5段

- 押す所：山を選ぶ（4択）→ 決めるボタン → 上乗せされたら 受ける／降りる（2択）。
- 頭の中：
  1. 跡の文を読んで、口ぐせを訳す（「精一杯」＝その時の上限は中）
  2. 上限から、品の格に戻す（中まで＝良い品。または待ち）
  3. 最後の札で格が変わったかを調べる（上の札が出た？ 待ちが外れた？ 化けた？）
  4. 新しい格から、今の上限を出す
  5. その品にミミは勝っているかを調べて、山を選ぶ

### 1-4. 根っこ

| | 根っこ | 何が起きたか |
|---|---|---|
| ア | **間に「品の格」という作った物差しが1枚はさまっている** | 札 → 格 → 値、と2回訳す。格は本物のポーカーにも無い言葉なので、ここでしか使えない |
| イ | **手がかりが文で、しかも暗号** | 口ぐせの意味は表を見ないと分からない。顔を見ても分からない。グラーノの大きな顔は、ただの飾りになっている |
| ウ | **過去の出来事（フロップ・ターンの賭け）を、文で思い出させている** | 自分で遊んでいない手の跡なので、実感がない。「小に払った」が何を意味するかは、賭けの流れを知っている人にしか通じない |
| エ | **答えが「値」で、当たったかどうかが割合** | 一番得な値を付けても、空箱だった・化けた、で負ける回がある（場面5・6）。初めての人には「合っていたのか」が分からない |
| オ | **「最初の1問」が易しくない** | 場面1から、跡2行＋口ぐせ＋場札＋3つの山。いちばん易しい問題でも5段ぜんぶを使う |

字の量は症状で、根っこはア〜ウ。**だから文字を削るのではなく、「訳す段」を1つにし、「文の手がかり」を「絵の印」に替える。**

## 3. 案（3つ）

### 案A　値付け・ひと目版（値付けを直す案）

**1行**：「グラーノの品は、ルーペの印の札のペア。最後の札がめくれた今、高く売れる？ 安くしか売れない？」

- **見る物3つ**：①グラーノの顔　②場札5枚（うち1枚にルーペの印＝彼女がペアにしている札。最後の札は金の縁）　③山2つ「安く」「高く」
- **決まり1つ**：「印の札が、**場でいちばん上の札**なら、高くても払う。ちがえば、安くしか払わない」
- **決める**：2択（安く／高く）
- 無くす物：跡の文・口ぐせの暗号・値札の表・品の格・待ち・上乗せ・見送る・ミミの手札の表示（ミミは勝っている、と最初に言い切る）。
- 残す物：金の線がせり上がる明かし、「惜しい。あと少し安ければ」「安いものですな」の台詞、本物のチップ。

| | |
|---|---|
| 初めての人が10秒で分かる理由 | 見るのは「印の札」と「場でいちばん大きい札」の2枚だけ。同じなら高く、ちがえば安く |
| それでも考える瞬間 | 最後の札で、いちばん上が入れ替わる。「さっきまで K が一番だったのに、A が出た」。逆に、大きい札が出ても印の札より下なら値は崩れない（こわく見えるだけ） |
| 3回目以降 | **正直に言うと弱い。** 考えることは数字の大小くらべで、4回目には手が勝手に動く。2〜3回で卒業する教材。山を3つにして「見送る」を足せば伸びるが、その分だけ決まりが増える（印の札が3枚目の♥なら見送る、など） |

見込み：分かりやすさ 9／考える 4／飽きにくさ 3。**値付けの骨（欲張ると逃げられる）は残るが、読む所が浅い。**

### 案B　リーディング：目利き（おすすめ）

**1行**：「場札が1枚ずつめくれる。グラーノは、自分の役ができた札だけ、ついルーペでのぞいてしまう。——どの札をのぞいた？ じゃあ、彼女の手は3つのどれ？」

- **見る物3つ**：①グラーノの顔（めくりのたびに動く）　②場札5枚と、その下のルーペの印　③見立ての札3枚（例「K のペア」「♥のフラッシュ」「ストレート」）
- **決まり1つ**：「**ルーペの印＝グラーノの役ができた札**」（役の名前が上がった札だけに付く。場札の下に、いつも1行で出しておく）
- **決める**：3択を1回
- 値付けの「跡2行＋口ぐせ」が言っていたこと（彼女は何を持っているか）を、**札の上の印**に置き替えた形。値を付けるのは、卓に戻ってから自分の賭けでやる（当てれば彼女の手札が見えているので、いくら賭けるかは自分で決められる）。

| | |
|---|---|
| 初めての人が10秒で分かる理由 | 「喜んだ札を見て、手を当てる」。人の顔を見て欲しい物を当てるのは、ポーカーを知らなくてもやったことがある遊び。印が札の真下に残るので、覚えておく物も無い。答えは役の名前（もう知っている言葉）だけ |
| それでも考える瞬間 | 3つの見立てを、印と場札で消していく。「K のペアなら、K で喜んだはず → 印は K に無い → ちがう」「♥のフラッシュ？ → ♥は場に3枚ある？」「印が2つ → ペア1つでは説明がつかない」。**印が無い**ことも手がかりになる（3枚目の♥が出たのに無反応 → フラッシュではない） |
| 3回目以降も飽きない理由 | ①型が7つあり、場ごとに変わる（印1つ＝ペア／印なし＝役なし／3枚目のマークに印＝フラッシュ／こわい札に印なし／印2つ＝ツーペア／並びの最後に印＝ストレート／同じ数字に印2つ＝スリーカード）。②答えが彼女の本当の手なので、当てると**手札が開いたまま卓に戻れる**（本物の得）。③相手ごとに決まりを1つ替えられる（下の表）。④慣れて速くなるのは「覚えた」ということ。その時は出る回数を減らし、次の相手の決まりに進む |

相手ごとの1つの決まり（先の話。試作はグラーノだけ）：

| 相手 | 決まり | 難しさ |
|---|---|---|
| ポルカ | 役ができた札で、飛び上がって喜ぶ。全部顔に出る | いちばん易しい |
| グラーノ | 役ができた札を、ルーペでのぞく | 試作 |
| セリナ | めがねを直すのは、**最後に役が上がった1回だけ** | 印が少ないので、消す力が要る |
| ヴェルベット | 印の1つは**わざとらしい演技**（大げさな方がウソ） | 本物の印だけで考える |

見込み：分かりやすさ 8／考える 7／飽きにくさ 6.5。

### 案C　鑑定（売り文句は本物？）

**1行**：「グラーノは、賭けながら売り文句を1つ言う。『これは♥のフラッシュですぞ』。——場札を見て。その役、この場で作れる？」

- **見る物3つ**：①グラーノの顔と、売り文句の値札1枚　②場札5枚　③2択「ニセ物だ！」「あり得る」
- **決まり1つ**：「**場札で作れない役**を言っていたら、ニセ物」
- **決める**：2択
- 異議あり（今の発言3つ＋証拠3つ）を、発言1つ・2択まで削った形。商人の売り文句は盛る物なので、グラーノなら間抜けに見えにくい。

| | |
|---|---|
| 初めての人が10秒で分かる理由 | 「言っていることが、見えている札と合うか」だけ。逆転裁判の一番小さい形 |
| それでも考える瞬間 | フラッシュ＝同じマークが場に3枚あるか数える／ストレート＝場に近い数字が3枚あるか／フルハウス＝場にペアがあるか／「♠の A を持ってますぞ」＝その札が場に出ていないか |
| 3回目以降 | 型は4つほど。覚えると3秒の点検になる。捕まえた時の顔（grano_cutin_busted・grano_bow）は何度見ても気持ちいい |
| 弱い所 | ①半分の回は「あり得る」が正解で、**当てても何も起きない**（卓に戻るだけ）。②「いつも あり得る」と言えば損をしない抜け道がある。③Codex の指摘（言い分が不自然になりやすい・「あり得る」の時に本当かどうかは決まらない）が残る |

見込み：分かりやすさ 9／考える 6／飽きにくさ 5。

- 見立ての札は押すと持ち上がり、「これだ！」で決まる（押しまちがいを防ぐ。2回押し）。
- 「3つのどれか」は本当（必ず1つが彼女の本当の手。残りの2つは、印か場札と必ず食い違う）。
- 当たりのご褒美は、彼女の手札が開いたまま卓に戻ること。コイン・判子・コンボは付けない。
- 外れても損はしない（初めての人を罰しない）。本編では、外した時の答え合わせは勝負が終わった後に見せる（試作では、その場で見せてよい）。
- 時間で急かさない。乱数は無い。

4点の札（初回の最後に1枚。各15px）：
1. 目的：グラーノの伏せた手札を当てる。当てると、手札が開いたまま卓に戻れる。
2. やり方：場札が1枚ずつめくれる。グラーノがルーペでのぞいた札に印が付く。3つの見立てから1つ選ぶ。
3. 危なさ：外れても損はしない。ただ、手札は見えないまま。

## 5. おすすめ：案B「リーディング：目利き」

### 5-1. なぜこれか

1. **値付けの良かった所を捨てていない。** 値付けの芯は「彼女の手を読む → だから強気に出られる」。難しかったのは「読む」の部分が暗号だったこと。目利きは、その「読む」だけを取り出して、絵の印にした。値を付けるのは、手札が見えた状態で卓に戻ってから、自分の賭けでやる（そこが一番気持ちいい所で、もう説明は要らない）。
2. **グラーノの顔が、初めて手がかりになる。** 試作では、顔は飾りで、読むのは文だった。目利きでは、めくりの1枚ごとに顔を見る。主役がキャラに戻る。
3. **答えが事実。** 彼女の本当の手札。めくれば白黒がつく。一番得な値を付けても負ける、という分かりにくい回が無い。
4. **本物の読みの形をしている。** 上手な人は「どの札が出た時に、相手が乗り気になったか」を覚えていて、そこから手を読む。それをそのまま、分かりやすく大げさにした遊び。場の読み方（フラッシュには同じマーク3枚・並びには近い数字3枚）も一緒に身に付く。
5. A は易しいが、考える所が数字の大小くらべで、すぐ手が勝手に動く。C は半分の回で何も起きない。

### 5-2. 一番の不安と、やめる線（正直に）

- **不安1：見立てが3つに絞られているから解ける、という作りである。** たとえば場面3（3枚目の♥に印）は、決まりだけなら「2 のペア」でも同じ印になる（数えると、同じ印になる手 135通りのうち、2 のペアが96・♥のフラッシュが36）。見立ての3枚に「2 のペア」を入れていないので答えは1つに決まるが、ポーカーを知っている人は「2 のペアかも」と思うかもしれない。
  → 画面とお手本で「**3つのどれか**」とはっきり言う（必ず1つが本当）。試して「ずるい」と感じたら、決まりを「役ができた時、**その役に使う場札を全部**のぞく」に替える（フラッシュなら♥3枚に印、ストレートなら並びの3枚に印）。印だけで手が決まるようになる。その分、考える所は減る。

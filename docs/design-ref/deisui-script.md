# 泥酔の夜　会話の文案（第2稿・11/12 ユーザー承認「これでよい」）

第1稿はユーザー「もっと泥酔してないといけませんね」。言葉そのものを崩した。
- ろれつが回らない：さ行が「しゃ・しゅ・しょ」、「ら」が「りゃ」、語尾が伸びる・切れる。
- 話が途中で別の話に飛ぶ。同じ言葉をくり返す。言い間違えて気づかない。
- 奇声・擬音・しゃっくり（ひっく、うぃ〜、うぇへへ、ぷぎゃ、ふにゃにゃ）。
- ミミも泥酔：心の声が全部口から出る。ツッコミも途中でろれつが崩れる。
- それでも「誰が何をしているか」は一言で分かるように、ト書き（かっこの中）を短く添える。

形はほろ酔いの夜と同じ：扉の題字／途中の場面1（序盤）／途中の場面2（終盤）／幕間／締めの一言3種／とんでもない賭けの心の声。

## 6. ミミ自身（全員の卓で）

- ときどき画面がぼやけて「（ミミは泥酔している……！）」。札も相手も見えないまま、降りる・付いていく・賭けるだけが見える。
- 心の声が全部口から出る：途中の場面で毎回。ツッコミもろれつが崩れる。
- うさ耳：ぴくぴく・ばたばた・ぴーん、と気持ちで動く（途中の場面の絵の注文に入れる）。
- うさぎ跳びで帰る：ヴェルベットの幕間の最後。

## 7. 決めてもらう所
1. 崩し方の強さ：このくらいのろれつ・脱線でよいか（もっと／少し戻す）。

3. 声を付けるか（Irodori-TTS、1行4〜9分。全部で約95行）。

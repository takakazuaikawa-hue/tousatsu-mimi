# Home v15 FABLE案：部品を空間に置き、動かす

共通：`.home{perspective:1400px;perspective-origin:50% 40%}`。層は4つ＝奥 scene(z-60・視差±4px)／中 額縁・台帳(z0〜+20)／手前 札群(z+40〜+80)／最前 券(z+120)。視差はポインタ比(-1..1)×深さ係数の translate のみ、追従 `.6s cubic-bezier(.2,.8,.2,1)`。入場は opacity+transform だけで0.9秒完結。借用元：崩壊スターレイル（傾いた板が視差で層割れ）、ゼンゼロ（斜めに刺さった札が押すと跳ねる）、Reverse:1999（吊られた物がゆっくり揺れる）、NIKKE（端のコマンド盤が奥へ倒れる）。

1. 名札（ミミ）：z+80、rotateY+14 rotateX+4（左縁が手前）、x-6。壁に真鍮ピンで吊る。待機 rotateZ±0.6°/5.2s。入場1番、左-40pxから rotateY+30→+14、.55s overshoot1.06。hover z+100＋金縁に光筋。視差×1.0。
2. 案内札5枚：同じ rotateY+14 だが上から z+70,+62,+54,+46,+38 と沈め x を 0〜+24 で6pxずつずらし、各札左端のピンで吊る（上の札の影が次に落ちる）。待機 rotateZ 0.4°ずつ位相ずらし/4.6〜5.8s。入場：名札の後60ms間隔、rotateX-25→0（蝶番で倒れ込む）ease-out-back。hover：z+20浮き・rotateY→+8（こちらを向く）、「新入荷」「あと5回」は別層z+15でぷるん。press：scale.97、ピンを支点に rotateZ-2°→戻り。視差×0.8。ぱにゅ・衣装の顔窓は札より+6px手前で逆位相（箱の中の立体）。
3. グラーノ額：z-10、rotateY-6（右縁が奥）rotateX+2、天井から鎖2本（::before の金線）で吊る。待機 rotateZ±0.35°/7s、幕だけ別層で±0.8。入場4番、上-30pxから落ちて.7s、着地で rotateZ1.5→-0.8→0。hover：肖像 z+12、幕が左右4px開く。視差×0.5（肖像は×0.3で奥行き）。
4. 券（今夜の卓へ）：z+120、rotateX-8 rotateY-10 rotateZ+2、台の上に置き右端が長針の先に触れる位置。待機 z+120↔+128 の呼吸/2.4s＋縁の光走り/8s。入場最後、下+60px・rotateX-40 から ease-out-back.6s、着地で小跳ね。hover：正対(0,0)＋z+150。press：z+100 に沈み80ms。視差×1.3（最前が最も動く）。
5. 台帳（5窓）：z+20、rotateX+6（上が奥）、下辺が台に接地して寝る。待機なし（寝た物は動かない）、代わりに現在戦カードだけ z+10↔+18/3s。入場3番、左-30px＋rotateY+12→0。hover：窓のカード z+14。視差×0.7、カード列×0.9。
6. 右上ボタン：z+60、rotateY-10、右ほど z-6 ずつ奥へ弧を描く。待機：通知の赤丸のみ脈1.6s。入場2番、上-20px順送り40ms。hover z+75・rotateZ+6。視差×0.6。

署名演出「針が卓を叩く」：長針を scene から別レイヤに切り出し（transform-origin 時計中心）、60秒に1回だけ1.2°カチッと進む。その瞬間、針先に触れる券が z+128→+140 に跳ね rotateZ+2→+4、縁の光が一周(.5s)、台帳の現在戦カードがコトッと沈む（+18→+10→+18）。＝「時間だ、卓へ」。スマホ横では視差係数を半分、吊り揺れは名札と額のみ残す。

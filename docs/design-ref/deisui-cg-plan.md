# 泥酔の夜　一枚絵の場面（案・11/12）

1人6枚。①②は勝負の途中の場面（会話の絵）、③は幕間の絵、④〜⑥はクリア報酬の写真集・CG集にも回す絵。
場面は文案（deisui-script.md、11/12 承認）と下書き（deisui-spec.md）の案から取った。

## 描き方（ChatGPT）
- 添付：1枚目＝その人の泥酔の基準の立ち絵（cut/<名>_deisui_stand）、2枚目＝ミミの泥酔の立ち絵（cut/mimi_deisui_stand）、3枚目＝絵柄の見本 pb_01_F1-1（正面の顔）。
- 依頼文は短く：「1枚目の人と2枚目のミミで、<場面>。二人とも泥酔して顔が赤く、服は着崩れています。二人の距離は近く。構図で体の立体感を出して、横長の絵で。」
- 表情・細かいポーズは指定しない。1場面3枚、毎回新しい会話。
- 断られたら、picked.json の order_for_fallback の順に、露出の弱い立ち絵に替えて試す。
- 30場面×3枚＝90枚。半分（リコ・ポルカ・セリナの前半）で一度見せ、見ている間も残りを描く。

## ミミのうさ耳
全場面で、ミミの耳が気持ちに合わせて動いている（ぴくぴく・ばたばた・ぴーん）。依頼文には足さず、絵を見て足りなければ直しで足す。

## 衣装の扱い

- 制服・既定：承認された頬杖のリコを含む `scene.webp` をそのまま表示。
- 装備中の別衣装：指定された人物なしの劇場 `bg_stage.png` をWebP化し、既存の衣装立ち絵を中央の卓の奥に置く。卓の前景を上に重ね、背景の `cover` 倍率から卓縁の位置を計算する。横長スマホでも足元が途中で切れて浮かない。
- ビューアで眺める衣装と装備中の衣装は従来どおり区別する。装備中は眺めるだけで装備を変えない。全解放後・別衣装を装備していない場合は、ビューアで送った衣装をホームでもプレビューできる。再入場時は既定の制服に戻る。ホーム入場時の旧ランダム衣装は、既定＝承認の舞台絵という指定に合わせて固定した。
- 装備変更はその場で反映する。新しい画像のdecode完了まで旧衣装を保ち、背景と人物を同時に切り替える。台詞は現在ホームに表示している衣装を参照する。
- 人物なしの背景には長針がないため、別衣装では針先の光のみ非表示。札の揺れ・反射・跳ねる動作は維持する。

## 動き・読み込み

入場、札と額の揺れ、奥行き別の視差、ホバー・押下、6秒ごとの針先の光と120ms後の札の跳ねを実装。アニメーションで変更するプロパティはtransformとopacityだけ。見本のfilterの変化と光筋のleftアニメーションは、固定影とtransformでの移動に直した。

視差はマウス操作時だけrequestAnimationFrameでまとめて更新し、スマホでは停止する。スマホでは奥行きを半減し、案内札5枚の待機揺れを止める。`prefers-reduced-motion: reduce` ではホームの全アニメーションと遷移を停止する。非表示タブでは待機演出を停止し、画面離脱時はタイマー・イベント・rAFを破棄する。

ホームで使う大きな絵と部品を既存のローダーへ登録。背景にはpreloadを付け、ホームに入る際は画像を先読みしてから描画する。PNGの装飾は原寸・透過を維持した最高品質指定のWebPへ変換した。元の見本素材は保存している。

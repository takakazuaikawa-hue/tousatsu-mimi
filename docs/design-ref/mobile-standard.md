# スマホ版の基準（2026-10-18 制定）

スマホは**横画面だけ**。**両手の親指で持ってタップする**前提。ズームはピンチではなくメーター（スライダー）。

## 1. 画面サイズ
| 区分 | 幅×高さ（CSS px） | 代表機種 |
|---|---|---|
| 基準 | 844×390 | iPhone 12〜16 |
| 最小 | 667×375 | iPhone SE |
| 広い | 932×430 | iPhone Pro Max |
| Android | 800×360・915×412 | Pixel・Galaxy |

- **安全域**：ノッチ付き iPhone の横画面では左右それぞれ約47px（env(safe-area-inset-left/right)）が欠ける。押すもの・読む文字・顔は必ず安全域の内側に置く。背景だけは端まで敷いてよい。
- **黒い帯を作らない**：舞台（1280×800）を高さに合わせて縮める画面では、左右に余った幅を背景で埋め、押すもの・情報は安全域の中の左右にも配置してよい（中央に縮こまらせない）。

## 2. 文字（スマホの画面上の実寸）
| 種類 | 最小 | 目安 |
|---|---|---|
| 本文（台詞・説明・ルール） | **14px** | 14〜15px |
| ラベル・ボタンの文字 | **13px** | 13〜14px |
| 補足（注記・単位・小見出し） | **12px** | 12px |
| 数字の主役（チップ・役・残り） | 16px 以上 | — |
- 12px 未満は作らない（以前の「11px以上」より引き上げ）。
- 1画面の文字量は、縮めずに減らす・畳む・次の画面へ送る。

## 3. 押すもの
- 押せる所は **44×44px 以上**、隣との間を 8px 以上。
- **親指の届く所**：よく押すもの（チェック・コール・賭ける・降りる・次へ・閉じる）は**画面の下半分の左右の端**（安全域の内側）に置く。画面中央の上は押させない。
- ドラッグ・長押し・ピンチを必須にしない（ぱにゅぱにゅの「長押し・引っぱり」は任意の遊び方）。
- 二本指を「左右を同時に叩く」に使う所（ぱにゅぱにゅ）では、ピンチを無効にする。

## 4. 確かめ方
- 検査は 844×390・667×375・932×430 の3つ。安全域は左右47pxの帯を重ねて、その下に押すもの・文字が無いかを見る。
- 文字の検査の下限を 12px（本文の場所は 14px）に上げる。
- 1画面に収まらず下や横に切れているものが無いか（スクロールが必要な所は、スクロールできると分かる見た目にする）。

## 5. 文字に頼らない（2026-10-20 追記）
文字を基準の大きさで並べ直すだけでは「収まった」ことにしない。まず文字の量を減らす。
- 確率・強さ・割合 → 目盛り・棒の長さ。数字は添えるだけ。
- 勝ち負け・危険 → 色と印（金＝有利、赤＝危険）。文で「〜には勝ち、〜には負け」と書かない。
- 場札の意味（フラッシュの危険など） → 当てはまる札そのものを光らせ、伏せ札に小さな札（「♥♥?」）を重ねる。
- 手順の帯 → 番号の菱形を並べ、今の段だけ名前を出す。
- 説明の文 → 1行に削るか「詳しく」に畳む。同じことを2か所で言わない。
- **ただし「今なにをするか」の指示は削らない**。各段で、動詞＋対象の1行（例「ウソの発言を1つ選ぶ」「怖い形の札をタップ」）を、手順の帯のすぐ下に大きく出す。削るのは説明・理由・重複だけ。
- 空の欄を文で埋めない（「まだ〜ない……」→ 点線の空き枠だけ）。
- 置き換えに白い丸吹き出し・ピンクの丸・絵文字・紫は使わない。

# 読み合い11種を、ホームと小窓の品格（劇場の型）にそろえる相談

## 状況
- ホームと小窓20種は「グランドクロック・カジノシアター」の型（黒・深紅・金、しっぽり明朝、四角いボタン、二重の金線、四隅の金飾り、絵文字なし）に作り替えて配信した。小窓の型は ui-modal.css。
- 卓の途中で出る「読み合い」11種（心理＝炎の背景：見抜く・見つめ合う・ダウト・ガチャ・つきつける／論理＝青い格子の背景：役づくり・ハイ＆ロー・危ない場札・ねらい撃ち・当たり札・容疑者）は、まだ古い作りが残っている。
- 写真（PC 1280x800）：qa/out/readsheet/read_pc_1.png・read_pc_2.png（各コマの下にファイル名）。元の写真は qa/out/textaudit/1280x800/*.png。
- コード：battles/core.css（共通）、battles/games/<名前>.js（各遊びの CSS は js の中の文字列）。スマホ横（844x390）は read-compact.css で別の並べ方にしてあり、文字 11px 以上・押す所 44px 以上を満たしている。今回は PC の直しが主。スマホ横を壊さないこと（PC の直しは `html:not(.is-compact)` に限るか、各遊びの CSS を直してもスマホ側が上書きしている所を確かめる）。

## 測った結果（PC 1280x800、画面上の文字の大きさ）
- 11px 未満の文字がある遊び：つきつける（最小 8.2px：発言の見出し・No.1・証拠の札の見出し・賭け方の記録・場札の説明）、ねらい撃ち（8.6px：最低額・軸の説明・賭け額）、見つめ合う（9.1px：緊張・動揺のメーターの名前、手がかりの説明）、ハイ＆ロー（9.5px：START・？？？・役の説明）、ガチャ（9.8px：台の文字・図鑑の /40種）、役づくり（10px：おまけ）。
- 原因の多くは battles/core.css の zoom（.gc-mach .7、.ob-court .77、.hl-duel .8、.stare-duel .83、.sn-wrap .86）。「一番中身が多い時に下のボタンが切れた」ので遊び全体を縮めた。写真を見ると、多くの場面で下に大きな空きがある。
- 押す所 44px 未満（PC はマウス想定だが気になる所）：見抜くの「強い手／ブラフ／関係なし」34px、つきつけるの証拠の札 38px、役づくりの「役の強さ順」27px、当たり札の札 42px 幅。
- ねらい撃ちは中身が 34px はみ出している（一番下が切れる）。

## 目で見て気になっている所（安っぽい・旧システムの残り）
- ガチャの心の声、つきつけるの証言：白い丸い吹き出し（禁止の「白い丸い吹き出し」）。
- 見抜くの付箋の中の白い丸いボタン、ピンクのテープ、ピンクの「ぱにゅぱにゅ」の付箋。つきつけるのピンクの「TELL」札。
- 論理の遊びの青い電脳の格子の背景（黒・深紅・金から外れている）。
- 英語の見出し（TESTIMONY・EVIDENCE・BOARD・LOST・CALL の緑など）。
- ハイ＆ローの「LOST」のポルカの絵が右端で切れている。
- ガチャ台のピンクと水色の玉、N/R/SR/SSR の札の色。

## 制約
- 紫を足さない。キャラを丸で囲まない。安っぽい物（白い丸い吹き出し、赤い四角のバッジ、ピンクのピル型ボタン、絵文字の見出し）は厳禁。「何よりも大事なのはクオリティ」。
- 遊びの中身・手順・数字は変えない。見た目と並べ方と文字の大きさだけ。
- 絵が要る所は ChatGPT で描ける（純緑の地で描いて切り抜く）が、最小限に。

## 聞きたいこと
1. PC で文字を 11px 以上（読む文は 13px 以上）にしつつ、一番中身が多い時も1画面（財布の帯の下 747px）に収める直し方を、遊びごとに。zoom をやめるのか、値を上げて並べ替えるのか。CSS の値の水準で。
2. 上の「気になっている所」を劇場の型に寄せる具体案（色コード・線・角・書体）。ui-modal.css の型と同じ部品で言えるなら、それで。心理と論理で背景を分けるなら、論理の背景は何がよいか（青い格子をやめる場合の代わり）。
3. ほかに写真で気になる所（切れ・重なり・押せそうに見えない・説明不足）。
4. 優先順位（目立つ順・プレイヤーがよく見る順）。

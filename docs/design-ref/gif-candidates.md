# GIF にすると良くなる所の洗い出し（D11、2026-11-21）

ユーザー（11/07）「チャットGPTでGIFが作れるようになったよ。GIFにした方がクオリティが上がるところを探しておいてね」への答え。

## 前提：今の動きの作り
- 動画（mp4）37本・合計 13MB（使っていない物もある：ミニキャラの勝ち負け・VS・待機は今のゲームから読んでいない）：assets/motion（ご褒美CG・幕間・待機・ロード画面・ロビー・ぱにゅぱにゅの当たり）と assets/battle/motion（VS・ミニキャラの勝ち負け・見破られ）。
- それ以外の動きは CSS（@keyframes 396個）と網目（ぱにゅぱにゅ・ホームのリコ・一枚絵の呼吸）。
- GIF は256色・透明が1段だけ・同じ長さの mp4 の3〜10倍重い。**大きい絵の動きは mp4 のままが良い**。GIF の強みは「透明な背景の小さなループ」。入れる時は GIF をそのまま使わず、**透明つきの動く WebP に変換**する（色・ふちのなめらかさ・重さとも GIF より良く、今の webp の読み込み係でそのまま使える）。

## 作り方の決まり（作る時）
- ChatGPT には「背景は純緑」で描かせて切り抜く（[[chatgpt-image-pipeline]]）。GIF の透明は1段なので使わず、緑抜きしてから動く WebP にする。
- コマ数は8〜16、1ループ1〜2秒。スマホが熱くならないように、同じ画面で同時に動かすのは2つまで（[[perf-loading-principles]]）。
- 先読みの場面を決める：1・2 は卓に入る時、3 は当てた時、4 は起動時。

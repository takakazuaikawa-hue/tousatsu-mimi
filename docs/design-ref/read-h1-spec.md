## 1. 筋：なぜ・いつ本編の卓で寝落ちするか

**卓の場面**：ほろ酔いの夜。場札5枚が全部出た後。ミミの番で、まだ誰も賭けていない（ミミが先に決める番か、相手が見送った後）。ミミが「うーん……」と考えこむ。その間に、グラスを重ねた相手が、札を胸の前に持ったまま、こくり……と寝落ちする。手がゆるんで、伏せ札が少し傾く。

**なぜ寝ぼけて払うのか**：酔って寝落ちした人は、「番だよ」と起こされても、自分の札を見直さない。寝ぼけたまま「ん〜……はらう〜」とチップを出す。眠りが深いほど、大きい額でも払う（＝泡が多い）。札の音で目がさめてしまうと、もう寝ぼけてはくれない。

**なぜのぞけるのか**：手がゆるんで、札が傾いているから。ミミがそーっと指をのばす。行儀は悪い。だから相手に見つかると（ヴェルベットのたぬき寝入り）罰がある。

## 3. 決まり1つ

画面にいつも1行で出す：

> **泡1つ＝寝ぼけて払ってくれる 300。1枚のぞくと、泡が1つ われる。**

この1行から出てくること（覚えなくてよい。画面を見れば分かる）：
1. 「賭ける」の額は、いつも残りの泡ぜんぶ（泡3つ＝900）。ボタンに額が出ている。
2. 寝ている相手は、賭けに必ず払う。その後は、ふつうに勝負（札をくらべる）。**ミミが負けていれば、賭けた分を取られる。**
3. 泡が無くなると、起きる。もう賭けられない（寝起きの彼女も賭けない。そのまま勝負）。
4. 途中で指を離せば、札は戻り、泡も割れない。割れるのは、1枚めくり切った時だけ。

**赤い目盛り**（決まりではなく、見る物）：横に10ます。赤います＝「ミミが負ける見込み」。残りの札を全部数えて出す（のぞく前は相手の2枚の組み合わせ990通り、1枚見た後は残り44枚）。赤が0の時は金の字で「負けなし」、10の時は赤い字で「負け」。数字（％）は出さない。少しでも負ける札があれば、赤は必ず1ます以上出る（0に見せない）。

**乱数は無い。** 相手の札は入りの時にもう決まっている。泡がいつ割れるかも決まっている（めくり切った時）。見えない速さや時間切れで失敗することは無い。「賭ける」は、赤が残っているのを見た上で自分で選ぶ賭け（危なさは目盛りに出ている。のぞけば避けられる）。

### 4-2. のぞく操作

- 「のぞく」を押している間、手前の伏せ札が起き上がる（1.0秒でめくり切る。0.4秒でマークの色、0.7秒で数字が見えはじめる）。一番右の泡が、いっしょにふくらんでふるえる。ボタンの縁に、進みの輪。
- **途中で離す** → 札は伏せに戻る。泡も戻る。何も起きない（何度でもやり直せる）。
- **めくり切る** → 泡が割れる（コインが落ちて消える。「−300」）。「賭ける」の額がへる。めくれた札は表のまま残る。赤い目盛りが動く（0.6秒）。彼女が身じろぎする（寝言）。ここで一度、指を離さないと2枚目には進まない（押しっぱなしで2枚めくれてしまうのを防ぐ）。
- 2枚とも見ると、目盛りは「負けなし」か「負け」になり、彼女の役の札が出る（「ポルカ：役なし」）。
- 最後の泡が割れると、彼女が起きる。「賭ける」は消えて、「このまま勝負」だけになる。
- 指で長押しできない時のために、軽く1回押すと「長押し」と出る。検査の台本用に、1枚めくる関数を window に出す。

## 6. 本編に入れる時の決まり

1. **いつ出す**：ほろ酔いの夜だけ。場札5枚が出た後、ミミの番で、まだ誰も賭けていない時。相手の酔いの段が2以上。1対戦に1回まで。どちらかが全部賭けている手では出さない。
2. **札を見て出すか決めない。** 寝落ちは札と関係なく起きる（酔いの段と、対戦の中の何手目か、で決める）。配り方も相手の打ち方も曲げない。札で決めると、出た時点で勝ち負けがばれる。
3. **泡の数**：相手ごとの元の数（ポルカ3・リコ3・グラーノ2・ヴェルベット2・セリナ1）。泡1つの額は、その時のポットの3分の1（切りのいい数に丸める。泡3つ＝ポットと同じ額）。手持ちで払えない分の泡は出さない。
4. **赤い目盛り**：本当の札から数える（のぞく前は990通り、1枚見た後は44枚。1回数ミリ秒）。どんな手・どんな場でも出せる。同点になる札は、赤に入れない。
5. **寝ぼけ払い**：寝ている間に賭けられたら、相手の AI の答えを「払う」に替える（つなぐのは、この1か所）。賭けない時・起こした時は、相手も賭けずに、そのまま勝負。**起こした後に、ふつうの賭け合いには戻さない**（戻すと「札を全部見てから、起きた相手にはったりをかける」が一番得になってしまう）。
6. **その手で終わる**：最後の札の後なので、のぞいた札を後の賭けで AI に使わせる仕組みは要らない。

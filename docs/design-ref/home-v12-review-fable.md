# ホーム v12 講評（FABLE／ゲームUIアートディレクター視点）

対象: `docs/design-ref/home-v12.html`、`qa-shots/home_v12_pc.png`（1280×800）、`qa-shots/home_v12_phone.png`（844×390、舞台倍率 k=0.4875）。絵は仮なので UI の骨格と方向のみを見る。

---

## 1. 総評

**v11 からは確実に格が上がった。だが「2026 年のプレミアム」には届いていない。今は「よくできた 2019 年の課金ゲームのホーム」。** 良い点は、Bodoni Moda × しっぽり明朝の組み合わせ（Reverse: 1999 の紙モノ編集感に近い）、右下に主役ボタンを置く構図（HSR / ZZZ の定石）、相手5人の肖像札で進み具合を見せる発想、黒・深紅・金の統制（紫ゼロは守れている）。

安く・古く見える原因は要素ごとに特定できる。

- **左の行き先が「同じ札を5枚積んだリスト」のまま。** 252×70 の等寸の板に線画アイコン＋六角形バッジ。六角形の中の細線アイコン（家・書類・ハート・本・ハンガー）は SaaS の管理画面の語彙で、時計台のカジノ劇場の物ではない。v11 の「テキストの一覧」が板付きになっただけ。
- **金の質感が「ウェブの金グラデ」。** `--metal` は縦5段の線形グラデで、ノイズも面取りも縁の暗線もない。CTA・勲章・WIN帯・左の縦線すべてが同じこれで、平たく光る。本物の金は「暗い地＋細いリム光＋筆目＋縁の影」で成立する。
- **吹き出し。** ガラス箱に三角のしっぽはチャットアプリの語彙。劇場の主役の台詞ではない。
- **上の帯が汎用スマホアプリ。** 丸いガラスのアイコンボタン、角丸ピルの財布、破線の丸に「12」。館の素材で作られていない。
- **グラーノが画面に4回出ている**（看板の立ち絵・右下のスラブ・肖像札の「今夜」・看板の背景）。情報の重複は「整理されていない」と読まれ、高級感を削る。
- **左右のべた黒ビネット**（左右 300px まで .86 の黒）が、絵を額縁の中の小さな写真に見せている。NIKKE / WuWa は絵を端まで生かし、UI は薄いガラスで絵の上に浮かせる。
- **看板の電球**は 4px の点の列で、1280 では「縁のノイズ」にしか見えない。

逆に、残すべき良い点: 肖像札の WIN スタンプの傾き、CTA の斜め断ち（六角形の横長）、歯車の後光、主役ボタンだけに走る光、入場の時差アニメ。方向は合っている。密度・素材・重複の3点を直せば一気に上がる。

## 2. 直し 8 件（効果の大きい順）

**① 「今夜」を1つの物に統合する（最大の効果）**
看板（右上）＋相手ブロック＋CTA をひとつの「今夜のチケット」縦柱に。右端 x=892〜1252、y=92〜766 の 360×674 を1枚のポスター札にし、上からグラーノ立ち絵（右にはみ出す）→ EPISODE 04 / 商人グラーノの値札勝負 → 勝てば 900 コイン＋ご褒美CG → 肖像札の「今夜」はここに吸収 → 最下段に CTA を一体化（半券のミシン目で切れている形）。参考: ZZZ の委託カード、HSR の右下「開始」札、Resleriana のイベント札。右下のスラブと看板は削除。空いた右上は小さな「衣装・催し」のカルーセル（280×110）に格下げするか無し。**HTML/CSS で今すぐ可。**

**② 金の素材を作り直す**
CSS の `--metal` に (a) 1px の暗縁 `#3a2408`、(b) 内側の面取り `inset 0 1px 0 #fff3c0, inset 0 -1px 0 #5a3a10`、(c) SVG `feTurbulence` のノイズを `mix-blend-mode: overlay` で 6〜8% 重ねて筆目、(d) 光沢は形に沿った放射（上1/3に明）。**今すぐ可。** 本命は **真鍮の額縁 PNG（9-slice、角に歯車の浮き彫り）1点**と**金箔テクスチャ 512px タイル 1点**を描いてもらう（アセット）。

**③ 左の行き先の「等寸リスト」を崩す**
5枚のうち「ぱにゅぱにゅ」「衣装」はキャラの出る場所なので、絵入りの大札（252×104、右半分にミミ／リコの切り抜き）にし、交換所・コレクション・教室は 252×58 の細札へ。NIKKE のロビー左列や ZZZ の HDD タイルと同じ「写真付き2＋文字3」。線画アイコンは廃止し、**金の浮き彫りの小道具 5 点（鍵・チップ・リボン・本・ハンガー、96×96 透過、アセット）**に置き換える。それまでは六角形を廃し、しっぽり明朝の1文字（交・集・艶・教・衣）を金で組んで仮置き。寸法と並びは**今すぐ可。**

**④ 吹き出しの箱を捨てる**
ガラス箱・三角を外し、文字だけを置く。Reverse: 1999 / Metaphor のやり方: 上に 1px の金の罫、しっぽり明朝 18px、一文字ずつ 30ms で出現（typewriter）、6 秒で消える。位置は現状（50%+196px, 300px）で可。**今すぐ可。**

**⑤ 上の帯を館の素材にする**
財布: 角を 6px 斜めに落とした真鍮の板（ピル廃止）、数字は Bodoni Moda Italic 28px。アイコンボタン: 46px の八角形、金 1px の罫、中の線画は 1.5→2px に太らせる。名札の破線丸「12」は **時計の文字盤メダル（64px、アセット）**に差し替え、それまでは八角形。**寸法は今すぐ可、文字盤はアセット。**

**⑥ 肖像札を「台帳」に育てる**
札を 72×100（今夜 88×124）に拡大、上にローマ数字 I〜V（Bodoni 11px 金）、WIN は帯ではなく **蝋の封印スタンプ（48px、アセット）**を角に。錠前の札は黒塗り＋錠ではなく、絵を 20% 見せて「？」を金で。今夜の札は斜め 4° で浮かせ、①の柱と同じ角度にして視線を右へ流す。**今すぐ可（封印はアセット）。**

**⑦ 左右のべた黒を「緞帳」に替える**
`.grade` の横グラデを .86→.6、幅 300→220px に緩め、深紅を 8% 混ぜる（`rgba(40,6,12,.6)`）。本命は **左右の緞帳（ベルベット＋金の房、各 320×800 透過、アセット）**を絵の層として重ね、ホバー／マウスで 4px だけ視差（WuWa / ZZZ の多層視差）。

**⑧ 動きの整理**
光の粒 14→7、`.gearglow` の不透明 .55→.4、電球は廃止（②の額縁に置き換え）。CTA は 3.4 秒の光走りに加え、2.2 秒の `box-shadow` 鼓動を追加して「ここが生きている」と伝える。ホバー時に札が `translateX(6px)` するのは良い。**今すぐ可。**

## 3. 強弱の検査

**「卓へ」は最有力だが、独走ではない。競合が3つある。**

1. **右上の看板**（360×168、絵入り・26px 太字・電球が点滅）。CTA と同じ幅、同じ右端、より明るく、より動いている。視線はまず看板に行き、次に CTA に落ちる。「主役ボタンにだけ光が走る」という設計意図が、看板の電球で破られている。→ 直し①で統合すれば解消。
2. **リコの手の A♠A♥**。絵の中で一番白い面。これは絵の問題で UI の責任ではないが、本番の絵では札の白を 10% 落とすか、CTA 方向に傾けて視線誘導に使う。
3. **コインの 850 と NEW の赤**。850 は 26px 金で CTA の「卓へ」34px に迫る。22px に落とす。NEW/5 の赤いピルは画面で唯一の赤い発光体で目を引きすぎる。深紅の布のタグ（金文字、角を斜めに）にして発光を消す。

CTA 自体の弱点: 「卓へ」の2文字が 360px の板に対して小さく、板の金が平たいので「金の板に文字」止まり。文字 34→42px、`letter-spacing .3em`、左にチップ・右に「▶▶」の二重山形（HSR の開始札）を足し、板の周囲に 0 0 24px の金の滲みを常時置く。

## 4. スマホ横（844×390）

舞台倍率 0.4875。画面実寸で検算した。

**文字（下限 11px）**
- 行き先 24px→11.7 ✓、名前 26→12.7 ✓、STORY 30→14.6 ✓、グラーノ 30→14.6 ✓、卓へ 34→16.6 ✓。
- **EPISODE 04 16px→7.8 ✗**（`.stage.sm .go .opp small`）。24px にするか隠す。
- **吹き出し 20px→9.75 ✗**。24px 以上に。
- **NEW / 5 のバッジ 12px→5.9 ✗**。24px 以上に。
- **「/ 5」15px→7.3 ✗**、**WIN 12px→5.9 ✗**。「/5」は 24px、WIN は文字をやめて封印マーク。

**押す所（下限 44px 実寸）**
- 行き先 76px→37 ✗、間隔 12→5.8。高さ 92px（=45）に。5×92＋4×8＝492、top 96 から 588 まで。肖像札は 610〜772 に収まる。
- アイコンボタン 60→29 ✗、財布 60→29 ✗ → 92px に。＋ボタン 30→14.6 ✗ → 46px に、または財布全体を押下域にする。
- 肖像札 62×86→30×42 ✗ → 96×132（=47×64）に。今夜 110×150。
- CTA 88→43 ギリギリ ✗ → 96px に。

**密度**
左の柱に名札・行き先5・肖像札5 が縦に積まれて重い。右は看板が消えて上半分が空き、バランスが左に倒れている。直し①の縦柱を右に立てればつり合う。また肖像札は左下で CTA から最も遠く、「今夜＝グラーノ」の対応が目で結べない。①で今夜の札を右の柱へ吸収し、左下は「勝った3人＋錠1」の 4 枚にすると軽くなる。

## 5. 捨てる物

- 吹き出しのガラス箱と三角のしっぽ（文字だけ残す）。
- 右上の看板（①の縦柱に統合）。「期間限定・残り3日」は物語の卓に期限が無いなら虚偽表示になるので文言ごと削除。
- 右下のグラーノのスラブ（肖像札の「今夜」と重複）。
- 看板の電球 16 個。
- 六角形の線画アイコン（小道具の浮き彫りへ）。
- 破線の丸の「12」。
- NEW / 5 の赤い発光ピル（深紅の布タグへ）。
- 光の粒の半分。
- `.pc.lock` の黒塗り（絵を薄く見せる方が「次がいる」期待を作る）。

**借りた型のまとめ**: 右下主役札＋右柱の情報統合（ZZZ 委託カード / HSR 開始札）、文字だけの台詞と紙モノの編集組版（Reverse: 1999 / Metaphor）、写真付き大タイル＋文字小タイルの混在ナビ（NIKKE / ZZZ HDD）、多層視差と緞帳（WuWa）、ローマ数字と封印の台帳（Resleriana / 学マス のスタンプ演出）。

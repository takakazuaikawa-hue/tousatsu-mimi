## 変更範囲

本作業で変更したプロジェクトファイルは `ui-modal.css` と本報告書だけ。既存の `game.js`・`home.js`・`style.css`・`read-compact.css`・`index.html` および画像には書き込んでいない。作業開始時から存在した別作業の変更は保持した。

## 実装内容

- 指定された20種類のモーダルに、暖色の暗幕、黒から深紅の紙面、暗金2pxの外枠と内側6pxの明金線、黒い影を適用。太い `frame_gold.webp` の border-image と大きな金色の発光を除去した。
- 4隅の背景画像をPC 44px、compact実寸28pxで配置。画像レイヤーの下に地のグラデーションを置き、画像が未配置でも紙面と二重線が残る構造にした。最終検証時には4画像とも存在した。疑似要素を枠の実装に使っていない。
- 明朝の金の見出し、深紅の見出し帯、本文14px／行間1.7、補足12px、金の数値、細いスクロールバーへ統一。既存DOMの独立した装飾アイコンはCSSで非表示にした。
- 主・副・危険ボタン、選択タブ、44px四方の×ボタン、44px高の真鍮スイッチ、フォーカス線、押下・ホバーを統一。主ボタンは標準48px。装備ロックは薄いopacityをやめ、破線・錠・読める文字で表した。
- 装備・手帳・辞典・履歴・知識ノートは、見出しと本文のスクロール領域を分離。辞典は中央配置し、並べ替えと閉じるボタンの重なりを解消した。
- スマホ横の設定を2列化。左に切替と説明、右に手帳・辞典・装備・リセット・閉じるを配置。追加ゲーム・練習設定は後続行に流し、スクロール可能にした。
- スマホ横の名鑑は左34%の立ち絵と右の本文を維持。立ち絵は全身をcontain表示し、本文だけスクロールする。
- 役一覧はPCでは全幅の3列、スマホ横では2列×5行の配置に変更。現データは9役なので最後の1枠は空く。弱い役も薄くしない。札の数字・スートも11px以上にした。
- ログインボーナスは報酬28px、日付12px、受取200×48pxに調整し、当日セルの疑似要素による発光も停止。
- 各話の本文は14px／1.8に固定。既存の `fitEpisodeTitle` が付けるinline縮小指定を上書きし、本文だけスクロール、開始・閉じるは下端に残す。
- ホームの台帳・音量設定は元の舞台座標を保持し、compact時の文字と操作領域だけ `--inv-scale` から実寸を求めた。
- 研修の手札と場札はスマホ横で横並びにし、修了画面の操作を横並びにした。ミニポーカーは外枠・見出し・ボタンと入門／終了確認カードの外観を変更し、ゲーム盤の列・札・キャラ配置は変更していない。

## 残した課題・マークアップ変更の依頼

1. **演習の正解を示す文言** — `game.js` の `showHandsOnExercise`。正解の選択肢を深紅・金と「✓ 正解」表示に変更したが、不正解時の本文は「正解は緑の選択肢」のまま。これを「『✓ 正解』と表示された選択肢を確認しよう」など、色に依存しない文言へ変更してほしい。既存のテキストノードの一部分だけをCSSでは安全に置換できない。
2. **文字列に埋め込まれた絵文字** — `game.js` の `showHandsOnExercise` の `.ho-tag`（✋）、`showRicoModeChooser` の選択肢名（📚・🔥）、`showNewGameModal` の選択肢名（🆕・💰）などは本文と同じテキストノード。絵文字だけを削除するか、`<span class="ui-icon" aria-hidden="true">…</span>` とラベルに分けてほしい。ラベル全体を消して疑似要素で書き直す方法は採っていない。主要な窓見出しは最終検証時のDOMで絵文字が除かれていた。
3. **設定DOMの保守性** — `game.js` の `showSettingsModal`。現在のDOM順に合わせてCSS Gridで2列配置している。今後項目を増減する際は、左の切替群と右の移動／リセット群をそれぞれラッパーに分けると、`nth-of-type` に依存せず変更できる。現状の通常表示はCSSだけで対応済み。
4. **ホームの閉じるラベル** — `home.js` の `showHomeLedger`・`showHomeSettings` は「閉じる」という文字ボタンを維持。×専用ボタンと完全に同じ44×44pxにする場合は、表示を×、`aria-label="閉じる"` に変更してほしい。現状も実寸44px以上の操作領域がある。

844×390では役一覧の9役をスクロールせず一覧できる。667×375では説明の折返しで下段のスクロールが必要になる場合がある。可読性を下げて無理に圧縮せず、本文スクロールで全役を閲覧できるようにした。

iOS Safari実機、縦持ち、全ての購入状態・追加設定の組合せ、ミニポーカーの全プレイフェーズは未検証。ミニポーカー盤面の既存の小文字は配置維持の指定を優先して変更していない。これらの全面的な再設計は本CSSの対象外。

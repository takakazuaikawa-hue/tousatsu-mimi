## 設計を決めたい（案）
### A. 本気リコ戦＝「卒業試験」に作り込む
- 今は、AI・台詞・声は作ってあるが、**読み合い（心理・論理バトル）だけ古い文字の3択のまま**（新しい11種の割り当て表にリコがいない）。
- 案：本気リコの読み合いは、4人それぞれの得意分野から1つずつ出る「総まとめ」にする（心理：見抜く・見つめ合い・異議あり・ガチャ、論理：役作り・危険度・アウツ・容疑者 などから毎回入れ替え）。リコ専用の台詞は役作りに既にある。
- 右の吹き出し（リコがミミに助言する欄）が、対戦相手本人の助言になっている → 本気リコ戦では欄を「ミミの心の声」に替える。開幕の一言も本気用に。
- 卓の背景を本気リコ専用に（今は無し）。チップの基準のずれ（ゲージ・ピンチ判定が800基準）を直す。
- 勝った時のご褒美：本気リコだけの一枚絵（ご褒美CG）と称号「卒業」。

### B. 幕間を強くする
今の弱さ：背景が全員同じ楽屋、話しているリコが画面にいない（リコの行は2人とも暗くなる）、相手は1行で退場、後半はリコの「次の相手の説明」、声は1行目だけ、ヴェルベットの座り姿の指定が未使用で宙に浮く。
- 案：場面ごとの背景（その相手の卓のぼかし）、リコを画面に出して3人の掛け合いに、相手の行を2〜3行に増やして「負けた相手らしい一言」で締める、次の相手の説明はリコの1行に短く、全行に声（第2弾の生成で）、ヴェルベットは座り姿。

### C. クリア時の解放を分かりやすく
今は結果画面にコインと戦術ノートしか出ず、交換所の新入荷・衣装・零時の卓は、自分でロビーや交換所を開くまで分からない。
- 案：勝利の結果画面に「解放」の札を1枚足す：新入荷の品の小さな絵を数点＋「交換所に N 点入荷」、新しいご褒美CG、零時の卓など。押すと交換所へ直行。

### D. 相手ごとの攻略と手ごたえ（盛り上げ）
今は：相手ごとに打ち筋（ポルカ＝弱いほど大声、セリナ＝額が正直、グラーノ＝いつも半分、ヴェルベット＝極端）と顔への出やすさの差はあるが、**それを突けた手ごたえ**と**振り返り**が無い。攻略は倒した後にしか見えない。
- 対戦前：「攻略の札」— その相手の癖を3つ、絵と短い言葉で（最初は1つだけ見えて、対戦中に気づくたびに開く）。
- 対戦中：癖を突いて勝った瞬間に短いカットイン「読み通り！ 大声＝弱気」と攻略度の目盛りが伸びる。逆に癖にやられた時は「やられた…」と小さく。
- 対戦後：結果画面に「振り返り」— 癖を突けた回数／見逃した回数、次に気を付ける1行。
- 相手ごとの見せ場の事件（1対戦に1回）：ポルカ「どーん！」の大声オールイン、セリナの「計算します」長考、グラーノの「特売」（安い額で誘う）、ヴェルベットの「女王の宣告」。それぞれ専用の演出と、正しく対処すると大きめの得。

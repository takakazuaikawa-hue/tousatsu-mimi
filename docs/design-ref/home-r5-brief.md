- 紫を足さない。キャラを丸で囲まない。ふざけた文言なし。絵の上の文字を増やさない。

## 聞きたいこと
1. 勝ち数 0→5 でホームがどう変わると「進んだ」「次が楽しみ」と感じるか。段階ごとに具体的に（何が・どこに・どう変わる）。「引き」を「カメラが一段ずつ引いて劇場の奥行きが見えてくる」と解釈する案も検討して、良し悪しを言って。
2. 勝った直後にホームへ戻った時の、一度だけの演出（変化を見せる瞬間）。
3. 常に動いている物を増やすなら何をどう動かすか（軽く、品よく、最新のゲームのホームらしく）。優先順に5〜8個。
4. 案内札5つと八角金具4つのアイコンを、部品と同じ金の浮き彫りで描く時の、図柄の案（各1行）。
5. ChatGPT で新しく描く必要がある絵の一覧（最小限）と、コードだけでできる物の区別。

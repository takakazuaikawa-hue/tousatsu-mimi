## 必ず守ること（プロデューサーの決まり）
- 品質が最優先。見本 v15 の作り込み（金の飾り縁の部品、立体の置き方：吊り・傾き・重なり・奥行きごとの視差、入場・揺れ・押した時の反応、長針の先が光ると今夜の札が跳ねる演出）を下回らない。部品を平らに並べ直さない。
- 文字は絵に描かず、コードで載せる。キャラを丸で囲まない。紫を足さない。色は黒・深紅・金。
- スマホは横向きだけ（844×390 などで確認。縦向けの直しはしない）。スマホでは押す所を実寸 44px 以上、文字を実寸 11px 以上（v15 の `.stage.sm` で達成済み。崩さない）。
- 動かすのは transform と opacity だけ。スマホが熱くならないように。設定で動きを減らす人（prefers-reduced-motion）では待機の動きを止める。
- 大きな絵は先に読み込む（描画が遅れて出るのは興ざめ）。絵は webp に。
- 舞台は「グランドクロック・カジノシアター」（巨大な時計台の中のカジノと劇場、英国バロック）。

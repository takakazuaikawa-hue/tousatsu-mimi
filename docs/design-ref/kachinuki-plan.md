# 勝ち抜き戦（エンドコンテンツ、2026-11-22 ユーザー承認）

ユーザー「エンドコンテンツとして、エンドレス勝ち抜きモードも作りますか。今までのディーラー含めた全員と、順々に戦って負けるまで何周できたか記録に残るようにする」「名前は勝ち抜き戦！」

## 決まり（ユーザーが選んだもの）
- 対戦の形：本編と同じ1対1の卓。相手を一人ずつ入れ替える。相手のチップを全部取ったら次の相手。ミミのチップが尽きたら終わり。
- チップ：**持ち越し**。最初の相手は 1000 で始め、勝った時に残ったチップのまま次の卓へ。
- 顔ぶれ：本編の6人＋バカラのディーラー4組＋女神ウンメ（周の締めのボス）＝11戦で1周。
- 周を重ねると強くなる＋コイン。記録は「最高 N周 M人目」。

## こちらで決めた細部（おすすめで作る）
- 1周の順：リコ先輩 → ポルカ → セリナ → グラーノ → ヴェルベット → 本気のリコ → ティカ → お蝶 → プントとバンコ → ピコ → ウンメ。
  - リコ先輩は講義ではなく普通の卓（rico_tutorial の profile を卓用に使う。打ち方の表は既存の物から近い物を当てる）。
- 相手の手持ち：本編の値（ディーラーとウンメは 1300〜2000 の間で新しく決める）×（1 ＋ 0.25 ×（周−1））。参加費も周ごとに上げる。打ち方は周ごとに少し鋭くする（ブラフの見破り・降りなさ）。
- コイン：一人に勝つごとに 100×周、1周するごとに 1000×周。
- 「やめる」・降参・チップが尽きた時に、その回は終わり。記録に残す（最高の周と人数、通算の勝ち数）。途中で閉じた時は、次に開いた時「続きから」できる（今の周・何人目・チップをセーブに持つ）。
- 新しい相手の打ち方（既存の AI の型に当てる）：
  - ティカ（ぜんまい人形・正確無比）：セリナ寄りのきっちりした型。ブラフ少・計算どおり。
  - お蝶（賭場の姐さん・「勝負」の一声）：大きく張る勝負師。ヴェルベット寄りを少し弱く。
  - プントとバンコ（双子）：ハンドごとに交互に打つ（青のプント＝慎重、赤のバンコ＝強気）。
  - ピコ（見習い天使・おどおど）：降りずに付いてくる受け身の型（コール多め、ブラフほぼ無し）。
  - ウンメ（女神）：本気のリコより強い型＋気まぐれ。口調は敬語ほぼ無しの「〜でーす」「〜だよぉ」のなめた口調。
- 台詞：新しい相手は、卓の始まり・自分の番の一言・勝ち・負けを数本ずつ（2行・27字以内）。
- 絵：dealer_tika / dealer_ocho / dealer_twins / dealer_pico / goddess_lean を立ち絵に使う。卓の背景は既存の物を当てる。
- 入口：エンディング後の「今夜の演目」の窓に「勝ち抜き戦」を足す。最高記録をそこに出す。
- 酔い（ほろ酔い・泥酔）の決まりは使わない。
- 声：新しい相手の声は後で（今は文字だけ）。

## 実装メモ（11/22 実装）
- コード：game.js 末尾近くの「勝ち抜き戦」の節（KN_ORDER・KN_SAY・kachinukiStyle・kn*）。本編側の差し込みは startBattleInternal(opponentId, kn)・startHand・endBattle・anteForHand・aiStyleOf・各台詞関数・back-lobby の確認・onAction 'kachinuki-open'。
- 入口：baccarat-ui.js の knBanner（今夜の演目の窓の下の横長の札）。見た目は baccarat.css 末尾と game.js の節の中の <style>。
- セーブ：save.kachinuki = { best:{lap,idx,wins}, totalWins, runs, laps, run:{lap,idx,chips,wins,coins,tableMimi,tableOpp,rec}|null, prevNight }。
- 絵：dealer_*.webp / goddess_lean.webp を assets/characters/kachi_<tika|ocho|twins|pico|unme>_default.webp に複製（専用の絵ができたら同名で上書き。表情・cutin・table_kachi_<id>.webp は manifest にある物だけ結線）（本編の絵の引き方を変えずに済ませるため）。顔のカットイン・差分は無いので立ち絵のみ。
- 相手の手持ち：リコ1000／ポルカ1000／セリナ1200／グラーノ1300／ヴェルベット1500／本気のリコ2000／ティカ1400／お蝶1600／双子1800／ピコ1300／ウンメ2000（×(1＋0.25×(周−1))、本編の「2倍積み」はしない）。参加費の段は周−1（最大3）上から始まる。
- 周ごとの鋭さ：ミミの大きな賭けを割り引かない（respect −0.03/周）・割に合わなくても付いてくる（loose −0.03/周）・オールインにも付いてくる（shoveCall −0.02/周）・稼ぎに賭ける線を少し下げる（valueEq −0.01/周）。
- 座り直し・圧倒モード・講義・幕間・ほろ酔い/泥酔の決まりは使わない。昼にして始め、終わったら元の夜に戻す。

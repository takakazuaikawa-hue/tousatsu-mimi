# ほろ酔いの夜だけの読み合い（中身・骨組みより先に決める）

2026-11-09。二周目（ほろ酔いの夜）で一周目と同じ読み合いが出ると「またこれか」になる、というユーザーの指摘から作る。
泥酔の夜は読み合いを出さない（11/09 ユーザー決定。代わりに勝負の途中に一枚絵と会話劇を挟む）。
見本のページ：https://claude.ai/artifact/YY4rEYH6xrHYQj4Eg3BM6z

**11/09 ユーザー指摘「ポーカーと関係ない」で、下の案1〜4（お酒の遊びが主役）は取り下げ。** 作り直しは「酔いがポーカーそのもの（札・賭け額・勝つ見込み）を変える」4案：A 見えちゃった札（酔った相手の伏せ札の端が見える・論理）／B ぼやけた手札（ミミの手札1枚がぼやける・お水で見えるが相手に読まれる）／C 酔っぱらいの取引（オールイン後のチョップの持ちかけを受けるか）／D 崩れた賭け額。おすすめは A と B。中身は見本のページ（同じリンクの版2）。下の旧案は記録として残す。

## 0. 守ること（一周目の作り替えと同じ）

- 読むのは、いま卓で賭かっている本当の手（state.opponentHand とミミの手）。手がかりは本当の手から毎回作る。
- 答え合わせは手の決着の後（降りても札をめくる）。
- 天秤・記録（大きな賭け20回）・自信の賭け（たぶん0／確信1倍／ぜったい3倍）・答え合わせの画面は今の部品（verdict.js ほか）を使う。新しく作るのは「遊び」の部分だけ。
- clarity-rules.md の4点（目的・やり方・危なさ・決める所と見る物）を初回の絵札で出す。運で決まる所は「運試し」と書き、10個の印で見せる。
- 操作の上手さで決まるように見せて乱数で決める、という作りにしない（酔いの揺れで操作を狂わせる演出は使わない）。
- 酔った台詞と癖は game.js の drunkSpeech と同じ人物に合わせる。

## 案2　一杯を注ぐ（心理）— おすすめ

| | 中身 |
|---|---|
| 目的 | 相手の伏せ札が本物（ミミより強い）かブラフかを当てる。当てるとコイン |
| やり方 | 甘いカクテル・強いショット・お水の3つから1杯選んで注ぐ（2回まで）。飲んだ相手が一言返し、その言い方が手がかり（天秤の重り）になる |
| 危なさ | その相手に合わない酒だと、手がかりにならない一言（重り0）。2回目を注ぐとご褒美が減る（40→25） |
| 決める所と見る物 | ①どの酒か → 相手の手帳（注いだ酒と反応が書き足されていく。初めての相手は空）／②もう1杯か → 天秤の傾き／③本物かブラフか → 天秤／④賭け → 天秤の％ |

相手ごとの「効く酒」（効く酒＝◆◆◆、半分効く＝◆、効かない＝重り0）。言い方は本当の手で変わる。

| 相手 | 効く酒 | 本物の時 | ブラフの時 | 半分効く |
|---|---|---|---|---|
| リコ | 甘いカクテル | にこにこして黙る | 甘えてよくしゃべる | 強いショット |
| ポルカ | 甘いカクテル | 泣き上戸のまま | 笑いが出る | お水 |
| セリナ | 強いショット | 口数が減る | 饒舌に理屈をこねる | 甘いカクテル |
| グラーノ | お水 | 値段の話で「本物の品」と言い切る | 値段の話をはぐらかす | 強いショット |
| ヴェルベット | お水 | 素の声で短く返す | 色気でごまかす | なし（酒は全部演技で返す） |

- 手帳はセーブに残す（save.horoyoiDrinkBook）。2回目からは「この人にはこの酒」が分かる → 上達。
- 試算で確かめること：効く酒を知っている時に、2杯目を注がない方が得になるか（ご褒美の減り方を決める）。

## 案4　ショット・トリック（心理）

| | 中身 |
|---|---|
| 目的 | 相手を先に酔い潰して本音（本物かブラフか）を吐かせる。当てるとコイン |
| やり方 | 伏せた3つのグラスのうち1つが「悪魔の一杯」（とても強い）。1つ選んで「相手に飲ませる」か「自分が飲む」。強い一杯を相手が飲むと確かな手がかり（◆◆◆）、弱い一杯だと◆。自分が飲むと手がかりは出ないが、ミミが酔ってトリックが解禁 |
| 危なさ | どれが強い一杯かは運（3つのうち1つと見せる）。ただし相手の目線（強いグラスをつい避けて見る）が手がかり。目線の当たりやすさは相手ごと |
| 酔うとトリック | ミミの酔い1：グラスのすり替え（選び直し）／酔い2：こぼしたふりで相手の札の端を見る（マークが1つ分かる）／酔い3：乾杯の勢いでもう一杯。見破られる見込みを10個の印で出し、見破られたら記録だけで読む |
| 決める所と見る物 | ①どのグラスか → 相手の目線／②飲ませるか飲むか → 残りの杯数と二人の酔い／③トリックを使うか → 見破られる印／④本物かブラフか → 天秤 |

相手ごと：ポルカ＝目線がすぐ泳ぐ（当たり8割）、セリナ＝目線を隠す（5割）がトリックを見破りやすい、ヴェルベット＝わざと強い一杯を見て誘う（目線の逆が当たり）、グラーノ＝酒に強く強い一杯でも◆◆。

## 案1　飲み比べ（心理）・案3　口がすべる（論理）

見本のページのとおり。案2・案4の見本を遊んでもらってから決める。
- 案1：乾杯ごとに相手の手がかりの確かさが上がり、ミミの酔いも上がる。赤い帯で潰れる。見つめ合いと形が近いのが難点。
- 案3：酔った相手が手のかけら（マーク・数字の大きさ）を口走る。かけらに合わない候補を外して勝つ見込みの棒を作る。かけらの1つは「ふにゃ」で聞き取れない（ぱにゅで聞き直し）。ヴェルベットだけ、かけらの1つが嘘のことがある。

一周目の作り替えで「小学生でも分かるように」と言われた（容疑者しぼり 10/31）。どちらも2問＋決める＋自信、の短い形にする。

## A 見えちゃった札（battles/games/peek.js、id 'peek'、group 'logic'）

| | 中身 |
|---|---|
| 目的 | 酔った相手の伏せ札が少し見えた。見えた札をヒントに、付いていくか降りるかを決める |
| 1問目「見えた札」 | 相手が札を見る仕草で、伏せ札1枚の一部が見える（下の表）。役の札（容疑者しぼりの survey と同じ分け方、4枚）のうち、**見えた札では作れなくなった役を全部タップ**（○消える／×まだ作れる）。作れない＝見えた札と矛盾しない相手の手が0組 |
| 2問目「勝つ見込み」 | 残った役の札に「危ない／負けない」を付けて見せ、見えた札と矛盾しない相手の手だけで数えた「ミミが勝つ見込み」を10個の印で出す。払う額の線（toCall/(pot+toCall)）も同じ帯に。プレイヤーが「付いていく／降りる」を押す（無料の時は「賭ける／様子見」） |
| 自信 | api.wager（たぶん0／確信1倍／ぜったい3倍） |
| 答え合わせ | 決着の後（kind:'logic'）。正解＝見えた札で数えた見込みと線を比べた判断（容疑者しぼりの「読んだ幅」と同じ考え。隠れた札の運で減点しない） |
| 危なさ | 作れる役をタップすると×（ご褒美の段が下がる）。見込みを線と比べ違えると不正解 |

見え方（相手ごと・本当の伏せ札から作る）：

| 相手 | 見える物 | 台詞の例（酔った人物に合わせる） |
|---|---|---|
| ポルカ | 2枚とも、片方はマーク・片方は数字 | 「あっ、見た？ 見たでしょ〜！ ひっく」 |
| セリナ | 1枚の数字だけ | 「……眼鏡が無いと、持ち方が分からなくて」 |
| グラーノ | 1枚のマークだけ（札を高く持ち上げる癖） | 「おっと、品定めは明るい所でせんとな」 |
| リコ | 1枚の数字だけ。強い時だけ「えへへ、見えちゃった？」と笑う | |
| ヴェルベット | 1枚をまるごと、わざと見せる | 「見せてあげる♡ ……どう思う？」 |

出す場面（READ_GAME_OK.peek）：見えた札で「作れなくなる役」が1つ以上あり、残った役に危ない役と負けない役の両方がある時だけ。

## B ぼやけた手札（battles/games/blur.js、id 'blur'、group 'logic'）

| | 中身 |
|---|---|
| 目的 | 酔ったミミの手札の1枚がぼやけて見えない。その中で付いていくか降りるかを決める |
| 1問目「なりうる札」 | ぼやけた札は「赤い絵札」「黒い数字札（2〜10）」のように、色と絵札かどうかだけ分かる。なりうる札（場札・もう1枚の手札にある札を除く）を並べ、**ミミの手が役（ワンペア以上）になる札を全部タップ**（○／×）。全部見つけたら次へ |
| お水 | 1問目の後に1回だけ「お水を飲む」が押せる：ぼやけた札がはっきりする。代わりにご褒美が半分（相手に「確かめた」と気づかれた、という言い方で出す） |
| 2問目「勝つ見込み」 | なりうる札のうち「役になる札」の数を10個の印で（例：12枚中5枚が役になる）。払う額の線と並べて「付いていく／降りる」を押す。お水を飲んだ時は本当の札で見込みを出す |
| 自信・答え合わせ | A と同じ。正解＝なりうる札で数えた見込み（お水を飲んだら本当の手の見込み）と線を比べた判断。答え合わせでぼやけた札の正体をめくる |
| 危なさ | 役にならない札をタップすると×。お水はご褒美半分 |

出す場面（READ_GAME_OK.blur）：なりうる札に「役になる札」と「ならない札」が両方ある時だけ。どの相手でも出る（ミミが酔う遊びなので）。

## つなぎ（game.js）

- REAL_READ_GAMES に 'peek'・'blur' を足す。READ_GAME_OK に peek・blur の判定。
- ほろ酔いの夜は、読み合いの表を別にする：READ_BATTLE_POOLS_HOROYOI = { rico: {psych:[], logic:['peek','blur']}, polka: {psych:[], logic:['peek']}, selina: {psych:[], logic:['peek','blur']}, grano: {psych:[], logic:['blur']}, velvet: {psych:[], logic:['peek']} }。readBattleReady は isHoroyoi() の時この表を引く（一周目の読み合いは出さない）。
- 心理の枠が空なので、ほろ酔いの夜は心理の読み合いが出ない。論理の出る率（今 0.55・1戦2回まで）はそのまま。案C・Dを作ったら心理の枠に入れる。
- 4点の絵札は初回だけ（api.rules の key を 'peek1'・'blur1'）。

# 11/10 Codex 18回目の残り：「夜の出来事は増えたが、駆け引きが変わる所はまだ弱い」への案（朝にユーザーに見せる）

答えは前回と同じ「一部思われる」。全員の途中会話と締めの一言は効いた。残る差は「卓の打ち方そのもの」。案（どれも今の部品で作れる物）：

1. **乾杯の一杯（各ハンドの前の選択）**：ハンドの頭に「乾杯する／しない」。乾杯すると、相手の酔いが1段上がって癖が強く出る（読みやすくなる）が、ミミも酔って助言の「ふにゃ」が増える。夜の打ち方を自分で調整できる。
2. **酔いの段（相手の打ち方が夜の中で変わる）**：対戦が進むほど相手が酔い、打ち方が段階的に崩れる（ポルカはブラフが増える、グラーノは何でも払う、ヴェルベットはオールインが雑になる）。途中会話の後で1段上がる、とすると会話と卓がつながる。
3. **酔った相手の「事故」**：ときどき相手が賭け額を間違える・降りるのを忘れる（泥酔の夜の案の軽い版）。理由が心の声で分かる。

本体のおすすめ：2（会話の後に相手の打ち方が変わる）。途中会話を「卓が変わる合図」にできるので、出来事と駆け引きがつながる。

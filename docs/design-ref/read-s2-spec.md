先に結論：
- ポルカは賭けながら、大きな役を1つ言い張る。「フラッシュ できちゃった！」。
- ミミが見るのは **場札だけ**。ポルカの手札は2枚しかないので、**役の5枚のうち3枚は場札に要る**。場に3枚そろわなければ、その役は作れない。→「異議あり！」。
- 決めるのは2択：**「異議あり！」（この場では作れない）／「作れる」（ウソとは言えない）**。
- 当てて異議 → ポルカが崩れて、罰で伏せ札を1枚めくる。外して異議 → ミミが札を1枚見せる。**目利きは「損なしの3択」、こちらは「自分の札を賭けた2択」**。

## 1. 面白さの1行と、目利きとの手触りの違い

**1行**：「ポルカが大きな役を言い張る。場札を数えて、作れない役なら『異議あり！』。——外したら、ミミの札を1枚見せる」

| | 中身 |
|---|---|
| 迷う瞬間 | 場はこわく見える（同じマークが多い・数字が近い）。でも本当に3枚そろっている？ 声を上げて外したら、自分の札を見せることになる。ポルカは得意顔で待っている |
| 明かしの瞬間 | 場札が「場から3枚」の枠へ飛ぶ。**2枚しか入らず、3つ目の枠が空のまま赤く光る** → 金の帯「異議あり！」→ ポルカの得意顔が一気に崩れて、伏せ札が1枚めくれる。めくれた札が「なぜ盛ったか」の種明かしになっている（例：♠が4枚までは本当にあった） |
| 上達の手応え | 場を見た瞬間に「この場でできる役・できない役」が分かるようになる。これは卓の本番でそのまま使う力（フラッシュがあり得ない場では、フラッシュをこわがらなくていい） |

**目利きとの違い**

| | 目利き（グラーノ） | 異議あり（ポルカ） |
|---|---|---|
| 気分 | 探偵。黙って観察して当てる | 法廷。相手の大口に、声を上げる |
| 相手 | 読まれていると気づいていない | 目の前で挑んでくる。得意顔 → 崩れる、の落差 |
| 見る所 | 顔の印（どの札でのぞいたか） | 場札の枚数（3枚そろうか） |
| 決める | 3択・外しても損なし | 2択・**外して異議を言うと、自分の札を1枚見せる** |
| ご褒美 | 手札が開いたまま卓へ | 罰で彼女の伏せ札が1枚めくれる |
| 考え方 | 消していく（どれが印と合うか） | 数える（枠が3つ埋まるか） |

2択は当てずっぽうで半分当たる。そこを「外した時の罰」で締める。目利きより考える量は少ないが、**度胸が要る**。

## 2. 決まり1つ（ポーカーとして正しい言い方）

画面にいつも1行で出す：

> **手札は2枚だけ。役の5枚のうち、3枚は場札に要る。**

絵の印：言い分の札の横に、**伏せた札2枚（ポルカの手札）＋空の金の枠3つ（場から3枚）**。見るのは「この3つの枠が、場札で埋まるか」だけ。

役ごとの言い方（明かしの1行と、リコの一言に使う。Codex の指摘どおり直した）：

| 役 | 正しい言い方 | 前の誤り |
|---|---|---|
| フラッシュ | 同じマークが**5枚**。手札は2枚だから、**場に同じマークが3枚要る** | 「フラッシュは同じマークが3枚いる」（5枚が正しい。3枚要るのは場） |
| ストレート | 続きの数字が**5枚**。手札は2枚だから、**場に「5つ続きの中に入る札」が3枚要る**（すき間は2つまで。手札2枚で埋める） | 「数字が並ばない」（並んでいなくても、とびとびで作れる） |
| フルハウス | 同じ数字3枚＋同じ数字2枚。手札は2枚だから、場から3枚使う。数字は2種類しかないので、**場に同じ数字が2枚（ペア）要る** | 「ペアがない」とだけ書いていた（どの役の話かを分ける） |

ほかの指摘の直し方：

| Codex の指摘 | 直し方 |
|---|---|
| 「ウソなし」は判定できない場合がある | 問いを「ウソか本当か」から、**「この場札で、その役は作れるか」**に替えた。これは場札だけで白黒がつく事実。ボタンは「異議あり！（この場札では作れない）」と「作れる（ウソとは言えない）」。**「作れる」は「本当」とは言わない**。ポルカも「ほんとかどうかは、ひみつ♪」と言う。本当かどうかは卓の勝負で分かる |
| 「その A はミミが持っている」は反証にならない | この試作では使わない。証拠は場札だけ。ミミの手札は画面に出さない（今回の3つの役は、ミミの手札2枚では否定できない。同じマークも同じ数字も、まだ山に残るから）。先でヴェルベットに使う時は「♥の A」のようにマークまで言わせる |
| 自然な会話の中に、暴ける矛盾を作れるか／くり返すと相手が間抜けに見える | ポルカのウソには毎回**わけ**がある。①あと1枚で本当だった役を、できたことにする（♠が4枚・数字が4つ続き）②ツーペアを盛ってフルハウスと言う。罰でめくれる1枚が、そのわけの種明かしになる。「弱い時ほど声が大きい」「調子に乗って盛る」「追い詰められると崩れる」という人物そのもの。間抜けではなく、**盛りぐせのある子**に見せる |
| 「いつも指摘しない」が強くなり得る | いつも「作れる」＝罰は受けないが、札は1枚も見えない（遊ばなかったのと同じ）。いつも「異議あり」＝半分は自分の札を見せる。6場面はどちらも3問（§4-8） |

この試作で言わせる役は、**フラッシュ・ストレート・フルハウスの3つだけ**（5枚で作る大きな役。ポルカが自慢したくなる役）。ツーペア・スリーカードは、どんな場でも作れるので出さない。

## 4. 固定の6場面

共通：場面ごとに独立。場面1・2は手引きの段（左下に「リコに聞く」。押すと、役に合いそうな場札が少し持ち上がり、リコの1行が出る）。場面3〜6はひとりの段（リコは出ない。「お手本」は開ける）。
ポルカの手札は、当てて異議の時に**1枚だけ**めくる。「作れる」場面では見せない（本当かどうかは言わない約束）。
枠・光る札・理由の数字は手で書かず、計算から出す（食い違いを防ぐ。目利きと同じ作り）。

### 場面1（手引き）　フラッシュ・2枚と2枚　→ 異議あり！

- 場札：A♠ 10♥ 7♠ 5♥ 3♦（♠2枚・♥2枚・♦1枚）
- ポルカの手札：K♠ 8♠（役なし。♠は手と場で4枚）
- 言い分：「フラッシュ|できちゃった！」
- 正解：**異議あり！**（作れる手札は0通り）
- 理由の1行：「同じマークは、多くても2枚。3枚ないと、フラッシュは作れない」
- ポルカの反応：崩れる「な、なんで|分かったの〜！？」→ K♠ がめくれる →「♠、4枚までは|あったんだよ〜！」
- リコの1行：「同じマークを数えてみて。3枚ある？」
- ねらい：お手本と同じ形を自分の手で1回。同じマークが2組あって多く見えるが、3枚は無い。

### 場面2（手引き）　フラッシュ・3枚ある　→ 作れる

- 場札：Q♣ 9♦ 8♣ 4♠ 2♣（♣3枚）
- ポルカの手札：K♣ 5♣（本当に♣のフラッシュ。見せない）
- 言い分：「またまた|フラッシュだよ〜！」
- 正解：**作れる**（作れる手札は45通り）
- 理由の1行：「♣が場に3枚。手札が♣2枚なら、フラッシュは作れる」
- ポルカの反応：（作れる）「ちぇっ、引っかから|ないか〜」「ほんとかどうかは、|ひみつ♪」／（異議で外す）「ざんねーん！|ちゃんと作れるもんね〜！」→ ミミの A♦ が表になる
- リコの1行：「♣が3枚あるね。枠は全部埋まる。ウソとは言えないよ」
- ねらい：**いつも「異議あり」の人は、ここで止まる。** 作れる時は言わない、を覚える。

### 場面3（ひとり）　ストレート・とびとび　→ 作れる

- 場札：9♦ K♠ 5♣ 7♥ 2♠
- ポルカの手札：8♦ 4♣（役なし。4・5・7・8・9 で、6 が足りない。**暴けないウソ**。見せない）
- 言い分：「ストレートだよ、|ストレート！」
- 正解：**作れる**（16通り。6 と 8 を持っていればできる）
- 理由の1行：「5・7・9 のすき間は 6 と 8。手札2枚で埋まる」
- 明かしの絵：場札が数字の順に並び直る（2・5・7・9・K）。5・7・9 が枠へ。間の 6 と 8 の所に伏せ札2枚がはまる。
- ポルカの反応：場面2と同じ（ひみつ♪）。異議で外すと、ミミの K♦ が表になる
- ねらい：数字が並んでいなくても作れる。「ばらばらだからウソ」と思った人がここで外す。

### 場面4（ひとり）　フルハウス・こわい場　→ 異議あり！

- 場札：J♥ 10♥ 9♥ 6♠ 2♦（♥3枚・数字も近い。こわく見える）
- ポルカの手札：J♠ 10♣（J と 10 のツーペア）
- 言い分：「フルハウス！|どーん！」
- 正解：**異議あり！**（0通り）
- 理由の1行：「フルハウスは、同じ数字3枚＋2枚。場に同じ数字が2枚ないと作れない。この場にペアは無い」
- 明かしの絵：枠が「同じ数字」の形（3枚組と2枚組）になり、場から入るのは1枚ずつ。どの数字も2枚目が無い。
- ポルカの反応：崩れる → J♠ がめくれる →「ペアが2つあったから、|つい……！」
- ねらい：こわい場でも、言った役に合わせて数える。フラッシュやストレートなら作れる場だが、フルハウスは作れない。

### 場面5（ひとり）　ストレート・並びが2組　→ 異議あり！

- 場札：6♣ 7♦ J♠ Q♥ 2♦（6・7 と J・Q が隣どうし）
- ポルカの手札：9♠ 8♣（役なし。6・7・8・9 の4つ続きで、10 が来なかった）
- 言い分：「こんどこそ|ストレート！」
- 正解：**異議あり！**（0通り）
- 理由の1行：「5つ続きの中に入る場札は、どこを取っても2枚まで。3枚ないと作れない」
- 明かしの絵：場札が数字の順に並び直る（2・6・7・J・Q）。5枚幅の金の物差しが左から右へすべり、どこでも「2枚」と出る。
- ポルカの反応：崩れる → 9♠ がめくれる →「あと1枚で、|ほんとだったのに〜！」
- ねらい：**場面3の裏返し。** 並んで見えるのに作れない。「隣どうしがあればストレート」と覚えた人がここで外す。

### 場面6（ひとり）　フルハウス・おとなしい場　→ 作れる

- 場札：2♣ 2♦ 9♠ K♥ 5♦（マークも数字もばらばら。小さい 2 のペアだけ）
- ポルカの手札：K♠ 2♥（本当に 2 と K のフルハウス。見せない）
- 言い分：「こんどはほんと！|フルハウス！」
- 正解：**作れる**（27通り）
- 理由の1行：「場に 2 が2枚。手札に 2 と K があれば、フルハウスは作れる」
- ポルカの反応：場面2と同じ（ひみつ♪）。異議で外すと、ミミの A♠ が表になる

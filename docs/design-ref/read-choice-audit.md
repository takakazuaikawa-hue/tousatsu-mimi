# 読み合い「選ぶ場面」の洗い出し（コード監査）

作者の悩み：「選択肢を選ぶ時に何を考えればいいか分からない」。
読み合い11種類（`battles/games/*.js`）と共通の骨格（`battles/core.js`）を読み、**プレイヤーが選ぶ場面ごとに「本当の正解の決まり」と「その時画面に出ている情報」**を並べた。ここから場面ごとの「選ぶ時に考えること」の一文を作る。

## この資料の読み方

- **[確]** ＝ コードを読んで確かめたこと（関数名・行番号つき）。
- **[試算]** ＝ コードの確率をそのまま使って Node で何度も回した数字（実機プレイではない。離す操作は理想的に一瞬とした）。
- **[推測]** ＝ コードから推した意見・遊び手の感じ方。確かめていない。
- 行番号は 2026-10-21 時点の `battles/core.js` と `battles/games/*.js`。ブラウザは起動していない。
- 「画面に出ている情報」は PC の既定の見た目で書いた。スマホ横（`html.is-compact`）では `read-compact.css` が一部を隠す（例：ガチャは1回引くと確率の棒と一言ラベルが消える、危険札の「大きく賭けた10回」の見出しが消える、アウツ・容疑者の問いの札が消える）。画面に出ているかの判断は PC 基準で、スマホで消える所は備考に書いた。
- 「初回だけ」とあるのは `tipOnce`（`core.js:423`）で、リコ先輩の一言は localStorage に見た印がつくと2回目から出ない。

### 判定の記号（最後の一覧で使う）

| 記号 | 意味 |
|---|---|
| ○ | 選ぶ時に考えることが画面だけで分かる |
| △ | 材料は画面にあるが、合わせ方（計算・読み方）の説明がない |
| × | 画面だけでは何を考えればいいか分からない（正解に必要な情報が画面にない／画面の説明がコードの本当の決まりと食い違う） |
| 運 | 考えても当たりが良くならない |

**作者への所見（推測）**
- 論理バトル（danger, outs, suspects, sniper）は `correct` が「得な方を選んだか」で決まり、運は入らない。一方で**棒が先に答えを出しているので、考える部分が残らない**（棒の塗りが線を超えたらコール、というだけ）。形さがし・当たり札数え・容疑者外しは、棒に至るための作業になっている。
- 心理バトルの探偵は、ぱにゅぱにゅが100%という重要な情報が画面に出ていない。ブラフ率が見つめ合いにはあって探偵にはない、といった種類ごとの情報の揃い方の違いがある。
- ハイ＆ローだけ賭け（×1/×2/×3）が無く、続ける／やめるが賭けの役目をしているが、画面の「外せば 0」は実際と違う。
- 「読みに賭ける」は、ほぼ必ず ×3 でよいので、選ぶ意味を持たせるなら損益の見せ方の見直しが必要（案は出さない）。

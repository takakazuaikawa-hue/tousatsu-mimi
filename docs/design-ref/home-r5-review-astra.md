率直に言うと、**リコと時計の一枚絵には十分な華があります。一方、UIは装飾と演出が競合していて、「高級な劇場」より「豪華な部品を貼り重ねたゲーム画面」に見える部分が残っています。** 次の修正は、装飾を足すより、細部・光・動きの強弱を整理する方が効きます。

ブリーフ、添付2枚、home.js と style.css 末尾を確認しました。動きについては実機再生ではなく、コードの設定からの評価です。優先順に挙げます。

1. **新アイコンは世界観に合うが、縮小すると情報が潰れる**

   画像1下段では天秤や本を判別できますが、上段の表示サイズでは左端が「赤と金の細かい塊」に見えます。特にコレクションは、札・リボン・紋章と周囲の唐草が競合しています。右上も、八角枠と中身の双方が強く光り、輪郭を拾いにくい。

   **浮き彫りの方向性は残し、小サイズ専用に描き直すのがよいです。** 天秤は皿と支柱、コレクションは重ねた札、本は開いたページを主形にして、細かな紋章や縁飾りを減らす。外枠は暗めの古金、中の図柄は少し明るい金に分ける。画像2の線画には判別しやすさがあり、その長所を新素材にも戻したいです。

   [現在のアイコン寸法](/C:/Users/takakazu/projects/mp_panyu/style.css:18946)は右上で32px、さらに舞台全体が縮小されるので、拡大図の出来より通常表示での識別を優先すべきです。

2. **常時の動きが重なり、金属の重さと勝利演出の特別感を損ねる**

   「19秒ごとの風」に加えて、[既存の連続揺れ](/C:/Users/takakazu/projects/mp_panyu/style.css:18778)が残っています。PCの案内札・額・卓札などは周期的に揺れ、[home.js](/C:/Users/takakazu/projects/mp_panyu/home.js:328)では針先が7秒ごとに発光。卓札には8秒ごとの光沢もあります。その上に3.3秒ごとの反射が加わります。

   これでは、重い額や金具が軽い吊り飾りに感じられる懸念があります。**常時は炎と微かな埃を中心にし、札の連続揺れと針先の定期発光を止める**のを勧めます。風への反応は残しても、額の振れは案内札より小さくする。

   また、反射のマスクは部品画像の形を使っており、金属だけを区別していません。赤い面まで一様に光るとビニールのように見えやすい。金縁専用のマスクで、細く弱い反射にしたいです。

3. **「新入荷57」の札が、最も露骨に安売り感を出している**

   画像1下段の新入荷表示は、周囲の造形に対して四角い赤地と明るい枠が唐突です。装飾された看板に、販促用のシールを貼ったように見えます。「あと5回」も同じ問題があります。

   [`.h15-tag`](/C:/Users/takakazu/projects/mp_panyu/style.css:18731)は、**看板の内側に収まる小さな銘板か、端に取り付けた細い札**へ変更したいです。赤を看板と同じ深い色に揃え、枠と文字の輝度を落とす。件数の強調が必要かも再考したいところです。

4. **スマホの下部は、文字を装飾の隙間に押し込めた印象がある**

   画像1中段では、リコの台詞と「勝てば〜」が窮屈です。主ボタンの見出しは読めても、補足が小さく詰まっていて、画面全体の仕上がりを下げています。

   [スマホの台詞領域](/C:/Users/takakazu/projects/mp_panyu/style.css:18890)は左右指定で幅が29%に制限されています。**卓の前面に台詞用の幅を確保し、台帳・卓札との間隔を固定する**方がよいです。単純な文字拡大ではなく、短い台詞が自然に一〜二行で収まる配置にする。報酬文も文字と金縁の間に余白を設けたいです。

5. **劇場の成長は、現状では「勝った成果」として読み取りにくい**

   画像1の0勝と5勝には明るさの差がありますが、最初に分かるのは台帳の解放と相手の変更です。時計の区画や燭台の変化は、説明を読んでから探す要素になっています。

   明るさを一律に増すと、5勝時のスマホのように背景の光が人物と競合します。**各勝利で「この燭台が灯った」と位置を特定できる変化を作り、周囲には暗部を残す**のがよいです。時計も広い琥珀色の影の解除より、該当数字の周辺に限定した変化の方が伝わります。

   なお、`HOME_ART`の燭台・暗がりは段階4までなので、5勝目には新しい燭台の点灯がありません。最終勝利に対応する灯りを用意すると、構成にも納得感が出ます。

6. **「開幕の儀」は、主役を追う時間が足りない**

   [現在の進行](/C:/Users/takakazu/projects/mp_panyu/home.js:124)は、時計の発光から450msで左下の封蝋、950msで照明、1400msで右上の額へ移ります。視線が大きく移動するうえ、額が落ち着く前の2300msに卓札が跳ねます。

   **時計と点灯を一つのまとまりにし、封蝋、額の掛け替え、台詞の間に短い静止を置きたいです。** 卓札の跳ねは省くか、額が完全に止まってから小さく一度だけ。添付の前・途中・後では人物差し替え以外の節目が弱く見えるため、発光量を増やすより、見せる順番を明快にする方が効果的です。

   実装上も、スキップ時の`finish()`で額のWeb Animationsを停止していないため、押した瞬間に最終姿へ落ち着く処理まで揃えると丁寧です。

良いのは、**リコの表情、時計の逆光、深い赤の組み合わせ**と、「今夜の卓へ」の分かりやすさです。ここは画面の魅力として成立しています。最初に直すなら、**アイコンの細部整理、常時演出の削減、新入荷札の作り直し**の3点を優先します。

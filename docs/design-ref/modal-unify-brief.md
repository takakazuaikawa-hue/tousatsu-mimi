# 小窓（モーダル）を新しいホームの品格にそろえる相談

## 状況
- ホームは「グランドクロック・カジノシアター」（黒・深紅・金、英国バロック、しっぽり明朝）に作り直した。金の部品は ChatGPT で描いた立体の金細工（assets/ui/home/*.webp、qa-shots 側の parts_b.png が見本）。
- ところが、ホームから開く小窓の多くが古いまま：ピンク寄りのボタン、紫がかった地、飾りのない素の箱、小さな文字。
- 写真：qa/out/fulltour/pc_sheet1.png・pc_sheet2.png（PC 1280x800）、qa/out/fulltour/phone_sheet1〜4.png（スマホ横 844x390）。各コマの下にファイル名。
- 小窓の一覧（33種）：物語の台帳・音量設定（.home-dialog）、ゲーム設定（settings-overlay）、装備変更（equip）、トロフィー手帳（collection）、キャラ名鑑（char-profile）、リコ先輩の選択（rico-mode）、ポーカー辞典（glossary）、ハンド履歴（hand-history）、役の早見表（hand-guide）、ログインボーナス（login-bonus）、終幕の前に（ending-prompt）、ファイブポーカー（minipoker）、各話の導入と回想（episode）、新しく始める確認（newgame）、確認（mimi-confirm）、戦術ノート（note-article）、ご褒美CG・メモリの鑑賞、衣装鑑賞（rico-viewer）、幕間（intermission）、チップの買い足し（rebuy）、ハンドの結果（hand-result）、研修・講義の窓（tutorial/lecture）、ほか。

## 制約
- 紫を足さない（既存の紫も深紅か黒に寄せたい）。キャラを丸で囲まない。安っぽい物は厳禁。「何よりも大事なのはクオリティ」。
- スマホ横 844x390 が主。押す所 44px 以上、文字 11px 以上。スマホでは小窓を画面いっぱいの紙面にし、中身は実寸で描く（CSS 1px＝画面 1px）方針で、今これを入れている。
- 33種を一つずつ描き直すのではなく、共通の「小窓の型」（枠・見出し・本文・主ボタン・副ボタン・タブ・切替・閉じる）を CSS で作り、全部にかぶせる。必要なら枠の飾りだけ ChatGPT で金の部品を描く（純緑の地で描いて切り抜く）。

## 聞きたいこと
1. 共通の小窓の型の具体案：地の色・枠（何重の金線か、角飾りの有無）・見出しの書体と飾り・本文の色・主ボタン／副ボタン／危険ボタン（リセット等）・タブ・ON/OFF の切替・閉じるボタン・区切り線・スクロールの見せ方。CSS の値の水準で（色コード・太さ・影）。
2. ChatGPT で描く価値のある部品（最小限、例：小窓の四隅の金飾り、見出しの銘板）とその描き方。
3. 写真の中で、型をかぶせるだけでは足りず、並べ方から直すべき小窓（例：役の早見表の右半分が空く、プロフィールがスマホで崩れる）と直し方。
4. 優先順位（プレイヤーがよく開く順・目立つ順）。

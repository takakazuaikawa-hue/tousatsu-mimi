おすすめは、**リコの大きさと操作位置を保ち、勝つたびに劇場の照明と勝利の印が積み重なる構成**です。カメラを引く案は魅力がありますが、今の「リコと向かい合っている近さ」を弱めるため、採用するなら小幅に留めたいです。

[ブリーフ](C:/Users/takakazu/projects/mp_panyu/docs/design-ref/home-r5-brief.md)、[home.js](C:/Users/takakazu/projects/mp_panyu/home.js:32)、[style.css のホーム部分](C:/Users/takakazu/projects/mp_panyu/style.css:18685)、[tpl-lobby](C:/Users/takakazu/projects/mp_panyu/index.html:157)を確認しました。現状にも逆光の明滅と札の光沢がありますが、スマホでは案内札の揺れを止めているため、動きが少なく見える理由があります。

以下の手間は「小＝既存部品の調整」「中＝状態管理・配置・素材調整が必要」「大＝原画の追加制作と画面全体の再調整」。重さは実測前の見込みです。

**1．勝ち数0→5で、何をどう変えるか**

毎回、**左下に勝利の証拠が残る／劇場の一部が明るくなる／右の額が次の相手に替わる**、という共通の流れを作ります。照明の変化は累積させます。

| 段階 | 具体的な変化 | 次への期待 | 手間・重さ |
|---|---|---|---|
| 0勝 | リコと時計の逆光を主役にする。左右の柱・階段は今より少し暗く、形は読める程度。台帳はⅠが選択状態、封蝋なし。 | 暗い周辺にも劇場が続いていると感じさせる。最初から未完成の画面にはしない。 | 小／低。静止した陰影で調整。 |
| 1勝・リコ | Ⅰに封蝋。左奥の燭台周辺が暖かくなり、左の案内札の金縁が読みやすくなる。右額はポルカ。 | 最初の勝利で「この場所が自分を迎えるようになった」と分かる。 | 中／低。既存封蝋＋局所照明。 |
| 2勝・ポルカ | Ⅱに封蝋。右奥の階段と手すりを照らし、画面奥へ続く道を見せる。右額はセリナ。 | 次の卓へ進んでいる感覚を、背景の奥行きで出す。 | 小〜中／低。照明の共通処理を再利用。 |
| 3勝・セリナ | Ⅲに封蝋。上部のアーチ・柱頭の金細工が見えるようになる。中央の顔の明るさは据え置く。右額はグラーノ。 | 劇場の高さと格が分かり、前半から後半への変化を作る。 | 中／低。原画に描かれている構造の範囲で照らす。 |
| 4勝・グラーノ | Ⅳに封蝋。右額の頂部にある赤い宝石と、卓へ進む札の王冠に照明を集める。右額はヴェルベット。 | 最終戦だけは「広がる」より「最後の相手へ視線が集まる」状態にする。 | 小〜中／低。小さいハイライト中心。 |
| 5勝・ヴェルベット | 五つの封蝋が揃う。左右・上部の照明が整い、台帳中央と卓札の王冠が明るくなる。額の既存見出しは「全卓制覇」。 | 自分が完成させた劇場として残す。再訪した時にも達成が分かる。 | 中／低。完成状態と再戦導線の調整。 |

現在、勝利済みの肖像には暗くする処理があります。これを少し弱め、**勝った相手は豊かな色と封蝋、次の相手は明るい金枠、未解放は暗い肖像**にすると、台帳が埋まる喜びが強くなります。スマホでは封蝋も少し大きくしたいです。

背景の照明は、描かれた燭台や柱に合わせた静的なマスクで調整します。存在しない建築を光だけで追加することはできません。局所補正で絵が濁る場合は、同じ構図の照明差分を一枚用意する方が品質を保てます。

カメラを引く案の評価は次のとおりです。

| 案 | 良い点 | 気になる点 | 手間・重さ |
|---|---|---|---|
| **固定画角＋上記の変化** | リコの魅力とスマホの読みやすさを保ち、進行を蓄積できる。 | 大きな景色の変化は控えめ。照明の差を明確に作る必要がある。 | 中／低。推奨。 |
| **毎勝利、小幅に引く** | 劇場の広さが徐々に分かり、進行が画面全体に出る。 | 一枚絵なのでリコも小さくなる。単なる縮小では新しい奥行きは生まれない。 | 大／常時は低、切替時は中。広めの原画と配置検証が必要。 |
| **最終勝利だけ引く** | 最後のご褒美として変化を大きくできる。 | 恒久的に引くと、完成後だけリコが遠くなる。 | 中〜大／切替時のみ中。短い演出としてなら有力。 |

毎段階引くなら、広めの同一原画を用意して、例えば **110→108→106→104→102→100％**と切り取りを変えます。UIは縮小しません。ただしこれは画角の変化であり、立体空間を移動するカメラではありません。スマホではさらに幅を抑えたいです。

**2．勝利して戻った時、一度だけ見せる演出**

**約2秒の「封蝋が付く→劇場が変わる→次の相手が現れる」**を提案します。

| 時間の目安 | 見せること |
|---|---|
| 0〜0.3秒 | 勝つ前の照明・台帳でホームを表示。通常の全UI入場演出は控える。 |
| 0.3〜0.7秒 | 勝った肖像に封蝋が短く押し付けられる。小さな打刻音を一度。 |
| 0.7〜1.3秒 | 今回解放された場所の照明が暖まり、その状態で残る。 |
| 1.1〜1.7秒 | 右額の肖像と名前が次の相手へ切り替わり、額が一度だけ小さく揺れて収まる。 |
| 1.7〜2.1秒 | 「今夜の卓へ」の王冠に細い反射が一度走る。5勝目は台帳の王冠で締める。 |

**手間：中。重さ：低〜中、一度だけ。** 新しい祝勝画面を挟まず、普段のホーム上で変化を見せます。途中で操作されたら完成状態へ即座に進めます。動き軽減時は最初から完成状態を表示します。

実装では、初回勝利時に「未再生のホーム演出」を記録し、ホーム復帰時に一度だけ消費します。通常の再描画や交換所から戻っただけでは再生しません。ログインボーナスの自動表示とも重ならない順序にします。

なお、**現行の `clearedStages` にはスキップによるクリアも入ります**。単純な件数増加を勝利演出の条件にすると誤発火するため、実際の勝利イベントと区別する必要があります。ここではブリーフどおり、各相手への初回勝利で進む設計を想定しています。

**3．常時の動きを増やすなら、優先順に6個**

全部が同時に目立つ状態にはせず、周期と休止時間をずらします。動くのは部品の中身で、押す範囲は固定します。

| 優先 | 動かす物・動かし方 | 手間・重さ |
|---|---|---|
| 1 | **燭台の灯り**：左右の見える炎付近、計3〜4か所の小さな暖色光が不規則に明滅。炎の位置は動かさない。 | 小〜中／低。小面積の不透明度変更。 |
| 2 | **相手の額**：上の吊り位置を支点に、8〜11秒で左右0.3度程度。スマホでは角度を弱める。鎖も一緒に動く。 | 小／低。既存の揺れを調整。 |
| 3 | **時計の逆光**：既存の `.h15-glow` を10〜14秒周期へ。顔が明滅したと感じない程度に、時計の周辺で光が呼吸する。 | 小／低〜中。面積が大きいため効果の重ね過ぎを避ける。 |
| 4 | **金縁の反射**：額の上辺、札の王冠、八角金具のどれか一つに、細い反射が走る。全体で8〜12秒に一度。 | 中／低〜中。小範囲のマスクを使用。 |
| 5 | **案内札**：支点から0.2〜0.4度のゆっくりした揺れ。5枚を同じリズムにしない。スマホでは1〜2枚に限定。 | 小〜中／低。既存処理の調整。隣の押す範囲との干渉確認が必要。 |
| 6 | **台帳の次の相手の金印**：6〜9秒に一度だけ、印の明るさが静かに上がって戻る。肖像や台帳全体は動かさない。 | 小／低。既存 `mark.webp` を利用。 |

今の「6秒ごとに卓札が跳ねる」は、常設の重い金具としては少し軽く見えます。**跳ねは勝利直後の一度に限定し、普段は反射で誘導する**方が、この美術に合います。

時計の針やリコの呼吸は今回は優先しません。`tpl-lobby` には独立した針・通常衣装の人物レイヤーがなく、背景に描き込まれているためです。CSSにある `.h15-hand`・`.h15-rico` を有効にするだけでは成立しません。

共通して、動き軽減・非表示タブ・画面離脱で停止します。ホーム側で確認できる動き軽減判定はOSの設定なので、ゲーム内設定でも切り替えるなら、その接続も追加します。

**4．金の浮き彫りアイコンの図柄案**

共通仕様は、**幅のある面取り、左上の明るい金、右下の濃い彫り影、細部より輪郭優先**です。スマホでは図柄が約20pxになるため、細い線画を金色にするだけでは弱いです。

| 用途 | 図柄案・各1行 | 手間・重さ |
|---|---|---|
| 交換所 | 重ねた金貨2枚と、その手前に置いた小さな交換用トレー。 | 小〜中／低 |
| コレクション | 厚い背表紙と四隅の金具が見える、少し開いた収蔵アルバム。 | 小〜中／低 |
| ぱにゅぱにゅ | 指先が丸みのあるハートを軽く押している、単純な手とハートの浮き彫り。 | 中／低 |
| リコの教室 | 開いた教本に、一本の羽根ペンを斜めに重ねた図柄。 | 小〜中／低 |
| 衣装 | 蝶ネクタイ付きのバニースーツを掛けた、上半身だけのトルソー。 | 中／低 |
| タイトルへ | 半開きの劇場の扉に、外へ戻る短い矢印を添えた図柄。 | 小〜中／低 |
| 贈り物 | 太いリボンと大きな結び目を持つ、正面寄りの贈答箱。 | 小／低 |
| コイン | 縁に刻みがあり、中央にスペードを打刻した厚い金貨1枚。 | 小／低 |
| 設定 | 太い歯を8つ持ち、中央に穴が開いた時計仕掛けの歯車。 | 小／低 |

ぱにゅぱにゅと衣装は現在、右側に肖像窓があります。最小変更なら、**その窓の中身を浮き彫りへ置き換える**方法がよいです。左にもアイコンを追加すると文字の場所が狭くなります。

各図柄を既存部品の実寸へ合成した見本で確認し、光源・金の色・影の硬さを揃えます。浮き彫りを別画像にしても、ここが揃えば部品として一体に見せられます。

**5．新しく描く絵と、コードだけでできる物**

固定画角の推奨案なら、**新規描画の最小構成は浮き彫り9図柄**です。6段階分の背景を最初から描く必要はありません。

| 区分 | 内容 | 手間・重さ |
|---|---|---|
| **新規・必須** | 上記9図柄。既存の金具を参照し、純緑背景・文字なしで制作して切り抜く。 | 制作は中。表示負荷は低。 |
| **既存を再利用** | 舞台、札、額、台帳、王冠、封蝋、鍵、次の相手の金印、肖像。 | 小／追加負荷ほぼなし。 |
| **コードのみ** | 勝利段階、封蝋の追加、肖像切替、局所的な陰影・光、揺れ、反射、一度だけの演出、停止処理。 | 全体で中／低〜中。 |
| **品質上必要なら追加** | 現在の構図を保った、劇場周辺まで明るい照明差分1枚。暗い部分に元の描写が不足する場合に使用。 | 中〜大／画像メモリ増、切替時のみ負荷。 |
| **引く案を採用するなら追加** | リコと舞台が一体の広い構図1枚。衣装変更時にも対応するなら、同構図の人物なし舞台も1枚。 | 大／常時処理より読込・メモリが増える。 |
| **針を動かすなら追加** | 針を除去した舞台と、独立した針。元の針が残ったまま重ねる方法は使えない。 | 大／回転自体は軽いが、原画整合が難しい。 |

スマホの44px条件は、画像の大きさではなく**変形後の押せる範囲**で確認します。現在の倍率では、94舞台pxが約45.8実pxと余裕が小さいため、カメラ変更や揺れでボタン本体まで縮めない設計が必要です。左下の台帳は現在ひとつのボタンなので、小さな肖像5枚を個別ボタンにする必要はありません。

実装・描画とも今回は行っておらず、負荷評価はコードと構成からの見込みです。

## 1.【最優先】左の案内札に載せた浮き彫りアイコン ― 「貼ったシール」に見える

ico-zoom.png で分かること。

- **台座ごと貼ってある**。交換所の天秤は、浮き彫り自身が持つ四角い板（背景のプレート）ごと札に載っている。札の金枠の上に別の四角が重なるので、金細工の一部ではなく「上から貼ったシール」に見える。コレクションの絵札は赤い布のかたまりに見え、札の赤と赤が重なって輪郭が溶けている。
- **札の外へはみ出し、枠に食い込む**。4つとも札の左端より外に出て、札の金枠の角飾りの上に乗っている。重なり方に意図（枠をくり抜いて嵌めた・枠に掛けた）が無いので、ただの位置ずれに見える。
- **縁がボケている**。拡大すると輪郭に白〜黄のにじみ（アップスケール跡）があり、隣の札枠の金線のシャープさと差が出る。これが「印刷が悪い」印象の正体。
- **視点が揃っていない**。天秤は正面の板、絵札は斜め俯瞰、本と角帽は3/4の立体。並ぶと寄せ集め。
- **2行だけ無い**。ぱにゅぱにゅ・衣装は金の丸いノブだけで、4行だけ図柄あり。「途中まで作った」ように見える。
- ミミの札のウサギは、0勝では金、5勝では白く光っている（§6の反射の白飛びと同じ原因と思う）。同じ部品が2色あるのは目立つ。

直し方（この順で効く）：
1. 浮き彫りは **台座を切り落とし、図柄だけ** にする（天秤・絵札・本・扉・箱・ウサギ・歯車すべて）。背景を透過し、図柄の外周に札の金枠と同じ色味の細い金縁（1px 相当）を付けて、札の金細工の仲間に見せる。
2. 置き場所を決める。案は二つ。**A** 札の左端に「丸い金メダリオン（札枠と同じ金線）」を1つ用意し、全行同じ大きさの図柄をその中に嵌める。**B** 図柄を札の内側（赤い布の上、文字の左）に収め、札枠からは一切出さない。はみ出しを「意図」にしたいなら、6行とも同じ量だけ、同じ角度で出す。今のように行ごとに違うのが一番安い。
3. 図柄は **札の高さの 70% を上限** に縮め、6行ぜんぶ同じ外接円に収める。視点は「正面・やや俯瞰」に統一（天秤に合わせるのが楽）。
4. 原寸で使う大きさの2倍で書き出し直し、拡大しない。ChatGPT で描き直すなら「背景なし・単一視点・金一色＋影」で6枚を一度に頼んで揃える。
5. ぱにゅぱにゅ・衣装にも図柄を入れる（ぱにゅぱにゅ＝赤石のリング、衣装＝ハンガーに掛けたドレス、など）。顔写真を使う2行は図柄を小さくしていい。

## 2. 右上の4つのメダリオンと「850」

- 八角の金枠が太すぎて、中の図柄が **札の 40% 程度** しかない。この大きさでは扉は「赤い長方形に金の棒」、歯車は「赤い点の付いた輪」にしか読めない。
- 4つとも同じ位置に同じ赤石が付いているので、遠目に **同じボタンが4つ** 並んでいるように見える。
- 「850」が、メダリオンの下に素の白文字（影付き）で置かれている。周りが全部金細工なのに、数字だけ CSS の文字。ここが一番「開発中」に見える。

直し方：
1. 枠を今の半分の太さにし、図柄を枠内の 65〜70% まで広げる。赤石は **ウサギの金貨（通貨）だけ** に残し、他は外す。
2. 「850」は、金貨のメダリオンの右に **小さな金縁の細長い札（名札と同じ作り）** を付け、その中に金色の数字を入れる。数字の書体は CTA の「今夜の卓へ」と同じ明朝で統一。桁区切りと単位は要らない。
3. 4つの横並びは、間隔を札の幅の 0.35 倍に詰め、「ミミ」札の上端と同じ高さに揃える（今は少し浮いている）。
4. cap-sheet（home-stage 側）は旧い線画のまま撮れている。差し替え後のもので撮り直す。

## 3. 「新入荷 7」「あと5回」のバッジ ― Web の CSS バッジそのもの

角の立った赤い長方形に白ゴシック。札の右上角に乗って金枠を隠している。画面で唯一、金縁を持たない赤い部品で、ここだけ別のアプリに見える。

直し方：
- **封蝋か、紐で下げた小さな荷札** にする。封蝋なら、台帳で使う封蝋と同じ赤石色の円に金の縁、数字は金で小さく。荷札なら、札の右上から短い金の紐で吊るす形にして、札枠と重ならない位置（枠の外側）に出す。
- 文字は「新入荷 7」ではなく **「7」だけ** にする（新入荷の説明は札の文字で分かる）。「あと5回」は「5」と小さな砂時計の図柄。
- 金枠を隠さない。重なるなら札の上に乗せず、札の右端の外に少し出す。

## 4. 台帳の施錠札 ― 灰色の板と南京錠が「準備中」に見える

0勝の台帳（Ⅲ〜Ⅴ）は、濃灰の板にフラットな南京錠。相手の顔札は手の込んだ金縁なのに、空き枠だけ無地なので「未実装」に読める。白いローマ数字も顔の上に乗って（5勝時）顔を汚している。

直し方：
1. 施錠札は **伏せた絵札の裏面**（ゲームの札の裏模様：赤地に金の唐草）にする。中央に札の数字（Ⅲ等）を金で、南京錠は外す。「まだ会っていない相手は裏向き」で意味が通り、灯りが入ると表に返る、という儀式にも繋がる。
2. 札の裏面は、卓の暗がりの中で燭台の揺らぎを拾うくらい暗い赤にし、顔札より一段沈める（明るくしすぎない）。
3. ローマ数字は札の **上の金枠の上**（札の外）に小さく付ける。顔札の上には何も載せない。
4. 0勝で解錠済みのⅠ・Ⅱと、施錠のⅢ〜Ⅴの間に、**封蝋の有無** を揃えて見せる（解錠＝封蝋あり、施錠＝裏面で封蝋なし）。

## 5. ミミのセリフ行 ― 字幕のプレースホルダに見える

卓の上に、裸の白ゴシックで「今日も頑張ろ」。背景なし、位置はおおよそ画面中央、スマホでは2行に折れて台帳と CTA の間に挟まる。ここは **毎回目に入る** ので、小さいが安さへの寄与が大きい。

直し方：
1. 書体を案内札と同じ明朝（細め）にし、色はクリーム（#f1e2b8 程度）、文字の下に **卓の木目と同系の暗い帯（高さ文字の 1.6 倍、左右はフェード）** を敷く。帯は不透明度 0.35 くらい、角は無し。
2. 置き場所を固定する。PC は台帳の右端と CTA の左端の間、卓の手前の縁に沿って1行。スマホはその行幅を超える文は **1行に収まる長さに台本側で切る**（「コイン貯まってきたじゃない。交換所、覗いてみる？」は長い）。折り返しは禁止。
3. 鉤括弧「」は外す。代わりに行頭に小さな金の飾り（◆や花弁の一片）を1つ。
4. 文字送りを「一度に出す」のではなく、儀式の最後と同じく **左から 0.3 秒で出し、12 秒で消える**。消えている時間があるほうが、出た時の品が上がる。

## 6. 赤石の使いすぎ、反射の白飛び、額の上の白い点

- 赤石が、札の両端（6×2）、額の頂、CTA の王冠と上下、台帳の頂、メダリオン4つ、と **20 個以上** ある。宝飾品は「少ないから効く」。
  → 残すのは **額の頂・CTA の王冠・台帳の頂の3つ**。案内札の両端の赤石は金の花飾りに置き換え、メダリオンの赤石は通貨だけ（§2）。
- 3.3 秒ごとの金の反射が、当たった部品を **白く飛ばしている**（5勝の review-sheet で ミミ札のウサギが白）。金に当たる反射は白ではなく、**薄い金（#ffe9a8）を狭い帯で、不透明度 0.35 以下**。長さは部品の幅の 30%、通過 0.6 秒。
- pc-stage0 の額の上辺の左右（y≈118、x≈1000 と 1170）に **白い小さな点** が2つ。鎖のアンカーだと思うが、静止画では「ゴミ」に見える。儀式の最中だけ鎖を描き、平常時は点を完全に消す。描くなら点ではなく「金の小さな鉤＋2〜3コマの鎖」。

## 7. 0勝の「琥珀色の影」が伝わっていない／暗がりが汚れに見える

- 0勝と5勝を並べても、文字盤の I〜V 区画の明暗差はほとんど分からない。文字盤はミミと額で大半が隠れ、見える区画が少ない。「育つ劇場」のいちばんの芯が、見た人に届いていない。
- 一方で、0勝の四隅の暗がりは **左上の案内札の上に被さって** いて、札の金枠がくすみ、「汚れた札」に見える。

直し方：
1. 文字盤の影は **見えている区画（上側 X〜I、右上の I〜III 付近）** に寄せて使う。隠れている区画に影を落としても誰も見ない。影の濃さは今の倍にして、区画の境を「光の当たる段差」で切る（ぼかさない）。
2. 「灯りが入る」は、文字盤より **客席の燭台の炎の数と明るさ** のほうがよく伝わる。0勝は炎を半分に・小さく、5勝で全部・大きく。これは今ある揺らぎの層の係数で済む。
3. 四隅の暗がりは **UI の層より下** に敷く（案内札・メダリオン・額・台帳は暗がりの影響を受けない）。暗がりの境は画面端から 12% で終え、札に届かせない。

## 8. 書体の混在と CTA の傾き

- 案内札＝太めの明朝＋濃い影、CTA＝筆気味の極太明朝、セリフ＝ゴシック、バッジ＝ゴシック太字、「850」＝別の数字書体。**4〜5 種類** が同じ画面にある。
  → 明朝1系統に揃える。案内札は Medium、CTA は Bold、セリフは Regular、数字は同じ明朝の数字。影は「1px 下に暗赤」を1本だけ（今の広がる黒影は外す）。
- CTA の札だけ 3° ほど傾いている。他の部品はすべて水平なので、傾きは「貼り直した値札」に見える。**水平に戻す**。動きを付けたいなら、19 秒の風で 0.5° だけ揺らすほうが品がある。
- 「勝てば 500 コイン ＋ご褒美CG」はスマホで2行に折れ、2行目が「＋ご褒美CG」だけになる。**「500 コイン と ご褒美CG」を1行に収まる字数** にし、折り返さない。

## 9. スマホ横の詰まり

phone-stage0.png：案内札が細くなった分、図柄が文字に重なる（コレクション）。ぱにゅぱにゅは顔写真と文字が接している。台帳・セリフ・CTA の3つが下段で接触している。

直し方：
- スマホでは案内札の図柄を **札の内側・文字の左** に入れる（§1 の案 B）。顔写真のある2行は写真を札の高さの 80% に抑える。
- 下段は、セリフ行を台帳の **上**（卓の奥の縁）に移し、台帳と CTA の間を空ける。
- 案内札6行の縦間隔を等間隔にする。PC でも ぱにゅぱにゅ→リコの教室 だけ広い（90px 前後に対し他は 75〜85px）。等間隔にするだけで「設計された棚」に見える。

## 良い所（短く）

- 右の額（赤い幕・金の額縁・下の名札）は、この画面で一番高級に見える部品。他の部品は **この額の作りに寄せる** のが正解で、新しく考える必要はない。
- 色の統一（赤・金・琥珀）と、ミミの絵の収まりは良い。背景の時計の光も、ミミの髪の逆光として効いている。
- 儀式（rite-sheet）は、止まった後の額の揺れが小さく、派手すぎない。方向は正しい。
- 台帳の金枠と封蝋は良い。中身（§4）だけ直せば十分。

## 優先順の要約

1. 案内札の浮き彫り：台座を切り、札枠から出さず、6行同じ大きさ・同じ視点、原寸2倍で描き直し
2. メダリオン：枠を細く図柄を大きく、赤石は通貨だけ、「850」は金縁の札に金文字
3. バッジ：四角をやめて封蝋か荷札、数字だけ
4. 施錠札：灰色＋南京錠をやめて伏せた札の裏面、数字は枠の外
5. セリフ：明朝・暗い帯・1行固定・鉤括弧なし
6. 赤石を3つに減らす、反射の白飛びを金に、額の上の白い点を消す
7. 0勝の影を見える区画と燭台の炎に寄せ、暗がりを UI の下に敷く
8. 書体を明朝1系統に、CTA を水平に、報酬文を1行に
9. スマホの詰まり（図柄を内側へ、セリフを台帳の上へ、行間を等間隔に）

# リーディングのお手本の長さの精査　2026-11-17・本体

作者：「お手本全部を一律短くするのは危険。それぞれに適正な長さがあるはず」。Codex の「等速で26〜35秒、8〜10秒に」は一律の案なので採らない。遊びごとに、**初めての人が本番の1回目で迷わないために、最低限見せる物**を決め、止まる所（リコの一言・4秒か押すと次へ）をそれに合わせる。

## 物差し
- 教える物 ＝ 決まり（1つ）＋ 見る所 ＋ 考える手順 ＋ 外した時の損。これが全部、お手本の中で1回ずつ目に入ること。
- 止まる所は、教える物1つに1回。同じ事を2回言う所、本番の画面を見れば分かる所（結果の明かし・ご褒美）は止めずに流す。
- 長さの決め手は、決まりの重さ（読み替えの段数）。決まりが1段の遊びは短く、2段の遊びは長いままにする。
- 手で操作するのが芯の遊びは、見せるより、**手引き付きで1回やらせる**ほうが早く身に付く。

## 共通
- どの遊びも「とばす」はそのまま。2回目からは右上の「お手本」で同じものを見直せる。
- 止まる所の4秒は、読み終わる前に進まないよう、文の長さで決める（1行目安 2.5秒＋1行ごとに1.2秒、最大5秒）。押せばすぐ次へ。
- お手本の後の4点の札は、その遊び・その相手に要る物だけ（おねだりの印の読み方は、その相手の分だけ）。
- 縮めた後、初めての人の目で「本番の1回目に、何を見て何を押すか言えるか」を、撮った画面の文字だけで確かめる（clarity）。

## 目利き・おねだりの形の作り替え（同じ段で行う）
- 目利き：場札のめくり直しをやめ、卓の本物のめくり（フロップ3枚・ターン・リバー）の間に、相手の反応と札の下の印を出す。リバーの後に、見立て3つを卓の上に重ねる。お手本だけは今の盤で流す。
- おねだり：「聞く」は卓の上の吹き出しと印だけ（盤を開かない）。リバーの後の判断で1回だけ盤を開き、答え合わせは手の後。

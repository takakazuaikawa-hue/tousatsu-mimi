**3．主導線の階層**

**「卓へ」は最大の操作ボタンとして読める。ただし、迷いなく物語を進める導線にはなっていません。**

PCでは右上の「商人グラーノの値札勝負」が、同じ人物・大きな見出し・期間限定表示で競合。同じ物語なのか、別イベントなのか判断できません。グラーノの顔も進行札・対戦予告・告知の3か所に重複しています。

CTA内のコインは入場料や購入を連想させます。「今夜の卓へ」と勝利報酬の明記で行動を確定させるべきです。リコが最初に目に入る構図は問題ありません。**鑑賞の主役はリコ、操作の主役はCTA**という関係が成立します。

コード上は電球、現行札、ランク枠、コイン、台詞も反復して動きます。静止画で成立している優先順位を、実動時に崩す構成です。

**4．スマホ横844×390**

`fit()`の倍率は390÷800＝**0.4875**。以下はコードからの算出値です。

| 要素 | 表示寸法・文字 | 判定 |
|---|---:|---|
| 左メニュー | 約151×37／11.7px | 高さ不足 |
| 通知・贈り物・設定 | 約29×29 | 大幅不足 |
| CTA | 約176×43／16.6px | 高さが基準未満 |
| コインの＋ | 約15×15 | 小さく、現状はspan |
| 通常／現在の進行札 | 約30×42／36×51 | 操作対象なら幅不足 |
| 台詞／EPISODE | 9.8／7.8px | 可読下限未満 |
| WIN・バッジ／ランク | 5.9／8.3px | 読ませる寸法ではない |

主メニュー名は最低限読めますが、細い明朝と約13pxの小アイコンが認識を遅らせています。画面全体が過密というより、**右側に余白を残したまま操作部品だけ小さい**状態です。

左メニューを上端56から44高×5段・間隔6で置けば下端300。進行札を下端16・高さ56に配置できます。左右余白にはセーフエリアを加算。報酬とイベント情報を単純に非表示にする設計も改める必要があります。

## セーブ（続きから遊ぶ）について

- 進み具合は**自動で保存**されます。手動でセーブする操作は要りません。
- 保存先は、遊んでいる**端末のブラウザの中**です（サーバーや、あなたのアカウントには保存されません）。
- **次のような時、進み具合が消えます。**
  - ブラウザの「サイトデータ」「履歴とキャッシュ」を消した時
  - 別のブラウザ、別の端末、別のアドレスで開いた時（保存はそれぞれ別です）
  - プライベートモード（シークレットモード）で遊んだ時（保存できない、または閉じると消える）
  - iPhone の Safari で、長い間（数週間ほど）開かなかった時（Safari が自動で消すことがあります）
  - ゲーム内の「セーブデータをリセット」を押した時
- **控えを取る方法（おすすめ）**：ホームの「音量・設定」から「セーブの引き継ぎ」を開きます。
  - 「控えを取る」：「引き継ぎコード」（長い文字の列。MIMI1: で始まります）が出ます。「コードを写す」でコピーしてメモ帳などに貼る、または「ファイルに保存」で文字のファイル（mimi_poker_save_日付.txt）にしておきます。
  - 「コードで続きから」：別の端末やブラウザで同じゲームを開き、コードを貼って「読み込む」（または「ファイルから」）を押すと、続きから遊べます。読み込み後は自動で再読み込みされます。
  - ぱにゅぱにゅの衣装の選び、心の声の図鑑も一緒に運ばれます。対戦の細かい記録は運ばれません（遊びには影響しません）。
- 大事な進み具合は、ときどき控えを取っておくと安心です。
- セーブが読めなかった時は、壊れた分の控えを残して新しく始めます（その旨の知らせが出ます）。
- 根拠：game.js の SAVE_KEY、loadProgress、saveProgress、showSaveTransfer（19559行〜）。【要確認】「数週間」という iPhone の目安は Apple の仕様に依るため、断定せず「長い間」に留めるのが安全。

## 通信がない場所で遊ぶ（まとめてダウンロード）

外出先などで通信を使いたくない時のために、全部の素材を端末に保存できます（任意です。押した人だけ保存されます）。

1. Wi-Fi につないだ状態で、ゲームを開きます。
2. 初回に出る案内、またはホームの「音量・設定」にある「まとめてダウンロード」を押します。
3. バーが最後まで進んで「ダウンロード済み」と出れば完了です（約84MB。途中で切れても、次に開いた時に続きから取ります）。
4. 以降は、機内モードでも、同じアドレスを開けば始まります。

- 保存先の容量が足りないと「取得できなかったファイル」と出ます。空きを作って、もう一度押してください。
- 「保存した分を削除」で消せます。
- iPhone では、しばらく遊ばないと保存が消されることがあります。**ホーム画面に追加すると消えにくくなります。**
- ゲームが更新された時は、通信できる状態で開くと「更新あり」と出て、自動で取り直します。
- 根拠：docs/design-ref/offline-pack.md。【要確認】販売版で実機（機内モード）の起動を確かめる。

## 困った時

**音が出ない**
- 端末の音量、マナーモード（iPhone は本体横のスイッチ）を確かめてください。ゲーム内の音のボタンで、声・効果音・曲の音量を変えられます。
- 設定に「端末が消音でも音を出す」があります。
- 最初の画面を一度タップするまで音が鳴らないブラウザがあります（ブラウザの決まりです）。

**文字が小さい・読みにくい**
- スマホは文字の大きさを最小14px以上にそろえてありますが、画面が小さい機種では詰まって見えることがあります。ブラウザの拡大（ピンチ）はゲームの作りで無効です。
- 【要確認】文字を大きくする設定の有無。無ければ「この版では変えられない」と正直に書く。

**画面が縦のままで遊べない／横に切り替わらない**
- スマホは**横向き専用**です。端末の「画面の向きの固定」をオフにして、横にしてください。

**動きがカクカクする・端末が熱くなる**
- ほかのアプリを閉じ、ブラウザのタブを減らしてください。【要確認】ゲーム内に動きを減らす設定があればその名前（OS の「視差効果を減らす」設定には対応しています）。

**iPhone のホーム画面に追加（全画面で遊べて、保存も消えにくくなります）**
1. Safari でゲームのアドレスを開きます（Chrome ではなく Safari で）。
2. 画面の共有ボタン（□に↑）を押します。
3. 「ホーム画面に追加」を選び、「追加」を押します。
4. ホーム画面にできたアイコンから開きます。
- ホーム画面から開いた版と、Safari で開いた版は**保存が別**です。先に Safari で遊んでいた場合は、「セーブの引き継ぎ」で控えを取ってから、ホーム画面版で読み込んでください。

**Android（Chrome）のホーム画面に追加**
- メニュー（︙）の「ホーム画面に追加」または「アプリをインストール」。ゲーム内に「ホーム画面に追加」のボタンが出ることもあります。

**読み込みが終わらない／真っ黒のまま**
- 通信を確かめ、ページを再読み込みしてください。直らなければ、ブラウザを最新にするか、別のブラウザで試してください。
- 【要確認】保存した素材を消して直す手順を書くか。書く場合は**消す前に必ず「セーブの引き継ぎ」で控えを取る**ことを先に書く。

# 画像生成 指示書 第2弾（CODEX用）— UI装飾・ボタン・カットインFX

> 納品先: `tousatsu_mimi/assets/ui/` 配下（ファイル名は下表どおり厳守）
> 目的: ウィンドウ・ボタン・カットインを商業品質に。**遊びやすさ最優先**＝装飾は縁に寄せ、
> 中央の情報領域を邪魔しないこと。
> 第1弾（キャラ・背景）は納品済み。画風の統一基準も第1弾と同じ:
> 夜のVIPカジノ、金×深紅×黒、アニメ塗り。参照: `assets/ui/btn_frame.png` / `assets/backgrounds/title_bg.png`

## 共通ルール

1. **9スライス前提のフレーム画像**は、四隅の装飾を角 96px 以内に収め、辺の中間は
   単純な繰り返し可能なパターンにすること（CSS `border-image` で伸縮させるため）
2. FX・オーバーレイ類は**背景透過PNG**。発光表現はプリマルチプライなしの半透明で
3. 文字は一切入れないこと（テキストはゲーム側で重ねる）

## 納品チェックリスト

1. ファイル名が本書と1文字違わず一致
2. フレーム類：中央が完全透明で、9スライスの角サイズ規約（A=96px/B=48px）を守っている
3. FX類：黒地で確認したとき発光が自然（白フチ・ハロー割れなし）
4. テクスチャ2枚：上下左右がシームレスに繋がる
5. 全体：既存 `btn_frame.png` / `title_bg.png` と並べて違和感がない

## 実装側の予定（参考・Sonnet/本体側の作業）

- フレーム: CSS `border-image: url(frame_psych.png) 96 fill / 72px` を
  `.psych-modal` 系に適用（画像未納品時は現行グラデ枠が残るフォールバック構成）
- ボタン: `.btn-primary` 等に `border-image` 適用
- カットインFX: `.rico-cutin` / `.cutin-flash` に重ねる `<img class="cutin-fx">` レイヤー追加
- スタンプ: 講義の正解/不正解カットインに 0.3s のスタンプ演出（scale 2→1 + 回転）
- 全て onerror / 多層 background によるフォールバック必須（画像が無くても壊れない）

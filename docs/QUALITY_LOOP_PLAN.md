## 2. 設計の芯

### 三原則
1. **見せる前に体験させる。** 画面に出る語と数字は、その時点で体験済みのものだけにする。新しい要素は、初めて必要になった瞬間に1つだけ光らせ、一言で名前を付け、使えたら褒める。
2. **選んだら必ず答え合わせする。** 読み・降り・コールの判断を実際の札と照合し、結果画面で褒めるか、次の一手を示す。
3. **理解した方が勝てる。** オールイン連打や全部コールでは勝ち越せず、その卓で学んだ考え方で勝てるように AI を直す。

### 仕組み：学習台帳（LEARN）
- 概念ごとに「解放済みか」を save に持つ。例：ante_pot, bet, check, call, fold, streets, showdown, hand_rank, psych, mimimi, panyu, tell, bluff_odds, board_danger, pot_odds, range, evidence。
- バトル画面の描画関数は台帳を見て出し分ける。未解放の要素は描かない。
- 「はじめての○○」は1ハンドに1つまで。スポットライト＋一言＋タップで進む。二度目からは出さない。
- 検出器が台帳と画面の文字を照合し、未解放の語が出たら失敗にする。

## 4. フェーズ

各フェーズは「実装→自動検査→監査→直す」を1周とし、P0/P1 が0になるまで同じフェーズで回す。順番は、事実を正す（1・2）→最初の5分（3）→本編（4）→教室（5）→奥行き（6）→スマホ（7）→仕上げ（8）。

### フェーズ0　検証の道具（最初に作る）
- **自動通しプレイ**：新規セーブ→研修→全卓→エンディングを、3つの方針の Bot（オールイン連打／全部コール／学んだ方針）で回す。タイマーを速めて実行し、例外・停止・重なったオーバーレイを数える。
- **対戦シミュレータ**：ページ内で AI の関数を直接回し、方針ごとの勝率・ハンド数・割り込み回数を出す。
- **未習語検出器**：学習台帳と画面の文字を照合する。
- **重なり・切れ検出器**（occlude/overlap の作り直し）と、1280×800・844×390・667×375 の撮影セット。
- **初心者ペルソナ監査**：実機を新規セーブから通し、画面ごとに「知らない語」「読む量」「押す理由」「返ってきた報酬」を記録するエージェント。

- foldDiscipline の向きを直す（898）。性格の攻略文（6289-6319）と「通る見込み」（6703）を実測値から作り直す。

### フェーズ3　研修を作り直す（最初の5分）
- 研修の3ハンドで、ベット・チェック・コール・フォールドを必ず1回ずつ自分で押す。押せるボタンはその時1つか2つだけにし、他は描かない。
- **Hand1** はプリフロップ（2枚）から始め、参加費とポットをチップの動きと一言で見せる。場札が3・1・1枚開く順番を体験させ、ターンでは「タダで次を見る＝チェック」を押させる。「大レイズ」ではなく「ベット」と呼ぶ。
- **Hand2** は「場のKペアはお互い様。自分の手札は何も足していない」と正しく言う。降りて失ったのは参加費だけだと数字で見せ、褒める。
- **Hand3** は卓で聞いたセリフと心理バトルのセリフを一致させる。答えを書いた付箋を外し、外したときだけヒントを出す。正解後はプレイヤーが「コール」を押し、ショーダウンでリコの手を開いて「やっぱりブラフ」と答え合わせする。
- 研修中は勝率・詳細データ・ミミミ・賭け金行・ぱにゅぱにゅを出さない。教える一言はプレイヤーが押すまで消さない。
- 完了画面で「覚えたこと」4枚のスタンプ（役・賭ける・降りる・読む）を押して報酬にする。ロビー初到着ではログインボーナスを出さず、次の卓はポルカにする。

### フェーズ4　本編の段階解放と答え合わせ
- 学習台帳を実装し、バトル画面の全要素を台帳で出し分ける（勝率・詳細データ・通る見込み・キッカー・手札の俗称・危険度・必要勝率・レンジ帯・SPR/AF）。
- 各卓の「はじめての○○」：ポルカ戦の最初の心理バトルで遊び方を体験させる。初成功でミミミ、初ぱにゅぱにゅで「勝率が見える」、最初のテルで「今の顔、見た？」。
- テーマの道具はその卓の間だけ貸し出し、勝ったら自分のものにする。
- **心理バトル**：値打ちのある手のベットでも出す（12673）。正解は実際の相手の意図で決める。選択肢を「付き合う／降りる」の判断に寄せる。ショーダウンで「さっきの読み：ブラフ→正解！」を出し、読みどおりに動いて勝てば追加の報酬を出す。
- **論理バトル**：卓の到達度で出題範囲を絞る（4985-5022）。1ハンド1回・1戦2〜3回まで。状況文は実際の札から作り、合わない問題は出さない。
- **ハンド結果**：自分で降りたら「撤退 −50」。必要勝率より低くて降りたら、押さなくても「ナイス撤退」で褒めて加点する。勝ち負けの理由を1文で書き、その札を光らせる。収支は実額で出す。「次のハンドへ」は1タップにする。
- **敗北と座り直し**：負けた分岐点を1行で見せ、次の1ハンドで直せたら褒める。
- **用語**：タップで1行の説明が出るチップにする。足りない用語を辞典に足し、バトル中と結果画面からも辞典を開けるようにする。ストリート名はカナ併記、BB はチップ額に、手札の俗称は「強い／ふつう／弱い」に置き換える。

### フェーズ5　講義を「リコの教室」へ
- 本筋から外し、ロビーのリコ席から任意で入る。章を選べて、済／未と正解数が見える。
- 10秒の早答えボーナスを廃止する。選択肢の長さを揃え、もっともらしい誤答に差し替える。
- 役の章は「7枚から5枚をタップして役を作る」、役の強さは「並べ替え」、アウツは「数える」に置き換える。
- ハンズオン演習はその章までの語だけで書く。正解で報酬、外したら選択肢を1つ潰して再挑戦させる。
- 雑学（WSOP の賞金）とマナー章はコレクションの読み物へ移す。背景は卓ではなく教室にする。
- 章ごとの初回だけ報酬を出し、周回のコイン稼ぎを止める。講義完了で幕間とリコのご褒美CGにつなげる。

### フェーズ6　報酬と奥行き
- 「どの選択にどの報酬が返るか」の表を作り、返りの無い選択を0にする。
- 最初のコイン獲得で「コイン＝交換所のお金／チップ＝卓で賭ける札」を見せ、そのまま1品買わせる。ロビーの数字にコインのアイコンを付ける。交換所の最初の棚は戦術ノートにし、説明を行動の言葉で書く。未入荷品は鍵付きで入荷条件を出す。
- 卓につく前に「Sランクの条件と報酬」を1行で出し、戦闘中に「Sまであと○点」を出す。
- クリア後：各卓の条件付き挑戦（例：3回正しく撤退して勝つ、ブラフを2回見抜く）と、SSランクの報酬（衣装や CG 差分）。本気リコの報酬を最強戦にふさわしい額にする。
- エンディングに「ミミが覚えたこと」と本人の成績、次の目標を出す。スキルを否定して終わる台詞（7301）を見直す。
- エンディング・主題歌・スタッフロールはクリア後に無料で見返せるようにする。ファイブポーカーの誤った期待損益・オールイン任務・リベンジ文言を外し、賭けの上限を下げる。ロビーのぱにゅぱにゅ稼ぎに1日の上限を付ける。
- ステージのスキップは同じ相手に3回負けたら出す。スキップしてもその卓のテーマを1枚で見せる。

### フェーズ7　スマホ横持ちで読める・押せる
- 読む必要のある文字（独白・助言・選択肢・付箋・危険度・レンジ帯）を実効12px以上にする。今は667×375で4〜7px。
- body 直下のオーバーレイを舞台の座標に入れるか、高さ基準のメディアクエリで縮め、カットインが場札を隠さないようにする。相手カットインの額と台詞を縦に分ける。
- 講義と吹き出しのボタンを画面下端に固定する。押す対象の当たり判定を実効40px以上にする。
- 全画面ボタンをロビーの操作列から外す。縦持ち警告の文言を事実に合わせる。title 属性だけの説明をタップで読める形にする。

### フェーズ8　仕上げの監査ループ
- 新しい目の初心者ペルソナ監査（完全な未経験者／スマホだけの人／せっかちな人）と、差分への敵対的レビュー（正しさ・学習設計・製品品質の3視点）を回す。
- 新規の P0/P1 が2周続けて0になったら完了とする。

## 5. 受け入れ基準（数値で判定する）

| 項目 | 基準 |
|---|---|
| 進行 | 3方針の Bot で研修〜エンディングを通し、例外・停止・重なったオーバーレイが0 |
| 未習語 | 台帳の語が解放前の画面に出た回数が0 |
| 読む量 | 吹き出し1つ60字以内。講義の状況文も同じ。押す前に消える教えの文が0 |
| 選択の返し | すべての選択に、即時の返しと結果画面での答え合わせがある |
| 難度 | 各卓でオールイン連打25%以下、全部コール30%以下、学んだ方針60%以上。1戦8〜15ハンド |
| 表示 | 3サイズで重なり・切れが0。学ぶ文字は実効12px以上、押す対象は実効40px以上 |
| 売り物 | 効果の無い商品、説明と違う商品が0 |
| 監査 | 初心者ペルソナ監査で P0/P1 の「分からない・面倒・理不尽」が2周続けて0 |

## 6. 進め方
- 1周＝実装→自動検査→監査→直す。1テーマ1コミット。
- 演出基盤や state・タイマーが絡む箇所は本体で直す。独立した画面や文言・データの整理は worktree の並行エージェントに任せる。style.css の末尾追記が衝突したら両方残す。
- 各フェーズの完了時に ?v= を上げて main へ push し、公開URLで実際に開いて確かめる。
- 新しい絵が要る場面（教室の背景、覚えたことのスタンプなど）は ChatGPT で作る。

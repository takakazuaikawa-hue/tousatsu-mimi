## 納品チェックリスト（CODEX 側で確認）

1. ファイル名が本書と1文字違わず一致しているか
2. キャラ画像は背景が完全透過か（白フチ・ゴミ残りなし）
3. ミミの顔・髪・衣装が mimi_default.png と同一人物に見えるか
4. 背景4枚のテーブル中央部が無地に近いか（UI が乗る）
5. 表情差分は構図がズレていないか（差し替えたときに位置が跳ねない）

## 配線について（Sonnet 側の対応・参考）

- 表情差分は `docs/PRODUCTION_POLISH_PLAN.md` P1-3 の setMimiExpression() が読み込む
- スキン差分が届いたら P1-1 の CSS フィルタを画像差し替えに格上げ
- 背景が届いたら battle 開始時に `body[data-opp="polka"]` 等で切替（onerror で既存 bg にフォールバック）
- **画像が未納品でもゲームは壊れない**（全て onerror フォールバック済み）ので、納品順は任意

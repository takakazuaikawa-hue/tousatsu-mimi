# ミミのテキサスホールデムポーカー

転生したらバニーガールだった私の外れスキル《ぱにゅぱにゅ》だけがレベルアップな件 — 心理ポーカーで成り上がる異世界カジノADV。

ブラウザだけで遊べる、心理バトル付き1人用ポーカーゲームです。

## 遊び方

GitHub Pages で公開されている場合：

👉 https://takakazuaikawa-hue.github.io/tousatsu-mimi/

ローカルで遊ぶ場合：

```bash
# このリポジトリをクローン
git clone https://github.com/takakazuaikawa-hue/tousatsu-mimi.git
cd tousatsu-mimi

# シンプルなHTTPサーバーで起動（Python 3 の場合）
python -m http.server 8000

# ブラウザで http://localhost:8000/ を開く
```

> ⚠️ `file://` で直接 `index.html` を開くと一部機能（テンプレート読み込み等）が動作しないことがあります。必ずHTTPサーバー経由で開いてください。

## ゲーム内容

- **Stage 1** リコ先輩のチュートリアル（操作・心理バトル基本）
- **Stage 2** ポルカ戦（ブラフ入門）
- **Stage 3** セリナ戦（ボード危険度・ベットサイズ）
- **Stage 4** グラーノ戦（ポットオッズ・割に合う判断）
- **Stage 5** ヴェルベット戦（VIPルーム・証拠突きつけ・ブラフブレイク）
- エンディング

各ステージ初回クリアでコイン報酬、戦術ノート自動解放。交換所でぱにゅぱにゅ強化・カード裏スキン購入。

### 特徴

- **心理バトル**：相手のセリフ・ベット・場札から違和感を読み取る
- **ぱにゅぱにゅ**：ミミの外れスキル。ヒントになる
- **ゾゾゾゲージ**：相手の動揺を可視化。MAXで「ブラフブレイク」
- **圧倒モード**：優勢時に自動勝利演出
- **闘札大逆転**：ボス戦の必殺演出
- **エピソード演出**：各話開始に長文ラノベ風タイトルカード

## 技術構成

- HTML / CSS / JavaScript（バニラ、フレームワーク不使用）
- ブラウザ単体で動作（サーバー不要）
- localStorage で進行保存
- 固定キャンバス 1280×800 を JS でウィンドウフィット拡縮

## ライセンス

個人プロジェクト。素材は各画像の権利者に帰属します。

### プレイ感（2026-08 強化分）

- **段階ショーダウン**：相手の手札めくり → 勝ち札ハイライト → 勝敗コール → チップがスタックへ飛ぶ
- **配布・めくりアニメ**、ベット時のチップ飛行、相手の「考える間」と即反応セリフ
- **連勝バッジ**／**ピンチ演出**（赤ビネット＋心音）／オールイン対決の暗転
- **リザルト演出**：段階表示・コインカウントアップ・ランクスタンプ・次の目標
- **デイリーログインボーナス**（7日サイクル）

### 見せ場（2026-09 強化分）

- **表情カットイン**：全6キャラが性格ごとに崩れる（女王は堕ちきる／ポルカは決壊／セリナは無表情のまま壊れる／グラーノは縋りつく／リコ先輩は笑って拍手しながら涙）。煽りが最高潮になるほど、崩れた時の演出も最大になる
- **動く一枚絵**：タイトル・ロビー・ご褒美CG・各話の扉絵・エンディングが動画で動く（再生できない環境では静止画のまま）
- **ロビー**：「次の卓」だけに照明が当たる劇場型。未解放の卓は煙ったガラス越しに賞金だけ見える
- **勝負の構造**：相手はミミの2倍のチップを積んでいる（オールイン1回では終わらない）。ミミは1戦に1回だけ座り直せる
